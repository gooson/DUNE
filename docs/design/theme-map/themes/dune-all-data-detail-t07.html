폭과 접근성

일반 행은 시각과 값을 좌우에 둔다. 좁은 Duo 또는 접근성 글씨에서는 시간 위, 값 아래로 배치한다. 이 도식의 값도 예시다.

오전 8:15+36.5 °C

iPad·Duo 펼침은 읽기 폭을 약 680–760pt로 제한하고 한 열 목록을 유지한다. 60pt 고정 시각 폭이나 값 생략은 사용하지 않는다.

표면과 아이콘T06 ScoreHeroPalette.surface/ink/border를 이어 쓴다. 브라우저 ♡는 도식일 뿐이며 네이티브는 16개 범주의 category.iconName을 사용한다.
색과 배경category.themeColor는 능선·작은 강조에, DetailWaveBackground는 기존 정적 화면 바탕에 사용한다. 값 자체를 건강 판정 색으로 코딩하지 않는다.
상태와 동작기존 .insetGrouped List, 페이지 spinner, 제한 이력 notice, 빈 상태, 시스템 back과 AXID를 보존한다. 링·차트·움직임·기간 필터는 추가하지 않는다.

16개 범주와 ready/loading/empty/limited/limited-empty의 정확한 정보 순서는 레이아웃 계약을 따른다. 네이티브 적용과 실제 전후 화면은 별도 캡처로 검증한다.
