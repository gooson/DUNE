테마 맵 · 배치 계약

P02 · 실시간 자세

구현 기준 정적 시안. 수치·웹 기호는 설명용이며 실제 기록·SF Symbol·앱 캡처가 아니다.

정보 순서

camera preview → 실제 score/skeleton/angles → 작은 운동 선택·폼·가이드 overlay. 미가용 시 camera.fill·원래 오류·Try Again을 강한 중앙면에 둔다.

보존 동작

start/stop·retry·switch·voice·form mode·운동 선택·Close 보존. 카메라 없어도 가능한 운동 선택을 유지한다.

기기·큰 글씨·상태

일반 iPhone·iPad·Duo 접힘/펼침을 대상으로 한다. 한 열 스크롤, 안전 영역의 원래 toolbar/CTA, MAX에서 수직 확장. camera preview에 큰 장식을 덧씌우지 않는다. 카메라·추론 성공은 시뮬레이터로 입증하지 않는다. 새 native PNG/AX와 Close/선택/결과 행동 검증 전에는 완료로 표시하지 않는다.

카메라 장면 영역 · 실제 영상은 예시하지 않음
