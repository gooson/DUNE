권장 행동

평가가 있으면 기존 단계별 권장 문구를 유지한다.

A08의 적색/황색/녹색은 모델의 Low/Moderate/High/Critical 단계 표시에서만 사용한다. 각 요인 막대는 최대 요인 대비 상대 길이이며 100% 임상 확률이 아니다. 원본 Activity 경로는 자세 지표를 보내지 않으므로 자세 요인 예시는 그리지 않는다. 보통 글씨에서는 원래 크기의 점수 링을 쓰며 위험 단계 호는 불투명한 원래 단계 색, 트랙은 옅은 색으로 구분한다. 최대 글씨에서는 실제 점수를 링 밖에 두어 읽기 순서를 유지한다. 모든 줄을 줄바꿈하고 680pt 읽기 폭을 넘기지 않는다.
