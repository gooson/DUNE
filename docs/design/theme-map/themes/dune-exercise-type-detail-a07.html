양수 거리 m/km, 실제 건강 앱 세션 최대 10건. kg·세트 추론 없음.

영웅 본문은 불투명한 표면과 밝은 팔레트 잉크로 읽는다. 활동/장비의 원래 의미 색은 아이콘 강조로 두고 작은 변화율은 어두운 표면에서 별도 대비를 확인한다. 최대 글씨는 텍스트를 축소하지 않고 세로로 쌓는다. 실제 원본·변경 후 화면은 별도 실제 화면 디자인맵에 보존한다.
