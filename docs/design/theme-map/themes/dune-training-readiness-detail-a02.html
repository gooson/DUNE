Ready · Moderate · Light · Rest

상태는 실제 점수의 네 임계값과 기존 flame.fill / figure.walk / leaf.fill / bed.double.fill로 결정합니다. 시안은 Moderate만 예시로 보여줍니다.

Calibrating

실제 isCalibrating일 때만 배지와 네 번째 계산 bullet을 표시합니다. 점수의 정확도를 새로 주장하지 않습니다.

Loading / Nil / sparse history

기존 spinner, “Need More Data”, chart empty state를 구분합니다. 빈 값을 0이나 임의 포인트로 채우지 않습니다.

현재 점수

HRV 30 / Sleep 25 / RHR 20 / Recovery 15 / Trend 10의 계산 구성 점수입니다. 중립 대체값은 관측 증거가 아닙니다.

기간 이력

Day는 rolling readiness snapshot. 비-일간 차트는 HRV·RHR·수면 세 원천의 근사치이며 다섯 구성의 과거 재계산이 아닙니다. 이전/다음 화살표는 제안하지 않습니다.

아이콘

네이티브 상태 심볼은 위 model mapping을 따르고 요인은 waveform.path.ecg, moon.zzz.fill, heart.fill, heart.text.clipboard, chart.line.uptrend.xyaxis를 사용합니다. 브라우저의 보조 문자들은 SF Symbol 캡처가 아닙니다.

실제 증거

원본 iPhone selector 1개가 영어·최대 접근성 글씨에서 통과했습니다. iPad 첫 max-AX 사례만 통과했고 배치는 계속 수집 중입니다. 일반 글씨 원본과 Duo는 미검증입니다. 구현 후 별도 actual 디자인맵의 새 캡처로 대조합니다.
