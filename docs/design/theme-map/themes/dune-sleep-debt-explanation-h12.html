H12 · 수면 부족분 설명

정적 테마 표현 시안. 접근성 크기에서는 아이콘·Close 다음 줄에 제목을 카드 폭으로 배치하고 카드 기호는 텍스트와 겹치지 않게 확장한다. 그림과 수치는 실제 건강 기록·SF Symbol·네이티브 캡처가 아니다. 앱은 테마별 ScoreHeroPalette 히어로와 기존 DUNE 카드 토큰을 사용한다.

ⓘ How Sleep Debt Works
◉Baseline

지난 14일 개인 평균. 기록 없는 날은 제외.

◉How It Adds Up

지난 7일의 하루별 부족분을 더함.

◉Excess Sleep

초과 수면은 앞선 부족분을 상쇄하지 않음.

◉Levels
Well Rested < 2h
Slightly Short 2–5h
Sleep Debt 5–10h
Severe Debt > 10h
