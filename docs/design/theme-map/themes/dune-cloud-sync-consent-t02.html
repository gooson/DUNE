T02 · 동의 시트 테마 표현

승인된 T02 방향을 기존 DUNE 팔레트에서 밝음·어두움으로 해석한 정적 연구 시안. 실제 앱 캡처가 아니다. 구름 그림은 웹 표기이며 앱은 원래 SF Symbol `icloud.and.arrow.up`을 사용한다. 다른 테마는 기존 `ScoreHeroPalette` 표면·강조색과 각 테마의 시트 배경을 따른다.
