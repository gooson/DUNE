원래 데이터와 동작

Activity A10과 알림 T16은 같은 상세 화면이다. 알림은 로딩 후 기존 unlockedBadgeKeys를 전달한다. Share와 보상 안내 A21, 실제 Back을 유지한다.

일·주·월·6개월·년: 일은 현지 자정부터 현재까지, 주는 오늘을 포함한 일곱 현지 날짜다. 한 번 계산한 동일 범위를 제목·필터·차트에 쓴다. 이전/다음 이동과 추세선 토글은 없다. 점이 없거나 하나면 그대로 표시한다.

기록 종류: trophy.fill 추정 1RM kg · scalemass.fill 반복 최고 중량 kg와 3RM/5RM/10RM subtitle · chart.bar.fill 세션 볼륨 kg · dumbbell.fill 근력 중량 kg · speedometer 페이스 /km · point.topleft.down.to.point.bottomright.curvepath.fill 거리 km · flame.fill 칼로리 kcal · timer 시간 · mountain.2.fill 고도 m. 원본 형식·단위와 선택 종류를 유지한다.

이력은 milestone flag.checkered.circle.fill, personalRecord trophy.fill, badgeUnlocked medal.fill, levelUp star.circle.fill 네 종류와 실제 제목·날짜·점수를 유지한다. 레벨·점수·잠금 badge는 실제 값만 표시한다. 월별 최대 30건이다.

기록 없음, 기간 기록 없음, 알림 로딩, 페이스 로딩/오류를 구분한다. pace는 유효한 실제 운동만 선형 연결하고 중복·이전 조회·취소를 기존대로 처리한다. 현재 최고는 전체 기간이다. 정적 깊이·광택은 장식이며 접근성에서 제외하고 연속 모션이 없다.
