실제 앱은 분석 가능한 지표만 표시한다. 히어로는 기존 제목·기록 날짜만 강조한다. 정적 시안은 막대의 채움 비율을 표시하지 않는다. 구현에서는 원래 계산을 유지한다. 전면 관절이 없으면 기존 No Symmetry Data 상태를 표시한다. Native 검증 전에는 완료 시안으로 보지 않는다. 밝은 표면의 상태 전경은 원래 색을 어둡게 조정하며 막대 색·계산은 유지한다.
