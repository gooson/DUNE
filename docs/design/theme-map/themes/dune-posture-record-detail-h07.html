밝은 화면의 상태 표기는 검정을 섞어 진하게, 어두운 화면은 원래 색으로 설명합니다. 실제 대비는 네이티브에서 확인해야 합니다. 표시된 지표 이름·상태색은 구성 설명용이며 실제 기록의 상태에 따라 달라집니다. 특정 사용자의 측정 결과나 의료 판정이 아닙니다. Front/Side 빈 틀은 사진이 없을 때의 자리표시자입니다. 실제 평가 항목이 비면 Assessment Details 제목과 기존 현지화 문구 Unable to measure가 표시됩니다. Duo MAX는 요청한 접힘 0°·펼침 180°를 각각 확인합니다. 기존 90° 포함 회귀는 장치 제어 문제로 미해결 상태를 보존하며 끝점 검증과 구분합니다. 모든 타일이 읽힌다는 뜻은 아니며 H07·P06 각각의 새 네이티브 캡처는 별도 검증 뒤 게시합니다. 큰 글씨의 기호는 예약한 사각형 안에서만 확대하고 신뢰도 숫자는 기본 전경으로 표시합니다. 여덟 평가 항목 전체의 수정 후 실제 대비·겹침 검증은 아직 남아 있습니다. 날짜·점수·사진·메모의 중립 캡션도 기본 전경으로 읽히게 하고, 어두운 화면의 강조색은 원래 값을 유지합니다. 새 그림의 대비 검증 전에는 보완 완료로 표시하지 않습니다.
