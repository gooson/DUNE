값의 의미

Muscles Hit = trainedCount/13이며 양수 주간 세트가 있는 그룹만 참여로 셉니다. muscles ready = recoveredCount/fatigueStates.count로 실제 제공된 상태만 분모에 둡니다. 없는 상태와 0세트는 훈련하거나 회복했다고 말하지 않습니다.

상태와 행동

Recovery/Sets 피커는 같은 앞/뒤 2D 몸체의 색과 범례만 바꿉니다. 근육 선택은 상세를 표시·해제하며 compact에서도 3D로 이동하지 않습니다. 3D Muscle Map 큐브 버튼은 보이되 비활성화하고 대상·상태·에셋은 보존합니다.

접근성

큰 글씨에서는 제목·피커·지도·선택 정보·목표/막대를 한 열로 읽고 모든 값과 버튼을 스크롤로 도달할 수 있어야 합니다. 원래 SVG 영역 버튼을 덮는 장식층은 두지 않습니다. 지도 색은 범례·텍스트 의미와 함께 전달합니다.

원본과 실제 증거

A04 소스 1f7f9900의 phone 기본·가슴 선택 PNG 두 장만 현재 before로 검증했습니다. iPad·Duo 접힘/펼침 before는 같은 소스·상태·기기 조건 확인 전까지 보류합니다. 이 브라우저 도식은 실제 캡처가 아니며 A03 변경 후 새 PNG로 actual 맵을 갱신합니다.
