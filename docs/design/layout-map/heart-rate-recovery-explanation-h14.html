H14 · 심박 회복 설명

운동 상세의 원래 Recovery 행에서 info.circle 버튼을 눌러 열리는 HeartRateRecoveryInfoSheet 배치 기준입니다. 테마 시안은 실제 앱 캡처가 아닙니다.

읽기 순서

  1. 원래 info.circle.fill 아이콘과 What is Heart Rate Recovery? 제목, 닫기 버튼. 기존 Recovery 행의 arrow.down.heart.fill을 설명용으로 재사용하되 실제 심박 데이터 도표로 해석하지 않는다.
  2. Definition: HRR₁의 첫 1분 심박 하강과 원래 설명 전체.
  3. How It's Measured: 운동 끝 최고 심박과 약 60초 후 심박의 차이를 설명하는 원래 문장 전체.
  4. Rating Guide: Good > 20 bpm, Normal 12–20 bpm, Low < 12 bpm. 원래 등급색 8pt 원형 표식과 레이블·범위를 유지.

행동·폭·상태

원래 medium/large 시스템 detent와 drag indicator, 전체 ScrollView를 보존한다. 닫기는 시트를 닫아 원래 운동 상세로 돌아간다. 원래 Recovery 행의 값·등급 및 정보 버튼 표시 조건(hrr1 > 0)은 변경하지 않는다.

일반 iPhone·iPad·Duo에서 최대 680pt 한 열. MAX에서는 info 아이콘과 48pt 소스 프레임으로 실제 최소 44pt 터치 영역을 확보하는 닫기를 첫 줄에 두고 제목을 카드 전체 폭의 다음 줄에 표시한다. 설명 문장은 세로 확장하고 범위는 레이블 아래로 쌓는다. 등급과 범위는 색에만 의존하지 않는다. 실제 기기·언어·AX 확인은 별도 네이티브 검증이 필요하다.
