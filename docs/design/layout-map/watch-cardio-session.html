Watch 유산소 세션 · 심박 존과 거리 통과

C01 메인 · C03 존 · C04 상세 화면의 상호작용 기준 시안. 색과 수치는 설명용이며 실제 캡처는 Watch 실제 화면 맵에서 확인한다.

  • C10 계단 진행 화면은 걸음·추정 거리·칼로리 증가나 무변화만으로 종료를 묻지 않는다. C19는 정확도 20m 이내 GPS에서 60초 이상·오차를 제외한 순이동 100m 이상·40걸음 이상을 확인한 뒤 표시하는 시스템 알림이다. 제목은 ‘계단 운동을 마칠까요?’, 설명은 ‘이동이 감지됐어요.’이며 ‘계속 운동’과 ‘운동 종료’를 제공한다. 타이머는 계속 흐르고 자동 종료는 없다. 계속 운동 또는 닫기를 선택하면 해당 세션에서 다시 묻지 않는다. 위치 권한이 없으면 C10을 그대로 유지한다. 이는 구현 기준이며 실제 캡처는 Watch 실제 화면 맵에서 확인한다.
  • 가로 스와이프로 선택한 유산소 페이지를 유지한다. 손목을 내렸다 다시 들어 올려도 C03을 C01로 되돌리지 않는다.
  • HealthKit 존 번호 0부터 시작하는 내부 인덱스를 화면 순서 1부터 표시한다. 설정된 존 개수와 막대 강조 위치를 일치시킨다.
  • 거리를 표시하는 유산소 운동에서 1km 경계마다 진동 한 번과 임시 배너를 제공한다. 운동 재개와 센서 값 흔들림으로 같은 경계를 반복 알리지 않는다.
  • 심박이 없거나 존이 활성화되지 않으면 기존 빈 상태를 유지한다. 큰 글씨에서는 본문 세로 스크롤을 허용하고 임시 배너는 주요 조작을 막지 않는다.
