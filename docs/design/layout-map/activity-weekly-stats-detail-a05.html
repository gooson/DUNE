원천과 기간

세 기간은 기존 rolling 7/30일 경계입니다. 비교 행은 comparison.previous의 실제 값과 시작·끝 날짜만 사용합니다. 근력 볼륨은 수동 운동의 유효한 무게×반복 수치이며 HealthKit 운동 시간·칼로리와 혼동하지 않습니다.

없는 값

이전 기간 또는 분모가 없으면 변화율을 만들지 않습니다. 이전 값 0과 기록 없음은 별도 의미입니다. Active Days는 현재 히어로에만 있습니다. 기존 로딩·오류·빈 상태 문구를 유지합니다.

상호작용과 접근성

기간 피커, 차트의 Duration/Sessions/Volume, 날짜 선택, 히스토리 가로 스크롤, 실제 운동 종류 분해, 새로고침과 Back을 유지합니다. 큰 글씨는 다섯 값과 네 비교 행을 세로로 읽고 차트 지표는 기존 메뉴 피커를 사용합니다.

증거 경계

이 도식의 기호는 실제 SF Symbol 렌더가 아닌 위치 표시입니다. 과거 A05 PNG는 revision 443a32ca라서 원본 672d5fdb before가 아닙니다. 원본과 after 기기 캡처는 별도 수집 후 실제 화면맵에만 기록합니다.
