P07 · 자세 좌우 비교

구현 기준 시안이다. 실제 기록·카메라 사진·SF Symbol 렌더링·앱 캡처가 아니다.

정보 순서

  1. 기존 Left vs Right Comparison 제목과 기록 날짜를 테마 히어로에 표시
  2. 실제로 분석된 각 SymmetryDetail을 원래 순서대로 카드에 표시: 지표 기호·이름·상태, 좌우 값과 단위, 기존 중심선 막대, 차이 요약
  3. 전면 관절이 없거나 분석 결과가 비면 기존 No Symmetry Data 상태와 설명을 표시
값 계약각 leftValue/rightValue와 원래 단위 포매터를 그대로 사용한다. 음수·0·소수점과 원래 좌우 순서를 보존한다. 막대 비율·higherSide·상태·차이 계산을 새 히어로나 시안에서 재정의하지 않는다. 정규화 점수나 비율을 새로 만들지 않는다.
동작·내비게이션기존 PostureDetailView의 좌우 비교 링크, 시스템 뒤로 가기, 날짜, 세 지표의 조건부 표시, 각 값과 측면 접근성 ID를 보존한다. 사진 확대·관절 표시·원본 기록 지표는 이전 상세 화면의 동작이며 P07 변경 범위 밖에서 그대로 둔다.
폭·큰 글씨스크롤 안쪽은 최대 680pt로 제한한다. 일반 크기는 좌우 값이 막대 양옆, 접근성 크기는 왼쪽 값 → 막대 → 오른쪽 값 순서다. MAX에서 값 전체와 단위가 한 줄로 읽히는 기존 full-frame 검사 계약을 유지한다.
검증기존 testPostureSymmetry와 opt-in testPostureSymmetryValuesAcrossFoldStatesAtMaximumTextSize의 정확한 셀렉터를 사용한다. iPhone·iPad·Duo 접힘/펼침 중 영향 기기와 새 PNG/AX를 확인한 후 실제 디자인맵을 갱신한다. 이 HTML만으로 통과를 주장하지 않는다.

상태 대비

밝은 카드의 상태 문구·아이콘은 원래 상태 색의 어두운 전경을 사용하고, 막대 채움·상태 이름·원래 기호는 유지한다. 최신 PNG로 대비를 다시 확인한다.
