# Siri 건강 정보 질의 시안

[기능별 인터랙티브 시안](../theme-map/themes/dune-siri-health-queries.html) · [기술 조사](../../brainstorms/2026-10-30-siri-health-queries-xcode-27-2-research.md)

운동·신체·수면·컨디션을 묻고 기록에 근거한 답변을 받는 14개 화면 제안이다. 기본안 V1과 비주얼 강조안 V2를 함께 보존하며 V2를 초기 표시한다. DUNE의 브라운·골드·아이보리와 모래 능선, 지표별 의미 색을 사용한다. 숫자와 단위·날짜를 먼저 읽고, 그래프와 출처를 이어서 읽는다.

시안의 질문·수치·날짜·음성 응답은 고정된 합성 예시다. Siri 시스템 UI의 외형을 앱이 교체할 수 있다는 제안이 아니며, 앱이 제공하는 응답 콘텐츠와 DUNE 내부 상세 화면을 설계한다. 실제 Siri 호출·낭독·HealthKit 조회·모델 실행·저장·공유는 수행하지 않는다. 어떤 자유 발화가 연결되는지는 별도의 한국어 실기기 검증 대상이다.

## 화면과 정보 순서

| ID | 기능 | 시각적 강조 | 정보 순서와 행동 |
|---|---|---|---|
| SQ01 | 최근 운동 | 입체 운동 기호와 큰 운동 시간 | 종목·날짜 → 시간·완료 세트 → 기록 열기 |
| SQ02 | 기간별 운동량 | 요일별 높이 막대와 큰 횟수 | 실제 조회 기간 → 운동 횟수 → 시간·거리·근력 볼륨 → 출처 |
| SQ03 | 근력 세트 | 바벨 모티프와 중량 | 운동명·날짜 → 실제 중량×횟수 → 완료 세트 표 → 기록 열기 |
| SQ04 | 개인 기록 | 골드 메달과 기록값 | 기록 기준 → 최고 중량 → 날짜·세트 → 달성 기록 열기 |
| SQ05 | 유산소 상세 | 주행 궤적과 거리 | 종목·날짜 → 거리 → 활동 시간·페이스·심박 → 기록 열기 |
| SQ06 | 신체 최신값 | 체중 중심 눈금과 항목별 수치 | 체중·측정일 → 체지방률·측정일 → 출처와 기록 열기 |
| SQ07 | 신체 변화 | 실제 표본 점과 끝점이 있는 선 | 비교 기준 → 체중 변화 → 양쪽 값·측정일 → 추세 열기 |
| SQ08 | 수면 | 달과 수면 단계 타임라인 | 수면 귀속 날짜 → 총수면 → 단계별 시간 → 수면 상세 |
| SQ09 | 컨디션·회복 | 104px 컨디션 링과 근거 수치 | 점수·계산일 → 기준선 대비 HRV/RHR → 근거 상세 |
| SQ10 | 지표 간 비교 | 분리된 운동·수면 차트 | 비교 기간 → 두 지표의 관측 변화 → 설명과 데이터 충족도 |
| SQ11 | 화면 문맥 질의 | 현재/이전 두 기록과 변화 연결 | 선택한 기록 → 비교 기준 → 중량·횟수·볼륨 → 비교 상세 |
| SQ12 | 메모 검색 | 검색어 강조와 원본 카드 | 질문 → 검색된 실제 예시 기록·날짜·메모 → 해당 기록 |
| SQ13 | 보고서 공유 | 종이 보고서와 미리보기 | 보고서 기간 → 포함 지표 → 공유 전 내용 확인 |
| SQ14 | 긴 종합 분석 | 단계별 진행과 근거 구성 | 실제 작업 상태 → 조회·집계·설명 단계 → 취소/완성 예시 보기 |

SQ01–SQ13은 일반 읽기 결과, SQ14는 장시간 처리 흐름이다. 현재 구현된 템플릿 열기와 습관 완료는 별도 기능으로 보존한다.

## 비주얼과 배치

V1은 평평한 카드·수치·직선형 그래프의 기본 비교안이다. V2는 골드 광원, 층이 있는 능선, 지표별 상징, 큰 수치, 점·축이 있는 차트와 분리된 근거 영역을 사용한다. 상징은 텍스트를 대신하지 않으며 상태나 점수를 새로 만들지 않는다. 목표가 없는 기록에 장식용 진행률을 표시하지 않는다. SQ09의 링만 실제 예시 점수 78/100을 표현한다.

Siri 요청 예시는 응답 콘텐츠와 분리한다. 응답 카드 안에는 앱 출처, 질문에 대한 결과, 필요한 날짜·기간·단위, 관련 기록 행동을 둔다. 전체 음성 문장은 카드 아래 독립적으로 펼칠 수 있어 소리 없이 검토할 수 있다. 시스템 음성 영역과 DUNE 콘텐츠 구분은 모식도이며 시스템 외곽 재현을 주장하지 않는다.

### 폭과 접근성

검토 폭은 iPhone 402px, Duo 접힘 466px, Duo 펼침 951px, iPad 1032px다. 좁은 폭에서는 한 열, 넓은 폭에서는 주 결과와 근거를 나란히 배치한다. 큰 글씨 160%·200%에서는 읽기 순서대로 한 열로 돌아가고 카드 높이가 자연스럽게 늘어난다. 그래프·기호·패딩은 글씨와 함께 확대하지 않는다. 본문은 줄임표로 잘라내지 않는다.

44px 이상 버튼은 DUNE의 검토 기준이며 CSS px는 브라우저 배치 연구 단위다. 네이티브 pt·Dynamic Type·VoiceOver 검증을 대신하지 않는다. 밝음·어두움과 Reduce Motion을 지원한다. 색만으로 비교·선택·누락 상태를 구분하지 않는다.

Watch 동반 시안은 최근 운동·체중·컨디션의 짧은 읽기 결과 3개다. 큰 값과 날짜·단위를 우선하고 긴 분석·검색 결과·공유 편집기를 Watch 화면에 축소 이식하지 않는다. 실제 Watch Siri 호스트·PCC 실행 가능 여부는 별도 검증한다.

## 상태 계약

| 상태 | 표시 | 보존하거나 숨길 내용 |
|---|---|---|
| 정상 | 기록과 날짜·출처, 펼칠 수 있는 음성 문장 | 모든 값은 합성 fixture |
| 조회 중 | 읽고 있는 대상과 단계 | 미확인 값을 0으로 표시하지 않음 |
| 확인 가능한 기록 없음 | “확인할 수 있는 기록이 없어요” | 성공한 질의의 빈 결과. 권한 거부로 추정하지 않음 |
| 잠금 해제 필요 | 잠금 기호와 필요한 다음 행동 | 민감 수치·메모·출처 미리보기 숨김 |
| AI 사용 불가 | 정형 조회로 제공 가능한 항목과 AI 설명 불가 상태 | 복합 설명·의미 검색의 완료 결과를 만들지 않음 |
| 오프라인 | 로컬 기록 조회 가능 범위와 분석 제한 | 캐시를 새로 조회한 기록처럼 표시하지 않음 |
| PCC 한도 도달 | 읽기 가능한 원본과 현재 분석 한도 | 임의 재시도·업그레이드 강요 없음 |
| 분석 취소 | “분석을 취소했어요” | 기존 기록 유지. 완료 보고서 표시 안 함 |

비AI fallback 시안은 이미 받은 합성 기록의 정형 표현만 보여준다. 실제 구현에서는 접근·신선도 검사가 선행되어야 한다. 체중 감소를 자동으로 건강 개선으로 평가하지 않으며, 운동과 수면의 동반 변화를 인과관계로 단정하지 않는다. 75kg×8회×3세트와 80kg×8회×3세트의 볼륨은 각각 1,800kg·1,920kg이며 +120kg/+6.7%다.

## 시안의 동작

상단에서 기능군, V1/V2, 밝음/어두움, 폭, 글씨, 상태를 전환한다. 각 기능의 근거와 음성 문장을 펼칠 수 있고, 기록·비교·보고서 버튼은 합성 데이터의 상세 대화상자를 연다. 공유는 내용 미리보기까지만 제공하며 기기 공유 시트나 외부 전송을 실행하지 않는다. SQ14 취소는 해당 카드의 로컬 표시 상태만 바꾼다.

## 검증과 디자인맵 등록

브라우저 검사와 출처는 `themes/assets/siri-health-queries-qa.cjs`, `siri-health-queries-qa.json`, 기능별 PNG에 보존한다. 테마 맵의 studies와 레이아웃 맵에서 연결한다. 모든 PNG는 HTML 시안 렌더이며 실제 앱 캡처가 아니다.

2026-10-30 브라우저 검증: V2의 5개 폭×3개 글씨×2개 표면, V1의 좁은 폭·큰 글씨, 390px 브라우저 viewport를 확인했다. 14개 화면에 대해 가로 넘침·텍스트 잘림·44px 조작 높이를 검사했고, 7개 대체 상태와 넓은 폭 오프라인 fallback의 겹침을 확인했다. 근거/음성 펼침 28개, 상세 미리보기 14개와 닫은 뒤 포커스 복귀, 실제 설정 컨트롤, 분석 취소가 통과했다. 정상 기능별 14장과 개요·다크·큰 글씨·Duo 펼침·V1·잠금의 총 20장 PNG를 보존하고 정상 14개를 육안 대조했다. 검증은 HTML과 합성 데이터에 한정한다.

앱 코드를 바꾸지 않으므로 실제 화면 디자인맵의 기존 PNG를 대체하지 않는다. 구현 단계에서 SQ01–SQ14 중 영향받는 화면·상태·기기를 확정하고 새 네이티브 캡처를 별도로 등록한다. 한국어 단일 발화 라우팅, 낭독, HealthKit, AI/PCC, 인증, 기기 간 문맥·공유는 이번 브라우저 검증에 포함되지 않는다.
