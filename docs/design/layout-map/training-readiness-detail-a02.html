화면 순서

원래 Activity 진입·내비게이션을 유지하고, 불투명 점수 히어로 → 시간 조정 → 기간/범위/추세/차트/요약 한 카드 → 비-일간 세 원천 추세 → 원래 점수 구성 → 계산 설명으로 읽습니다. 이전/다음 날짜 화살표는 ViewModel 계약이 없으므로 넣지 않습니다.

값의 의미

현재 점수는 다섯 계산 구성의 결과입니다. 구성 점수 72 같은 예시는 센서 수신의 증거가 아닙니다. 실제 계산은 중립 대체값을 포함할 수 있습니다. 막대 길이는 구성 점수/100이고 30% 같은 표시는 가중치입니다.

Day는 실제 rolling readiness snapshot입니다. W/M/6M/Y 이력은 HRV·RHR·수면 세 원천의 근사치이며 현재 다섯 구성 공식을 과거에 재계산한 값으로 말하지 않습니다.

상태와 폭

nil 준비도에서는 기존 “Need More Data”만, 차트 조회 중에는 기존 로딩 표시만, 보정 중이면 실제 점수와 “Calibrating” 및 계산 bullet을 표시합니다. 본문은 중앙 정렬된 최대 680pt 폭입니다. iPhone·Duo 접힘과 최대 글씨에서는 점수를 링 밖으로 빼고 구성 행과 차트 요약을 세로로 전환할 수 있습니다. iPad·Duo 펼침도 수치·가중치·설명을 생략하지 않습니다.
