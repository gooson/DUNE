# T06 건강 지표 상세 개편 계약

검토 시안의16개 T06 변형은 [화면별 보존 JSON](../theme-map/assets/health-metric-detail/reviewed-proposal.json)에 보존한다. [표현 방향](../theme-map/themes/dune-health-metric-detail-redesign.html)은 예시 기록의 브라우저 시안이며 실제 앱 캡처가 아니다. 원본 스냅샷과 이후 미확인 변경을 구분한다.

1. 원래 지표 아이콘과 실제 수치/단위를 강조한 일관된 불투명 히어로. 아이콘은 어두운 표면에서 읽히는 팔레트 전경색을 사용하고, 카테고리색은 차트와 지표 행에 유지한다. kg/BMI/ms를100점 점수로 바꾸거나 임의 링 진행률로 표현하지 않는다. 기존 숫자 정밀도·체중 단위·수면 시간·산소 포화도 변환·체온 부호를 보존한다.
2. 한 추세 카드: 제목/추세선 → 일/주/월/6개월/년 → 이전/가시 날짜/다음 → 실제 차트 → 같은 구간의 요약. 날짜 중복을 없애고 선택/스크롤/기간 이동과 이력 제한을 보존한다. 차트의 자체 ScaledMetric 높이를 외부 고정 frame으로 누르지 않는다.
3. 지표 행은 같은 위치의 원래 아이콘과 필요한 단위를 표시한다. 카드 간격은 명시적 DS 간격, 큰 글씨는 단일열과 줄바꿈, 조작은44pt 이상. 원래 하이라이트·최근 표본·전체 데이터와 수면4분석/운동 거리·시간 분기를 유지한다.
4. 체중/BMI는 사용자가 명시적으로 고른 연령 구간·자료상 성별에 해당하는 미국 NHANES2021–2023 조사 평균을 선택적으로 비교한다. 프로필·국적·건강 목표를 추정하지 않는다. 단위가 같은 현재값/평균/차이와 출처를 표시하고 평균 이상/이하를 건강 판정 색으로 채점하지 않는다.
5. 체지방률은 별도 후속 작업으로 미국 성인 NHANES 1999–2004 DXA 조사 평균을 선택적으로 제공한다. Table 3의 실제 20년 연령 구간·자료상 성별·측정 방식과 연도를 명시하고, 개인 기록과 평균은 원래 지표 아이콘이 있는 별도 값 행으로 표시한다. 측정 방식 차이 안내를 값보다 먼저 두며 차이·건강 판정색·백분위·한국/인바디 기준을 만들지 않는다. 체중/BMI의 2021–2023 경로와 제지방량 미지원은 보존한다. [후속 구현 계획](../../plans/2026-11-04-t06-body-fat-survey-reference.md)의 단위·선택·실제 캡처 게이트를 따른다. 2026-11-05 [체지방 DXA 실제 화면 갤러리](../full-redesign-map/review/t06-body-fat-dxa-native-2026-11-05/index.html)에 선택 검사 5건의 32개 PNG/AX 쌍을 별도로 연결한다. Duo 접힘 일반 case는 실패한 2건 집계 안에서 Passed였으며 최대 글씨 case는 최종 소스에서 별도 Passed였다. 기존 HRV 대표 T06 이미지는 유지한다.
6. 기존 T06 네 기기 이미지는 Sleep이므로 HRV 전후 비교에 재사용하지 않는다. 전용 기기의 정확한 metric-detail-screen-* AX와 제목/단위를 확인해 새 기준/개편 캡처를 만든다. 기본 맵의 대표는 HRV, 나머지16변형/운동단위 분기는 별도 식별표와 갤러리에 연결한다. iPhone/iPad/Duo 접힘·펼침의 실제 출처와 미검증을 구분한다.

7. 실제 최대 접근성 글씨 캡처에서 확인한 면적 차트 주간 요일 겹침은, 해당 크기에서 달력 기준 주당 두 요일 눈금으로 완화한다. 전체 날짜 범위·표본·선택·스크롤·일반 글씨 눈금은 유지하며, 일반 크기의 점선 차트 날짜 누락과는 별도 검증한다.
