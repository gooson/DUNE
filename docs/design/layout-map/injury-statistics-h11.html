H11 · 부상 통계

H09의 원래 통계 버튼이 여는 InjuryStatisticsView의 배치 계약입니다. 테마 방향 시안은 앱 캡처가 아닙니다.

읽기 순서

  1. 시스템 제목 Injury Statistics와 뒤로 가기
  2. Overview: 총 기록 건수를 첫 강조 수치로, 현재 활성 건수를 같은 강조 면의 두 번째 수치로 표시
  3. 평균 회복일과 최장 회복일을 별도 보조 타일에 표시
  4. 기록된 부위가 있을 때 Frequency by Body Part의 실제 부위·건수 목록과 기존 가로 막대 그래프
  5. 비교 데이터가 있을 때 Exercise Volume Impact의 원래 설명과 부상별 Before/During/After 막대

데이터·상태

총수·활성수·부위별 빈도·완료된 부상의 평균/최장 회복일은 원래 InjuryStatisticsService 결과를 그대로 표시합니다. 평균은 기존 정수 반올림, 일 단위는 기존 d 표기를 유지합니다. 완료 부상이 없으면 회복값은 —로 표시합니다. 빈 빈도와 빈 비교 데이터의 섹션은 기존처럼 생략합니다. After가 없는 활성 부상은 기존 —를 유지하며 0회와 구분합니다.

운동 비교는 각 부상 전 14일, 부상 기간, 종료 후 14일의 실제 횟수입니다. 세 막대의 상대 높이와 심각도 아이콘·색은 보존합니다. 수치나 의료적 의미를 새로 추정하지 않습니다.

폭과 접근성

일반 iPhone과 iPad·Duo에서 같은 한 열의 섹션을 읽습니다. 접근성 글씨 크기에서는 Overview의 두 수치와 회복 타일이 각각 세로로 쌓입니다. 아이콘은 제목을 대체하지 않으며 수치·상태는 색에만 의존하지 않습니다. 실제 앱의 기기·MAX 검증과 캡처는 별도 증거가 필요합니다.

H11 실제 앱 검증

영어·Light의 iPhone·iPad·Duo 접힘·펼침 기본 글씨와 Duo 접힘 최대 글씨를 검토했다. 시안과 실제 기록은 구분하며 실제 PNG·접근성 계층·실행 소스와 제한에서 출처를 확인한다.
