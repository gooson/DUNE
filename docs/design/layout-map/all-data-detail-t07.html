LimitedHealthHistoryNotice가 날짜 섹션 앞에 나온다. 보이는 행은 허용된 기간 안의 실제 조회 결과다.

같은 notice와 “No data in the available range.”를 함께 표시한다. 제한 기간 밖의 데이터가 없다고 단정하지 않는다.

네이티브 배치·행동

  1. 기존 영어 내비게이션 제목과 시스템 back을 유지한다. 상단에는 원래 아이콘, category.displayName, 번역된 기존 “History”만 둔다. 수치·마지막 업데이트·전체 건수·평균·필터는 추가하지 않는다.
  2. 불투명 ScoreHeroPalette 표면과 전경 대비를 T06과 공유한다. 범주 색은 배경 능선과 작은 강조에 사용하며 아이콘은 팔레트 전경색으로 읽힌다. 정적 DetailWaveBackground를 유지한다.
  3. 기존 .insetGrouped List에서 섹션은 point.date의 달력 날짜, 행의 시각은 point.displayDate ?? point.date, 값은 기존 formattedValue를 사용한다. 수면은 비각성 시간만 합산한다.
  4. 일반 크기에서는 시각과 값을 한 행에 둔다. 고정 60pt 시각 폭을 없애고 좁은 폭·최대 접근성 크기에서는 시각 위, 값 아래로 쌓는다. 값·단위는 줄바꿈으로 끝까지 읽히고, 행의 VoiceOver 레이블은 시간·값을 함께 전한다.
  5. iPhone·Duo 접힘은 한 열. iPad·Duo 펼침은 본문 가독 폭을 약 680–760pt 안에서 제한해 지나치게 긴 행을 피한다. 실제 List의 스크롤·페이징·notice·empty AXID all-data-screen-*/all-data-empty-state를 보존한다.

이 HTML은 구현 전 방향이다. 변경 전 원본 16범주와 변경 후 동일 fixture의 실제 화면 비교는 네이티브 검증 및 실제 화면 맵에서만 판정한다.
