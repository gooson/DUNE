H10 · 부상 기록 상세

구현 기준 시안입니다. 실제 앱 캡처나 의료 판정이 아닙니다. DUNE 표현 · 배치 맵

정보 순서

  1. 기존 부상 부위·좌우, 심각도 기호·이름, Active/Recovered
  2. 히어로에서 원래 durationDays를 큰 글씨로 표시; 심각도 설명 보존
  3. Timeline: 시작·종료 또는 Ongoing·기록 시각을 각 한 번 표시
  4. Memo: 실제 메모 또는 원래 No memo

폭·큰 글씨·행동

한 열 ScrollView, HeroCard와 StandardCard 사이 16pt 이상. 큰 글씨는 날짜 행을 세로로 쌓고 각 필드 전체를 스크롤로 읽습니다. 기간은 히어로에 한 번만 두며 Timeline에서 반복하지 않습니다.

시스템 뒤로, 활성 기록의 Mark Recovered, Edit → 기존 Form → Save, nil 기록의 원래 unavailable 화면을 유지합니다. 새 입력 검증·모델·통계를 만들지 않습니다. H08의 보류된 Add 경로를 이번 작업에서 실행하지 않습니다.

실제 검증 상태

아직 미구현·미검증 상태입니다. 네 프로필의 실제 PNG/AX는 구현 후 별도로 갱신합니다. H09 역사적 이미지를 H10의 새 증거로 사용하지 않습니다.

이력 행에서 여는 경로

H09의 기록 행은 저장된 기록 ID를 선택 상태로 전달하고 이 상세를 엽니다. 상세는 현재 SwiftData 기록을 다시 조회하여 원래 값과 기록 없음 화면을 유지합니다. 회복 처리로 기록이 Active에서 Recovered 섹션으로 이동해도 상세·뒤로 경로가 유지되어야 합니다. iPad 첫 탭과 편집·회복·뒤로를 실제 UI 검사에서 확인합니다.
