# 기록 진입 상단 내비게이션 배치안

[4탭 시안](../theme-map/themes/dune-final-four-tab.html) · [4탭 레이아웃 맵](index.html)

Activity·Wellness·Life의 기록 추가 행동은 화면을 내려도 찾을 수 있도록 **상단 제목 오른쪽 44pt 추가 버튼**에 둔다. 히어로 카드는 현재 상태와 상세 진입에 집중한다. Today의 알림·설정은 현재 상단 배치를 유지한다. 탭 바는 네 화면 전환에만 사용한다.

| 화면·상태 | 상단 버튼 | 누른 뒤 경로 | 본문 |
|---|---|---|---|
| A01 Activity · 일반·로딩·기록 없음 | 운동 추가 | 운동 찾기 → 검색·최근 운동·전체 운동 → 운동 시작/기록 | 준비도 히어로의 운동 기록 버튼 제거. 로딩 중에도 상단 추가 버튼 유지. |
| H01 Wellness · 일반·기록 없음 | 기록 추가 | 신체 기록, 부상 기록, 자세 평가, 실시간 자세 분석 메뉴. 신체 기록은 기존 입력 화면으로 이동 | 예측 카드 아래의 신체 기록 버튼과 기록 없음 카드의 중복 버튼 제거. |
| L01 Life · 일반·습관 없음 | 습관 추가 | 새 습관 또는 템플릿에서 만들기 메뉴 | 습관 없음 히어로의 습관 추가 버튼과 목록 끝 중복 추가 링크 제거. |

각 상단 버튼에는 보이는 더하기 아이콘과 화면별 VoiceOver 이름을 둔다. 메뉴는 탭별 행동만 표시하고, 뒤로 가면 원래 탭의 스크롤 위치로 돌아온다. iPhone·Duo 접힘에서는 상단 오른쪽, iPad·Duo 펼침에서도 제목과 함께 상단에 둔다. 큰 글씨에서 제목이 길어져도 44pt 터치 영역을 유지한다. 빈 상태에서도 같은 진입을 제공하고 카드에는 현재 상태 설명을 남긴다.

이 문서는 **목표 시안**이다. 실제 앱의 Activity·Wellness·Life에는 이미 상단 추가 도구가 있으므로 구현 시 중복된 본문 행동을 제거하고 목적지가 동일한지 확인한다. 시안의 추가 메뉴와 입력 화면은 배치 예시이며 실제 저장을 수행하지 않는다.
