Watch 홈 · 운동 카드 스크롤

H01 루틴 · H02 최근 · H03 선호/인기 카드의 동작 기준 시안. 실제 앱 캡처는 Watch 실제 화면 맵에서 확인한다.

  • 정보 순서: 구분 → 운동/루틴 이름과 세부 정보 → 시작 행동.
  • 스크롤 추적·감속·프로그램 이동 중에는 시작 표시만 투명하게 한다. 공간은 유지해 카드 높이와 스크롤 위치를 고정한다.
  • 멈춘 뒤 시작 표시가 다시 나타난다. 카드 선택은 기존 운동 미리보기로 이동한다.
  • H04 전체 운동 탐색, H05 빈 상태는 기존 행동을 유지한다. 큰 글씨에서도 이름과 세부 정보가 시작 공간을 침범하지 않도록 스크롤 높이를 허용한다.
