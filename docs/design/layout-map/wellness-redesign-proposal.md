# Wellness 개편 시안 · Flow / Compact

[전체 시안 열기](../theme-map/themes/dune-wellness-redesign.html) · [Flow 첫 화면](../theme-map/themes/assets/wellness-flow-light.png) · [Flow 전체](../theme-map/themes/assets/wellness-flow-light-full.png) · [어두움](../theme-map/themes/assets/wellness-flow-dark-full.png) · [큰 글씨](../theme-map/themes/assets/wellness-flow-large.png) · [넓은 화면](../theme-map/themes/assets/wellness-flow-wide.png)

H01 웰니스 탭의 **구현 전 제안**이다. 사용자 요청에 따라 기존 개편 기록·현재 SwiftUI·점수 모델을 먼저 대조했다. 권장안 Flow와 현재 순서를 정돈한 Compact를 비교한다. 모든 수치·시각·사진 평가·부상은 예시이며 브라우저 PNG는 실제 앱 캡처가 아니다. 앱 구현 방향이 선택되기 전까지 현재 네이티브 배치와 실제 화면맵을 덮어쓰지 않는다.

## 확인한 개편 이력

Today·Activity는 이미 개편한 앱 화면이 있고, Wellness는 제목 통일 외에는 기존 124pt 링/점수·수면 묶음이 남아 있다. **124pt에서104pt로 바꾸는 것은 이번 제안**이며 앱 적용 완료가 아니다. Life 역시 링 전체를 이번 작업에서 변경하지 않는다.

## 정보 순서 결정

권장 Flow는 **현재 상태 → 최근 수면 → 오늘 밤 준비 → 건강 지표 → 신체 변화 → 자세·부상 관리**다. 웰니스는 운동 선택보다 수면과 몸의 기록을 읽는 목적이 크므로 Activity의 카드 내용을 복사하지 않고 읽기 위계만 이어간다.

| 순서 | 카드 | 배치·행동과 이유 |
|---|---|---|
| 1 | WELLNESS | 104px 링·짧은 해석·수면/컨디션/신체/자세 네 점수. 의미가 다른 수면 그래프를 분리해 첫 카드의 목적을 하나로 줄인다. 계산 설명은 펼침. |
| 2 | 최근 수면 | 최근 날짜·시간을 가장 크게, 유효 표본 평균은 보조로 표시. 7일 시간 막대와 각 날짜. 전체 제목은 기존 수면 상세로 이동한다. |
| 3 | 오늘 밤 수면 | 수면 다음에 예측을 배치해 관측→미래의 흐름을 만든다. 예측 점수·신뢰도·짧은 팁, 사용 기록 펼침. 두 번째 큰 링을 더하지 않는다. |
| 조건부 | 관리 중인 부상 | Flow에서 활성 부상이 있으면 예측 다음으로 올린다. 직접 기록한 부위·시작일·수정 행동을 표시한다. ‘부상 없음’을 건강상 이상 없음으로 해석하지 않는다. |
| 4 | 건강 지표 | HRV/안정 시 심박 → 심박/산소 → 호흡/온도. 낮은 미니 그래프와 측정 시각. 심폐 체력/심박 회복은 펼침으로 읽는다. 덜 자주 갱신되는 신체 기록보다 앞에 둔다. |
| 5 | 신체 변화 | 체중/체지방률/제지방량/BMI를 2×2 항목 패널로 표시한다. 유효한 비교 기록이 있는 경우 각각 현재값·변화량·이전값·측정일을 읽는다. 제목은 이력으로, 각 항목은 해당 상세로, 기록 추가는 독립 행동. |
| 6 | Watch 자세 | 관측 시간·수신 시각·스트레칭 알림을 표시한다. 사진 평가와 별도 카드로 유지한다. |
| 7 | 자세 평가 | 중립적인 촬영 안내 프레임, 큰 사진 평가 점수·100점 막대·평가일을 구분한다. 촬영/실시간 확인은 같은 높이의 두 행동. 사진이 없는 경우 수치 대신 시작 안내. |
| 8 | 부상 기록 | 등록 항목이 없을 때 하단에 짧은 안내와 기록 추가. 활성 부상은 위 조건부 위치로 이동해 중복하지 않는다. |

Compact는 **점수+수면 묶음 → 예측 → 신체 → 건강 지표 → Watch → 사진 자세 → 부상**으로 현행 묶음·순서를 보존한다. V1은 밀도와 공통 표현 정돈, V2 Flow는 정보 순서·카드 경계 개선이다. 현재 수면을 Active Indicators에서 다시 보여 주는 중복은 두 방향 모두 제거하되 수면 상세 진입은 유지한다. Flow를 기본으로 제시하며 최종 선택은 아직 기록하지 않았다.

## 데이터 의미와 구현 계약

| 표시 | 확인한 실제 원천 | 지켜야 할 의미 |
|---|---|---|
| 웰니스/근거 | `WellnessScore`, `CalculateWellnessScoreUseCase`, `WellnessViewModel` | 수면35%·컨디션30%·신체20%·자세15%, 누락 항목 가중치 재분배 및 시간대 보정. 네 막대는 각각 0–100점이며 비중/생체 원시 단위가 아니다. 새 계산식 없음. |
| 예시79점 | 수면83·컨디션64·신체75·자세80 | 가중 평균75.8에 오전09:41 보정+3, 반올림79. 일부 누락 예시는 신체 제외78, 신체만78, 수면 한 항목만86. 링 경계 확인용 점수 조절은 읽기 모형이며 근거 재계산 기능이 아니다. |
| 수면 시간 | `sleepDetailTrend`, 수면 `HealthMetric` | 10.21–10.27의398/420/435/405/441/430/432분. 최근7시간12분, 평균423분=7시간3분. 유효 표본2개 미만은 평균 없음. 결측일 막대 채우기/0시간 대체 없음. 수면 단계는 상세의 실제 기록을 유지하며 새로 만들지 않는다. |
| 수면 예측 | `SleepQualityPrediction`, `recomputeSleepPrediction` | 예시78·보통 신뢰도는 관측 점수와 별도 표시. 모델의 실제 factor/tips만 사용한다. 현재 ‘취침 일관성’ 입력은 수면 **시간 변동** 대리값이고 운동 강도는 호출 기본값일 수 있다. 실제 취침 시각·실측 운동 효과·목표 취침 시간으로 확대하지 않는다. |
| 건강 지표 | `VitalCardData`, `HealthMetric` | 단위·최근 날짜·오래됨/기준선 상태를 유지한다. HRV/안정 시 심박은 서로 다른 값이며 묶음 때문에 합산하지 않는다. 손목 온도는 개인 기준선 대비 변화. 산소98%는 fraction0.98 변환 후 값. 미니 그래프는 유효 표본2개 이상일 때만 표시한다. |
| 신체 | `physicalCards`, `BodyHistoryLinkView`, `BodyCompositionViewModel` | 현재 체중만 `change`를 제공한다. 체지방률은 이력 그래프만, BMI/제지방량은 최신값만 제공한다. 네 항목 변화 비교는 아래의 **추가 제안 상태**이며 실제 앱에 이미 구현된 표시가 아니다. 유효 비교 표본이 있을 때만 표시하고 숫자 방향을 건강상 좋음/나쁨으로 판정하지 않는다. |
| Watch | `DailyPostureSummary`, `WatchPostureSummaryCard` | `sedentaryMinutes`, `walkingMinutes`, `stretchRemindersTriggered`; 유효한 `averageGaitScore`가 있을 때 해당 행도 유지한다. 하루 전체 시간/앉은 비율을 새로 만들지 않는다. 미설치·꺼짐·미착용/수신 없음은 각각 구분할 후속 앱 상태다. |
| 사진 평가·부상 | `PostureAssessmentLinkView`, `WellnessInjuryBannerView` | 사진 평가 날짜·점수와 Watch 기록을 혼합하지 않는다. 부상 입력/수정은 기존 경로. 활성 부상이 한 개보다 많으면 실제 목록을 보존한다. |

지표 그룹 순서는 의미를 기준으로 고정하되 fresh/stale 구분을 제거하지 않는다. 항목별 미수신/접근 문제를0점 또는 ‘평소 범위’로 채우지 않는다. 표본이 없는 상세의 chevron을 비활성화한다. 현재 앱은 최신 수신일 기준으로 정렬하고 있으므로 고정 그룹화·수면 중복 제거·이력 위치 변경은 모두 향후 앱 구현 항목이다.

## 상태·크기·행동

- 기본/일부 조회 누락/첫 수면1일/신체 기록만/수면·지표가3일 전/Watch 모니터링 꺼짐/활성 부상/전체 기록 없음/접근 확인/클라우드 동기화 대기/초기 로딩을 제공한다. 기록 없음만으로 HealthKit 읽기 권한 거부를 단정하지 않는다.
- 로딩·전체 없음·접근 확인·동기화 대기는 가짜 점수·채운 막대·가짜 추세를 표시하지 않는다. 상단+와 수동 신체/부상/자세 진입을 유지한다. 신체만 있는 상태의 수면·예측은 안내다. 향후 앱에서 비어 있는 안내의 반복을 더 줄일 여지가 있다.
- 상단 지표 비교와+메뉴는 유지한다. 유효 지표2개 미만에서는 비교 비활성. 비교 상세에서는 서로 다른 단위의 축을 나누며 현재 미리보기 상세는 경로 확인용이다. 입력 확인은 브라우저 로컬 동작이고 실제 기록 저장/카메라/HealthKit 설정 전환은 수행하지 않는다.
- 폭320/402/466/951/1032px, 브라우저 글씨100/125/160/200%, 밝음/어두움을 비교한다. 큰 글씨는 점수를 링 밖에 두고 막대를 다음 줄에 배치하며 모든 지표·신체·자세 수치를 한 열로 읽는다. 상태 배지는 제목 다음 줄로 내려 낱글자 줄바꿈을 피한다. 그래프 높이·링 기하를 글씨와 함께 늘리지 않는다.
- 넓은 화면의 히어로는 점수와 근거 두 열, 그 아래는 수면/예측·건강/신체·Watch/평가를 짝지어 표시한다. 기본 읽기 순서를 DOM 순서로 유지하고 높이가 다른 카드의 본문을 늘려 맞추지 않는다. 이는 브라우저 배치이며 네이티브에서는 기기 이름보다 실제 size class/접근성 글씨를 기준으로 전환한다.
- 날짜·단위·색 외의 이름·수치를 함께 제공한다. 그래프에 접근성 요약, 버튼에 이름, 목적지가 있는 제목에 실제 클릭 영역을 둔다. [Apple 차트 지침](https://developer.apple.com/design/human-interface-guidelines/charts)의 위계·맥락·접근성 원칙을 참고했다. 네이티브 VoiceOver 합격을 뜻하지 않는다.

최신 개선본은 두 방향×폭5종×글씨4종×밝기2종의80개 배치에서 가로 넘침 없음·104px 원형·외부 점수 전환·카드 순서를 확인했다. 두 방향의 추가10개 기록 상태를320px/200%/다크의20건으로 확인했다. 링0/1/99/100, 상세·추가·비교·로컬 입력 확인·한 표본 수면 상세, 신체 네 항목의 값/정확한 비교 단위/비교 없음/상세 일치, 평가 없음의 점수 미표시 등60건을 확인했다. 제목의 오른쪽 빈 영역에서도 상세 진입 후 복귀한다.

초기 시안에서는 긴 PNG의 iframe 밖 페인트 누락과 캡처용 globals 주입 누락을 보정했다. [초기 검사 이력](../theme-map/themes/assets/wellness-initial-qa.json)은 당시80/20/52건의 기록이다. 이번 개선본의80/20/60건과 구분한다. 최신 검사 중 스크린샷 저장만 스크롤 후 clip 좌표 때문에 중단되어 document 좌표로 고쳤다. 소스 해시를 대조해 이미 통과한 검사는 재사용하고 캡처만 재실행했다. 네 카드와 밝음/어두움·전체·큰 글씨를 육안 확인했다.

마지막 자세 안내 아이콘은 host의16px 규칙으로 너무 작게 표시돼46×64px로 수정했다. 정확히 그 CSS 규칙만 달라졌음을 소스 해시로 확인한 뒤 두 방향×320/402/1032px×기본/200%×밝음/어두움의24개 배치에서 크기·넘침·큰 글씨 도식 숨김을 확인했다. 영향받은 전체4장/자세2장을 갱신했고 standalone의 실행 오류 없음도 확인했다. 다른 배치/상태/동작 검사는 변경 없는 범위로 재사용했다.

### 신체 항목별 변화의 추가 제안

화면에 `비교 기록이 있는 경우 · 예시`와 **10.20→10.27의7일 비교**를 명시한다. 다음 값은 사용자 요청의 항목별 변화 표시를 보기 위한 고정 fixture다.

| 항목 | 10.20 | 10.27 | 변화 표시 |
|---|---|---|---|
| 체중 | 68.6kg | 68.4kg | −0.2kg |
| 체지방률 | 18.6% | 18.2% | −0.4%p · 상대 변화율%와 구분 |
| 제지방량 | 55.8kg | 55.9kg | +0.1kg |
| BMI | 22.2 | 22.1 | −0.1 · 단위 없음 |

현재 앱은 체중 변화만 직접 제공한다. 체지방률의 비교값을 내보내고 BMI/제지방량의 과거 이력을 조회·실제 측정일로 매칭하는 후속 데이터 연결이 필요하다. 체중 변화나 신체 점수를 나머지 항목 변화량으로 재사용하지 않는다. 체중/체지방률의 작은 그래프는 **10.21–10.27**의 최근 기록으로, 비교 기준일10.20과 다르다. BMI/제지방량 그래프는 미제공 상태 그대로 두었다.

`신체 비교 기록 있음`을 끄면 네 항목의 최신값·측정일은 유지하면서 변화량/이전값만 `비교 기록 없음`으로 바뀐다. 별도로 유효한 체중·체지방률 추세는 계속 표시한다. 실제 구현에서는 항목별로 비교 표본 유무를 판정해야 하며 전체 토글은 시안 비교 편의를 위한 것이다.0의 유효 변화와 비교 표본 없음도 구분한다.
