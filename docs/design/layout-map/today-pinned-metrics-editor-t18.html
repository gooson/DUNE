정적 배치 계약. 예시 아이콘은 실제 선택 상태나 앱 캡처가 아니다.

공통 셸·동작

Today 지표 편집 버튼 → PinnedMetricsEditorView 네이티브 List. 원래 Edit Pinned Metrics 제목, Cancel 취소, Done 저장·닫기, 선택 시트 진입과 닫기를 유지한다. `workingSelection`은 취소 전까지 원본 바인딩을 바꾸지 않는다.

Top 6 Metrics

현재 `TodayPinnedMetricsStore.maxPinnedCount = 6`을 설명하는 제목과 실제 현재 선택된 지표 아이콘만 보여 준다. 접근성 글자 크기에서 미리보기 격자는 최소 80pt 칸으로 재배치하고, 아이콘 배지는 실제 기호 크기만큼 확장한다. 앱에서는 상한 값을 동적으로 보간한다. 수치·완료율·의료 상태는 만들지 않는다. 기존 footer “Select up to 6 metrics shown at the top of Today.”를 목록 뒤에 둔다.

선택 목록

기존 `allowedCategories` 순서와 각 카테고리의 원래 SF Symbol·표시 이름·테마 색, 선택 체크표시를 보존한다. 미선택 행은 상한 도달 시 비활성화하고, 선택된 행은 해제할 수 있다.
