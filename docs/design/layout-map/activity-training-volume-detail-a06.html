원천·상태 계약

  • 원래 Activity 진입, 시스템 Back, 1W/1M/3M/6M, 기간 재조회 및 도넛 세 모드를 유지한다. 1W의 5는 주간 활동일 목표다. 1M/3M/6M에는 실제 선택 기간 활동일 건수만 표시하고 5일은 별도 주간 참고 chip으로 둔다. 기간 목표나 N/5 진행을 뜻하지 않으며 A03 근육 세트 목표도 아니다.
  • 이전 값은 nullable previous와 원래 포맷을 사용한다. 날짜는 이전 기간 요약에서 한 번만 표시하고 분모 0에 임의의 0%를 붙이지 않는다.
  • 일별 막대는 kg가 아니라 운동 시간(분)이다. 보이는 제목과 AX label을 Daily Duration으로 바꾸되 그래프·선택·스크롤·probe ID는 유지한다. 수동 kg×reps와 HK 운동 시간은 서로 다른 원천이다.
  • 조건부 Training Load/RPE, 빈 상태, 운동 종류 목록과 네 기간 상세 링크를 유지한다. 일별 차트가 비면 “No daily workout duration for this period”를 en/ko/ja로 표시한다. A03 13근육 세트/목표 막대를 데이터 원천 없이 A06에 가져오지 않는다.
  • iPhone/Duo 접힘은 한 열, iPad/Duo 펼침은 읽기 폭을 제한한다. 최대 글씨는 카드 높이를 늘려 값·단위와 조작을 보존한다. SF Symbol 이름 calendar/timer/flame.fill/figure.strengthtraining.traditional은 네이티브 선택 예정이며 이 웹 기호는 대체 그림이다.

AX 계약: 1W는 “해당 주 활동일 N, 주간 목표 5일”, 1M/3M/6M은 “선택 기간 활동일 N”과 별도 “주간 목표 5일”로 읽는다. 숫자 예시는 원천 데이터가 아니다.
