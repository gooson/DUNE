# Activity·Life 히어로 개선 시안

[비교 시안](../theme-map/themes/dune-activity-life-heroes.html). 사용자 사진의 큰 빈 공간을 줄이고 상태의 근거와 기록 흐름을 추가한다. **제안 시안이며 SwiftUI 앱 미적용, 수치는 설명용**이다. 2026-10-25 사용자가 흐름과 근거 안을 승인했다. 실제 구현에서는 과거 습관 대상 수를 복원하지 않고 일별 완료 기록을 표시한다.

## 범위와 공통 기준

- A01 Activity 준비도, L01 Life 오늘 습관. iPhone 기본 폭을 우선하며 좁은 폭·넓은 폭·큰 글씨·밝음·어두움·기록 없음·일부 누락을 비교한다.
- 공통 124pt 링·금빛 진행 호·모래색 배경·불투명한 내용 표면을 유지한다. 새 캐릭터나 장식용 수치를 넣지 않는다.
- V1 `핵심 요약`: 기존 링 옆 설명을 유지하고 아래에 근거 또는 6개 진행 표식과 남은 수를 추가한다.
- V2 `흐름과 근거`: 상단 링·상태, 중간 근거/완료 요약, 하단 날짜가 있는 7일 그래프를 둔다. 권장 방향이다.

## A01 정보 순서와 행동

1. 오늘의 운동 준비도 / 최근 기록 기준.
2. 준비도 67 링, 보통 상태, 일반 훈련 가능, HRV가 평소보다 낮다는 짧은 근거.
3. HRV·수면·회복 구성 점수. 구성 점수는 raw HRV ms나 수면 시간이 아닌 100점 기준 값임을 표시한다.
4. V2에서 최근 7일 준비도 그래프. 마지막 값은 링과 같은 67. 하루 한 값의 기준은 앱 구현 시 현재 준비도 산정 기준과 맞춰야 한다.
5. 준비도 상세를 열면 기존 TrainingReadinessDetailView로 연결한다. 시안에서는 카드 안의 근거 설명을 펼친다. 운동 추가는 기존 상단 더하기 경로를 유지한다.

## L01 정보 순서와 행동

1. 오늘의 습관 / 오늘.
2. 4/6 링, 6개 중 4개 완료, 남은 2개 안내. 개별 습관을 히어로에 재나열하지 않는다.
3. V1은 6개 진행 표식. V2는 완료·남음 요약과 최근 7일 현재 수동 습관의 일별 완료 기록 개수. 과거 대상 수는 저장되지 않아 표시하지 않는다. 주기형 습관의 현재 진행 상태와 일별 완료 기록을 구분한다.
4. 오늘의 습관 행동은 기존 체크리스트를 연다. 시안에서는 아래에 예시 체크리스트를 펼치며 개별 기록을 변경하지 않는다.

## 데이터와 접근성 상태

- 준비도 없음: `--`, 기록을 기다리는 설명. 구성 점수와 그래프를 숨기고 상세 행동 비활성화.
- 일부 누락: 누락한 구성 점수는 `--`, 과거 표본은 `—`와 `기록 없음`으로 표시하며 0점으로 연결하지 않는다.
- 습관 없음: `--`, 첫 습관 안내. 0/0 완료율이나 가짜 주간 그래프를 만들지 않는다. 첫 습관은 기존 상단 추가 경로.
- 큰 글씨: 링과 설명, 구성 점수를 세로로 전환한다. 카드 높이는 내용에 따라 늘어난다. 기본 124pt 링은 유지한다.
- 시안 설정은 대화 내 디자인 설정에서 제공한다. 보존본에는 별도 미리보기 설정을 두되 제품 화면 밖에 둔다.
- 실제 앱을 변경하지 않으므로 실제 화면 디자인맵의 새 캡처로 등록하지 않는다. 시안의 브라우저 검증은 iPhone/iPad/Duo 앱 실행 검증이 아니다.

## 시안 검증 (2026-10-25)

- 설치된 Chromium headless로 두 배치 각각 320·402·736px, 기록 있음·일부 누락·기록 없음의 총 18개 조합에서 가로 넘침이 없음을 확인했다. 밝음·어두움과 큰 글씨를 포함한다. 전체 설정 조합의 완전 탐색은 아니다.
- 두 배치 전환, 준비도 근거 펼치기, 오늘 습관 펼치기를 확인했다. 기본 어두움과 큰 글씨·밝음·일부 누락 렌더를 육안 확인했다. 기본 배치 JavaScript 예외 0건.
- 테마 맵 생성·동기화 검사와 `git diff --check` 통과. 앱 소스 변경이 없어 앱 빌드·시뮬레이터 실행은 범위에 포함하지 않았다.
- 기본 Playwright 실행은 해당 버전 브라우저 파일 부재로 실패했다. 설치된 실행 파일 경로를 확인한 뒤 한 차례 재시도해 렌더 검증을 완료했다.
