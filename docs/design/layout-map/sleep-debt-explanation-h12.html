구현 배치 계약 · 정적 시안. 실제 앱 캡처나 사용자의 수면 기록이 아니다.

How Sleep Debt Works

기존 info.circle.fill 선행 아이콘과 제목. 접근성 글자 크기에서는 아이콘·44pt Close를 윗줄에 두고 제목은 카드 전체 폭의 다음 줄에 둔다. 14일 기준선 → 지난 7일의 하루별 부족분 → 합산을 장식 흐름으로 보여 준다. 그림의 연결선는 임의 건강 데이터가 아니며 접근성 읽기에서 제외한다.

Baseline · 14 days→How It Adds Up · 7 days→Sleep Debt

설명 카드 순서

Baseline: 지난 14일 평균, 기록 없는 날 제외. How It Adds Up: 지난 7일 각 날을 14일 평균과 비교하여 부족분 합산. Excess Sleep: 평균보다 더 잔 날은 누적 부족분을 줄이지 않으며 하루 부족분 하한 0. 기존 영문 카탈로그 문장을 그대로 표시한다.

Levels

원래 네 레이블·경계·색과 8pt 색 점을 유지하고 각 행의 왼쪽에 등급 SF Symbol과 텍스트를 함께 둔다. 접근성 글자 크기에서는 기호의 실제 크기만큼 공간을 주고 범위는 다음 줄에 표시한다.

◉ Well Rested < 2h
◉ Slightly Short 2–5h
◉ Sleep Debt 5–10h
◉ Severe Debt > 10h

출처: SleepDeficitGaugeView의 info 버튼 → SleepDebtInfoSheet. 중간/큰 시스템 detent·드래그 표시와 전체 ScrollView 유지. iPhone/iPad/Duo는 최대 폭 680pt 한 열, MAX 글씨에서 제목·설명·등급 행은 줄바꿈·세로 확장하며 아이콘은 텍스트와 겹치지 않는다. 밝음·어두움에서 텍스트는 표면 대비 전경을 쓴다.
