  • 평균·최대 레벨 다음에 변화 기록을 시간순으로 표시한다. 시간은 일시정지를 뺀 운동 경과 시간이다.
  • 레벨을 입력하지 않은 운동과 기존 기록에는 변화 목록을 표시하지 않는다.
  • iPhone·iPad·Duo에서는 요약과 기록 상세의 스크롤 영역 안에 둔다. Watch에서는 완료 요약의 통계 아래에 둔다.
  • 큰 글씨에서도 한 행의 시간과 레벨을 읽을 수 있게 세로 스크롤을 유지한다.
