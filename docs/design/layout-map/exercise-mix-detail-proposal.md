# A01 운동 구성 상세 배치안

[4탭 시안에서 상세 열기](../theme-map/themes/dune-final-four-tab.html) · [4탭 레이아웃 기준](index.html) · [현재 실제 화면](../phone-design-map/actual/index.html)

이 문서는 Activity의 운동 구성 요약 카드와 상세 화면에 적용한 **정보 배치 계약**이다. 구현 전에는 요약의 운동별 수행 횟수 상위 6개와 상세의 운동별 빈도 도넛·전체 목록만 있었다. 현재 코드는 최근 4주 근력·유산소 구성, 주별 구성, 주요 부위의 완료 세트 환산 비율과 유산소 종류를 같은 `ExerciseMixSummary`에서 표시한다. 시안의 수치는 설명용 예시이며 실제 앱 데이터가 아니다. 새 실제 캡처와 런타임 검증은 아직 대기 중이다.

| 위치 | 정보 순서 | 단위·기준 |
|---|---|---|
| Activity 요약 | 최근 4주 기록 기간 → 근력/유산소 구성 막대와 건수 → 근력 주요 부위 3개 → 상세 진입 | 완료된 운동 기록 **건수** 기준. 구성비의 분모와 표본을 함께 표시한다. |
| 상세 첫 카드 | 선택 기간 → 전체 기록 건수 → 근력/유산소 건수·비율 → 4주 주별 구성 | 전체 기록 건수를 분모로 한다. 주별 막대도 같은 기록 건수를 사용한다. |
| 상세 근력 부위 | 주요 부위별 비율·세트 환산 수 → 부위 정보 누락 안내 | 완료 세트를 운동의 **주요 부위**에 균등 배분한 세트 환산값을 분모로 한다. 보조 부위는 포함하지 않고, 부위 정보가 없는 세트는 비율에서 제외한다. 카테고리 합계는 100%다. |
| 상세 유산소 | 달리기·사이클·걷기 등 종류별 기록 건수 | 유산소 기록만 분모로 한다. 거리·시간은 해당 운동에 실제 값이 있을 때만 보인다. |
| 상세 운동별 | 운동 이름별 수행 횟수와 전체 기록 중 비율 | 현재 앱의 운동 빈도 계산을 유지한다. 정렬은 수행 횟수 내림차순이다. |

요약의 구성비, 부위 비율, 운동별 빈도는 **각기 다른 분모**를 명시한다. 같은 세션에 여러 운동이 있더라도 운동 기록 단위로 센다. 부위별 비율에 한 운동의 전체 세트 수를 여러 부위에 중복 가산하지 않는다. 요약에서 부위별 숫자는 근력 기록이 있고 부위 정보가 있는 경우에만 노출한다.

기록이 없으면 그래프와 퍼센트를 만들지 않고 운동 기록 진입을 보여 준다. 근력 기록만 있으면 유산소 세부 영역을 빈 안내로, 유산소 기록만 있으면 근력 부위 영역을 빈 안내로 표시한다. 부위 정보가 일부 빠지면 제외 세트와 분모를 알리고, 기존 운동별 빈도는 계속 보여 준다. 구현된 상세 화면은 최대 780pt 읽기 폭에서 일반 글씨의 regular 너비에 두 열을 사용하고, compact 또는 접근성 글씨에서 한 열로 쌓는다. 레이블과 수치가 색상만으로 구분되지 않는지 실제 캡처에서 확인한다.

집계 서비스 단위 테스트는 기간 경계, 수동·HealthKit 중복, 주요 부위 균등 배분과 누락 세트를 다룬다. 상세 화면의 ID 기반 UI 경로도 추가했다. 데이터 수치와 차트의 실제 기기 렌더링은 다음 런타임 검증에서 판정한다.
