# L01 주간 운동 업적 시안

[시안 열기](../theme-map/themes/dune-workout-achievements.html) · [기존 Life 전체 배치](life-redesign-proposal.md)

## 범위

사용자가 첨부한 Life의 **이번 주 운동 업적 영역만** 재설계한다. 전체 상세 화면이나 기존 화면 병렬 비교는 다른 세션 요청으로 정정되어 제외했다. 앱 소스와 실제 화면 디자인맵은 변경하지 않는다. 이 문서의 그림은 브라우저 시안이며 실제 앱 캡처가 아니다.

## 정보와 표현

| 순서 | 성과 보드 · 강조안 | 숫자 중심 · 절제안 |
|---|---|---|
| 완료 현황 | 큰 완료 수 / 10, 완료한 수만 채운 작은 표식, 장식 메달·능선 | 큰 완료 수 / 10, 메달과 장식 표식 제외 |
| 내 목표 | 별 아이콘, 이름, 오늘 자동 연동 상태, 기존 더보기 위치 | 동일한 행 구조 |
| 루틴 | 운동 횟수 하나와 7개 분절, 5회·7회 목표를 함께 표시 | 낮은 분절과 큰 횟수 |
| 근력 | 근력·가슴·등·하체·어깨·팔 3×2 타일, 각 3회 표시 | 2열의 수치와 가벼운 구분선 |
| 러닝 | 큰 거리·남은 거리, DUNE 능선과 곡선형 거리 진행 | 큰 거리와 낮은 진행 곡선 |
| 출처 | DUNE + Apple 건강, 운동 횟수·거리 기준 | 동일 |

기존의 외곽 카드·내부 그룹 카드·반복 진행 막대 중첩을 하나의 표면과 구획으로 바꾼다. 도전 그룹은 접고 펼칠 수 있다. 카드 전체를 새 상세 진입으로 만들지 않는다. 내 목표 메뉴의 위치와 항목은 표현하지만 시안에서는 앱 데이터 수정·이력 조회·보관을 실행하지 않는다.

## 데이터 계약

- 총 10개 = 내 목표 1개 + 주간 운동 5회/7회 2개 + 근력 6개 + 러닝 15 km 1개.
- 기본값은 첨부 화면과 같은 완료 0/10, 운동 4회, 근력 2회·등 1회·어깨 1회·팔 2회, 러닝 0 km다. 기존에 숨겨진 가슴·하체도 0/3으로 명시한다.
- 분절은 **운동 횟수**이며 월–일 완료 여부가 아니다. 하루에 여러 운동을 기록할 수 있다.
- 내 목표의 현재 exercise 존재 기반 자동 연동과 주간 운동 도전의 기간을 구분한다. ‘매일 달리기’는 사용자 목표 이름 예시이며 달리기 종목 매칭 기능을 새로 약속하지 않는다.
- 장식 메달은 새 보상이나 점수가 아니다. 작은 표식만 실제 fixture 완료 수에 맞춰 채운다.
- 진행 예시·모두 완료·기록 없음은 시안 내부의 설명용 데이터다. 마지막 동기화 시각·권한 거부·조회 오류를 추측해서 만들지 않는다.

## 기기·접근성·검증

폭 320/402/736, 밝음/어두움, 기본/125%/160% 글씨, 4개 기록 상태, 2개 방향을 브라우저에서 검사한다. 큰 글씨는 근력 2열·메달 숨김·문구 줄바꿈을 적용한다. 색 외에 수치·체크·단위를 제공한다. 더보기는 44px, 펼침 헤더는 최소 65px이다. 이 검사는 SwiftUI Dynamic Type, VoiceOver, iPad/Duo 네이티브 배치의 검증을 대체하지 않는다.

검증 결과와 시안 PNG는 [브라우저 QA](../theme-map/themes/assets/workout-achievement-qa.json), [어두움 기본값](../theme-map/themes/assets/workout-achievement-board-dark.png), [밝음 진행 예시](../theme-map/themes/assets/workout-achievement-board-light-progress.png)에 보존한다. 구현은 사용자 방향 선택 후 별도 작업이다.
