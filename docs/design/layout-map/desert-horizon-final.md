# DESERT HORIZON 4탭 구현 기준 상세 시안

[4탭 밝음·어두움 시안](../theme-map/themes/dune-final-four-tab.html) · [공통 레이아웃 맵](index.html) · [초기 테마 방향](../theme-map/themes/dune-design-direction.html) · [현재 실제 화면](../phone-design-map/actual/index.html)

이 시안은 2026-10-22에 구현된 첫 화면 UX와 Wellness 상세 목적지 분리를 기준으로, DESERT HORIZON의 4탭 레이아웃 게이트를 닫기 위한 **목표 화면**이다. HTML의 수치·그래프·문구는 배치 설명용 예시이며 실제 건강 데이터나 앱 캡처가 아니다. 앱 구현 완료와 시안 일치 판정은 별도다.

시안 화면은 각 탭에서 **기존 앱 실제 PNG → 전체 스크롤 목표 시안 → 카드별 차이**를 나란히 보여 준다. 기본 비교 PNG는 저장된 iPhone 첫 화면 캡처다. Duo 펼침을 선택하면 실제 PNG도 같은 951×669pt 가로 자세의 탭별 캡처로 바뀐다. 큰 글씨·기록 상태 전환은 시안에만 적용된다. 첫 화면 밖의 비교 설명은 현재 SwiftUI 화면의 섹션 순서도 기준으로 한다. T03·A01은 2026-10-22 첫 화면 UX 캡처, H01 어두움은 점수·수면 링크 분리 뒤 통합 실제 화면맵 캡처, L01은 진행 설명 변경 뒤 402pt 캡처다. H01 밝음은 분리 전 캡처임을 비교 화면에 표시한다. Duo 펼침 L01 비교는 진행 설명 변경 뒤의 가로 캡처를 사용한다.

## 공통 배치와 시각 규칙

- 첫 화면의 순서는 **상태 → 실제 변화 또는 진행 → 근거 → 같은 맥락의 행동**이다. 탭마다 첫 질문이 달라 카드 안의 세부 정보는 달라진다.
- 상단 장면에는 채워진 먼·중간·가까운 모래 능선 세 층을 둔다. 능선 실루엣은 초기 방향 시안의 **비대칭 사인 곡선과 보조 굴곡**을 그대로 사용한다. 타원이나 큰 원호로 단순화하지 않는다. **화면 전체에 세로 그라데이션**을 깔고, 능선의 채움은 카드 뒤로 내려가며 투명해진다. 헤더 하단에 직선으로 끊기는 면이나 색 경계가 없어야 한다. 세 층은 낮은 진폭으로 서로 다른 속도로 움직이고, 본문·터치 영역·실데이터는 정지한다. Reduce Motion에서는 완성된 정지 장면이다.
- 첫 카드의 링은 공통 124pt·11pt 획이다. 금빛 광택은 테마 표현이고 숫자·상태 문구가 의미를 전달한다. 점수의 의미색은 테마 금빛으로 대체하지 않는다. 접근성 글씨에서는 링과 설명을 세로로 쌓는다.
- 밝은 모드의 Today 히어로는 짙은 갈색 표면을 유지한다. Activity·Wellness·Life는 안정된 밝은 표면을 쓴다. 어두운 모드에서는 네 카드 모두 짙은 표면을 사용한다. 시안의 대비는 목표이며 앱 합성 화면에서 작은 글자 4.5:1, 큰 글자 3:1을 확인해야 한다.
- 첫 카드 아래에도 기존 앱의 시각 문법을 유지한다. 날씨·수면·운동·기록에는 아이콘을, 진행과 예측·부상 위험에는 목적이 분명한 작은 링을, 시간에 따른 변화에는 기간 레이블이 있는 그래프를 배치한다. 습관에는 범주 아이콘과 실제 완료 달력을 둔다. 아이콘과 링은 이름·수치·단위의 보조 표현이며, 기록이 없으면 그래프나 진행률을 만들지 않는다.
- 숫자만 나열되는 기록 카드에는 질문에 맞는 작은 그래프를 더한다. T03의 안정 심박 인사이트와 하단 HRV·RHR·걸음·운동 시간·체중·수면은 각각의 기간과 단위를 표시한다. A01 이번 주 운동은 7일 운동 시간 분포를, 주간 보고서는 이전 기간과 이번 기간의 훈련 볼륨 비교를 표시한다. L01 운동 성취는 요일별 수행을, 주간 보고서는 이전 7일과 최근 7일 완료 수를 보여 준다. 단일 측정값인 BMI와 행동 선택 카드에는 추세를 만들지 않는다.
- 네 탭의 모든 기본 카드에는 최종 화면에서 실제로 볼 수 있는 제목·값·아이콘·그래프·상태·행동을 배치한다. 구현 조건을 설명하는 문장이나 임시 목적지 안내는 기기 프레임 안에 두지 않는다. T03은 어제 운동·수면·점수 변화, 걸음·수면 진행, 날씨와 코칭, 추천 근거, 저녁 요약, 고정 지표와 건강 Q&A를 표시한다. A01은 부상 기록, 최근 운동별 내용, 달성 기록과 운동 페이스를 구체화한다. H01은 Watch 앉은 시간·걷기·알림, 자세 평가의 최근 점수와 촬영·실시간 행동, 활성 부상 기록을 표시한다. L01은 습관 종류별 입력·진행, 운동 성취의 루틴·근력·달리기, 기간별 완료율·달력·보고서 요약을 표시한다. 이 값들은 배치용 예시이며 데이터가 없을 때는 같은 영역의 실제 빈 상태 배치를 보여 준다.
- 탭 바에는 현재 `AppSection.icon`의 네 상징을 함께 둔다. Today는 심장·기록지(`heart.text.clipboard`), Activity는 불꽃(`flame`), Wellness는 잎(`leaf.fill`), Life는 체크리스트(`checklist`)다. iPhone·Duo 접힘·iPad는 아이콘 위에 이름을 두고 Duo 펼침 가로는 우측 레일에 같은 아이콘을 둔다. 선택 상태는 색과 강조 배경으로 구분한다.
- Today 상단에는 알림 종과 설정 톱니를 둔다. 현재 앱의 별도 새로운 소식 버튼은 [알림함의 새로운 소식 섹션](notification-inbox-proposal.md)으로 통합하는 제안이다. 종을 누르면 시안 안에서 알림함·출시 상세를 볼 수 있다.
- Activity·Wellness·Life의 기록 추가는 [상단 내비게이션 배치안](record-entry-navigation.md)에 따라 제목 오른쪽 44pt 더하기 버튼에 둔다. 준비도 히어로·웰니스 예측 아래·습관 없음 히어로의 중복 기록 버튼은 제거한다. 일반·로딩·기록 없음 상태에서 같은 목적지로 연다.
- 원본 방향 시안의 장면 색과 링 방향은 유지한다. 이번 시안은 카드 정보 구조·문구·행동 목적지를 최신 구현 계약에 맞춘다. 다크 모드 시안과 실제 화면을 우선 대조한 뒤 밝은 모드도 확인한다.

### 보조 카드의 시각 배치

| 화면 | 시각 요소 | 수치와 설명의 위치 |
|---|---|---|
| T03 | 브리핑의 날씨 아이콘·온도, 진행 링, 수면 단계 타임라인, 스트레스 작은 링·30일 추세, 지표별 아이콘 | 그래프 기간과 현재값을 그래프 바로 아래에 두고, 수면 시간·스트레스 점수는 그래프 밖에도 텍스트로 쓴다. |
| A01 | 앞·뒤 전신 근육 지도, 회복/볼륨 선택, 주간 통계 4개 카드, 부상 위험 링, 훈련량 막대, 주간 보고서의 수치·근육군·하이라이트, 개인 기록 2열 그리드, 운동·성취 아이콘, 운동 구성 비율 막대 | 지도 바로 아래에 회복됨→피로 그라데이션 또는 0·1–5·6–10·11–15·16+세트 범례를 둔다. 선택에 따라 지도 색·상태 요약·범례가 함께 바뀐다. 이번 주 운동은 실제 앱처럼 훈련 볼륨(kg)·칼로리(kcal)·운동 시간(분)·활동일(일)을 2×2로 보여 주고, 제공되는 이전 7일 대비 변화값을 해당 카드에 표시한다. 보고서는 운동 횟수·활동일·볼륨·이전 기간 대비 수치 뒤에 상위 3개 근육군, 요약, 최대 2개 하이라이트를 둔다. 개인 기록은 근력·유산소를 합쳐 날짜순 최대 8개까지 2열로 놓고 종류·값·단위·날짜·출처를 표시한다. 운동 구성은 근력/유산소 기록 건수와 주요 근력 부위의 완료 세트 환산 비율을 분리해 적는다. 위험 수준과 부위, 훈련량 총합과 기간을 시각 요소 옆에 둔다. |
| H01 | 실제 수면 7일 막대, 웰니스 점수의 짧은 7일 흐름, 예측 링, 신체·활성 지표별 작은 추세, Watch 자세 요약 지표, 자세 측정 기록의 점수 링, 체중 장기 추세 | 각 그래프에 기간·최근값·단위를 표시한다. 체중·체지방률은 서로 다른 단위로 분리하고 HRV·안정 심박·일반 심박·호흡수도 각 카드에서 별도 스케일을 사용한다. BMI처럼 추세 표본이 없는 지표는 선을 만들지 않는다. 현재 측정·미래 예측의 구분과 기록 날짜를 유지한다. |
| L01 | 습관별 아이콘, 루틴 목표 링, 완료 막대, 4주 히트맵 | 분류·시간대·개별 실행을 유지하고, 완료 수와 기간을 차트 밖에도 표시한다. |

## 상태와 반응형 계약

- 유효한 기록이 없으면 점수·곡선을 만들지 않고 **아직 기록이 없습니다**와 가능한 기록 경로를 보여 준다. T03은 건강 데이터 확인, A01은 상단 운동 추가와 본문의 운동 검색, H01은 상단 기록 추가, L01은 상단 습관 추가를 주 경로로 둔다. L01의 습관 없음 화면에는 보관한 습관과 자동 운동 성취가 이어진다. 일부 누락은 T03 업데이트 뒤, H01 히어로 앞에 별도 배너로 표시한다. 권한 거부·기준선 수집·동기화 지연·오류는 같은 빈 상태로 합치지 않는다.
- iPhone 402pt에서는 상태·행동이 첫 화면에서 읽히게 하고, 긴 문구와 최대 접근성 글씨에서는 카드 높이를 늘린다. 내용을 글자 축소나 한 줄 생략으로 감추지 않는다.
- A01 운동 페이스의 분수형 목표 링은 숫자 주변에 충분한 내부 여백을 두고, 링·설명·진행 막대·기간 레이블 사이의 간격을 각각 확보한다. 좁은 폭에서는 설명을 줄바꿈하고 큰 글씨에서는 링과 설명을 위아래로 쌓아 겹침을 막는다.
- A01 추천 운동은 실제 앱의 검색 필드와 헬스장/집·장비 설정을 맨 앞에 둔다. 검색어가 있으면 추천 묶음을 검색 결과로 바꾼다. 일반 상태에서는 회복 부위 칩과 최대 4개 운동의 이름·추천 이유·세트·시작·대체 운동·관심 없음 행동을 보이고, 해당 데이터가 있을 때 추천 루틴과 내 템플릿을 가로 목록으로 이어 붙인다. AI 운동 만들기와 전체 운동은 마지막에 둔다. 회복일에는 운동 카드 대신 회복 이유·다음 준비 부위·가벼운 회복 제안을 보여 준다. 시안 상단의 Activity 추천 상태 조작으로 운동 추천·회복일·추천 없음 배치를 확인한다.
- A01 추천 운동의 검색·설정·운동 카드 그리드는 iPhone 402pt와 Duo 접힘 466pt에서 화면 안쪽 너비를 넘지 않는다. 긴 운동 이름은 카드 안에서 줄을 바꾸고, 추천 루틴·내 템플릿의 가로 스크롤은 해당 목록 안에서만 일어난다. 화면 본문 자체에는 가로 스크롤을 만들지 않는다.
- A01 주간 보고서는 **현재 기간**의 운동 횟수·활동일·볼륨·가능한 경우 이전 기간 대비 볼륨 변화, 상위 근육군 최대 3개, 생성된 요약 문장, 하이라이트 최대 2개를 간결한 카드 안에 유지한다. 이전 기간 데이터가 없으면 변화율을 만들지 않고, 보고서가 없으면 빈 안내 카드만 보여 준다. 자세한 운동 시간·평균 강도·근육별 볼륨은 보고서 상세에 둔다.
- A01 개인 기록에는 기록이 있을 때만 레벨·배지·포인트 요약을 표시한다. 각 카드에는 근력/유산소 종류와 운동명, 최고값·단위, 기록 날짜·수동/HealthKit 출처를 둔다. 같은 종류의 값이 두 개 이상일 때만 작은 추세를, 최근 새 기록이면 NEW를 표시한다. 큰 글씨에서는 카드 열을 하나로 줄인다. 유산소 기록을 불러올 수 없는 시안의 일부 누락 상태에서는 근력 카드를 남기고 Apple Health 연결 안내를 둔다. 기록이 없으면 단일 최고값이나 그래프를 만들지 않고 근력·유산소 기록 안내를 보여 준다. 전체 기록 상세에서는 종류 선택, 현재 최고값, 기간별 추세, 보상 진행, 종류별 기록과 달성 이력으로 이어진다.
- A01 운동 구성은 요약에서 최근 4주 근력/유산소 비율과 주요 근력 부위 3개를 보여 주고, 상세에서 주별 구성·근력 부위 전체·유산소 종류·운동별 빈도를 펼친다. 운동 기록 건수와 근력의 완료 세트 환산값은 서로 다른 분모로 표시한다. [상세 배치안](exercise-mix-detail-proposal.md)에 계산·누락·반응형 기준을 둔다.
- H01 신체·활성 지표는 실제 앱의 2열 VitalCard 구성과 표본별 스파크라인을 유지한다. 각 카드에 최근값·단위·기록 시각·기간을 두고, 값이 2개 미만인 지표에는 점선 자리와 기록 부족 안내를 쓴다. 일부 신체 지표 조회 실패 시 해당 카드의 그래프만 숨기고 다른 기록은 남긴다. 긴 체중 변화는 기록 내역 카드에서 기간을 넓혀 보여 준다.
- 시안은 기기 프레임 안쪽을 스크롤하고 탭 바를 하단에 고정한다. 배경 그라데이션은 기기 화면 전체에 유지하고 본문 카드가 그 위를 지난다.
- Duo 펼침은 실제 내부 화면의 **가로 951×669pt**를 기준으로 한다. 상단 높이를 줄이고 우측 탭 레일을 둔 뒤, 본문과 행동의 읽기 폭을 제한한다. iPad와 Duo 펼침에서 A01의 근육 지도·이번 주 요약, H01의 점수·수면, L01의 습관·운동 성취는 충분한 폭에서 두 열이다. 좁거나 큰 글씨에서는 모두 위아래로 쌓는다. Duo 접힘에서는 세로 한 열과 안전한 터치 영역을 유지한다. 시안 상단의 기기·큰 글씨·기록 상태 조작으로 이 전환을 확인한다.
- 한국어·영어·일본어, VoiceOver, Increase Contrast, Reduce Motion에서 동일한 목적지와 상태 의미를 확인한다. 상단 능선은 접근성 정보가 아니다.
