# Activity 최종 통합 시안

[최종 한 화면 열기](../theme-map/themes/dune-activity-final.html) · [이전 세 방향 비교](../theme-map/themes/dune-activity-redesign.html) · [Astra 자문·타 앱 근거](activity-information-architecture-study.md) · [카드별 상세 계약](activity-redesign-proposal.md)

지금까지 받은 피드백을 **Flow 한 가지**로 묶은 최종 제안이다. 선택용 캐러셀을 제거하고 첫 카드부터 마지막 카드까지 한 화면에서 이어서 읽는다. 기존 Compact·Training 비교본은 보존한다. 사용자의 앱 구현/배포 승인을 뜻하지 않으며 수치·날짜·보상은 예시, 브라우저 이미지는 실제 앱 캡처가 아니다.

## 최종 흐름

**상태 → 운동 선택 → 기록·성취 → 누적 분석**

| 순서 | 카드 | 확정한 표현 |
|---|---|---|
| 1 | 운동 준비도 | 104px 링, 현재 해석, HRV/수면/회복의 같은 100점 척도 가로 막대. 과거 흐름은 펼침. |
| 2 | 근육 회복 | 앞/뒤 지도, 회복/세트 수 전환, 지도 아래 회복됨→피로 10단계 또는 세트 수 5단계 범례. 3D 없음. |
| 3 | 훈련 부담 점검 | 수준·기간·근력 볼륨 변화·연속일·회복 부위와 일부 기록 누락 안내. |
| 4 | 추천 운동 | 검색·장소/장비·운동·루틴/템플릿·AI·전체 운동 경로 유지. |
| 5 | 최근 운동 | 최신 2개와 이전 기록 펼침. 리본 메달형 달성/5K 배지와 밝은 골드 트로피형 PR 배지, 제목 옆 작은 Apple 연동 마크, 유효한 평균 심박. |
| 6 | 개인 기록 | 금빛 메달·큰 최고 값·최근 기록 표시·개선량·날짜·출처·레벨/배지/포인트. |
| 7 | 달성 이력 | 시간순 최신 3개 이벤트와 날짜·보상 포인트. 별도 카드로 표시. |
| 8 | 최근 7일 운동 | kg 근력 볼륨·칼로리·시간·활동일·일별 운동 시간. |
| 9 | 주간 보고서 | 볼륨 변화/합계 강조, 운동 횟수·활동일·총시간과 주요 부위·하이라이트. |
| 10 | 운동 꾸준함 | 월 운동일 목표를 먼저, 현재/최고 연속 운동일을 아래에 배치. |
| 11 | 훈련 부하 | 최근 운동일 합계의 시간/칼로리 강조와 별도의 최근 28일 부하 그래프. |
| 12 | 운동 구성 | 근력/유산소 아이콘, 큰 비율, 16px 구성 막대, 주요 근력 부위 태그. 최근 28일·운동 기록 수 기준(세션 수와 구분). |

넓은 화면에서는 관련 카드가 두 열로 놓이고, 좁은 폭/큰 글씨에서는 같은 읽기 순서로 한 열이 된다. 수치·범례·라벨을 줄여 높이를 강제로 맞추지 않는다.

## 공통 기준

- 각 탭의 첫 히어로 제목을 영어 대문자로 통일한다: Today `CONDITION`, Activity `READINESS`, Wellness `WELLNESS`, Life `HABITS`. 제목은 링 바깥 상단에 두고 설명은 사용자 언어를 유지한다. [4탭 히어로 제목 계약](hero-heading-style.md)을 따른다.
- 기존 DUNE 브라운·골드·모래 능선을 유지한다. 상태/범주 색은 이름·아이콘·정확한 값과 함께 표시한다.
- 상세는 제목 바로 옆 4px chevron과 전체 헤더 최소44px 터치로 통일한다. 중복 하단 상세 버튼을 두지 않는다. 별도 검색/시작/정보 동작과 중첩하지 않는다.
- 운동 꾸준함은 월 목표/연속일이고, 근력 볼륨은 중량×횟수 kg, 근육 모드는 세트 수, 훈련 부하는 노력도/심박 기반 흐름, 훈련 부담은 평가다.
- 시간/칼로리의 원천은 최근 단일 운동이 아닌 **최근 운동일 합계**다. 주간 통계/보고서는 집계 출처가 달라 이번 시안에서 합치지 않는다.
- HealthKit 표시는 기존 앱 `UnifiedWorkoutRow.sourceBadge`처럼 제목 옆 작은 분홍색 Apple 마크로 축소한다. 텍스트·칩 배경·회전 아이콘은 제거하고, 불러온 기록/수동 기록 연결 설명은 접근성 이름에 유지한다. 연결 플래그를 실시간 동기화 완료 상태로 확대 해석하지 않는다. 심박·비교값이 없으면 가짜 숫자를 만들지 않는다. 수동 보상 배지는 실제 workoutID로 연결할 후속 앱 구현이 필요하다.
- 기본/일부 누락/첫 준비도/기준선 형성/기록 없음/접근 필요/로딩, 휴식일을 비교한다. 접근 제한과 수동 기록 공존, 높은 부담, Other 운동 범주는 별도 네이티브 상태 구현/검증이 남는다.

## 검증 범위

최종 파일은 12개 카드 순서·수치·배지·색 범례·기존 상세 진입, 한 화면 여부와 폭/글씨/밝음/어두움의 관련 상태를 브라우저에서 확인한다. 정확한 결과는 `activity-final-qa.json`에 기록한다. 네이티브 Dynamic Type·VoiceOver·iPhone/iPad/Duo 런타임 통과로 간주하지 않는다.

최종 통합본 검증 결과: 밝음/어두움, 폭 320–1032px, 브라우저 글씨 100–200%의 14개 조합에서 카드 순서와 가로 넘침을 확인했다. 기록 상태 6종, 상세 진입 13개, 근육 지도 전환·검색·휴식일 추천이 통과했다. 실행 오류는 없었다. 402px의 밝음/어두움 전체 화면과 주요 카드 14개 PNG를 새로 저장하고 실제 표시를 점검했다. 테마 맵 동기화 검사와 `git diff --check`도 통과했다.

후속 Apple 마크 축소는 최근 운동 카드의 밝음/어두움·320/402px·100/200% 글씨 6개 조합과 운동 상세에서 다시 확인했다. 연결된 두 기록에만 마크가 보이고, 접근성 설명·심박수는 유지되며 가로 넘침이 없었다. 최근 운동 카드 및 전체 화면 PNG 4개를 갱신했다. 변경 전 통합 검사의 소스 해시와 이번 변경 범위는 QA 파일에 구분했다.

후속 달성 배지 강조: 5K/횟수 달성은 리본이 달린 입체 메달, PR은 밝은 골드 트로피·작은 빛 아이콘으로 표시한다. 원래 달성 문구와 데이터는 유지했다. 같은 6개 최근 운동 카드 조합과 운동 상세를 재확인했고, 배지·Apple 마크·심박수 표시와 가로 넘침 검사가 통과했다. 최근 운동/전체 화면 PNG 4개를 다시 갱신했다.

## 네이티브 적용 · 2026-10-27

사용자의 `/run` 요청으로 위 Flow를 앱에 적용했다. [새 실제 화면](../full-redesign-map/review/activity-flow-2026-10-27/index.html)과 [구현 계획](../../plans/2026-10-27-activity-final-flow-implementation.md)이 현재 앱 기준이다. 앞부분의 “시안”·예시 수치·브라우저 검증 기록은 제안 당시의 이력이다.

- 준비도는 104pt/7pt 링과 같은 100점 척도의 막대, 별도 44pt 펼침 버튼과 실제 저장 추세를 사용한다. 접근성 글씨에서는 점수를 링 밖에 둔다.
- 원래 10단계 회복/5단계 세트 수 범례를 유지한다. 관측이 없는 근육을 부담 맥락에서 회복됨으로 표시하지 않는다. 3D 외부 목적지는 유지하고 루트 바로가지만 제거했다.
- 최근 두 운동에 실제 ID로 연결한 보상·평균 심박·작은 Apple 마크를 표시한다. 이전 세 항목과 전체 기록 진입을 유지했다.
- 개인 기록의 값은 전체 폭을 쓰고 단위·미니 그래프는 아래 행에 둔다. iPad의 반폭 카드에서도 값이 생략되지 않도록 실제 캡처로 보완했다.
- 운동 구성은 세션이 아닌 **기록 항목 수** 기준이다. 근력 kg 볼륨, 세트 수, 노력도/심박 기반 부하, 정성적 부담을 서로 바꾸지 않는다.
- 앱은 기존 DS의 근력·유산소·회복 색 토큰을 사용한다. 골드 성취 강조와 테마 대비를 유지하며 시안의 예시 배색·수치를 실제 측정값으로 간주하지 않는다.

일반·다크·큰 글씨의 사진, UI 실행 결과, 전체 수집 시간 초과와 범위 밖 공통 검사 실패는 실제 화면 갤러리의 출처에서 따로 추적한다. 실기기 HealthKit 권한/실시간 동기화와 전체 회귀를 통과한 것으로 확대하지 않는다.
