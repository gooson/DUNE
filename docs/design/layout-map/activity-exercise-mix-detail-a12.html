A12 운동 구성 · 배치 제안

시안이며 실제 네이티브 캡처가 아닙니다. 수치는 예시입니다.

  1. 기존 4주 기간, 실제 총 기록과 유형별 기록·비율의 불투명 히어로
  2. 주별 실제 누적 구성과 날짜·범례
  3. 주요 근육 세트·비율과 미귀속 안내, 유산소 종류·횟수·시간·거리
  4. 기존 선택 가능한 종목별 도넛과 전체 빈도 목록

로딩·빈 상태·일부 수신 안내, 뒤로, 실제 계산과 원래 값은 유지합니다. 접근성 크기는 한 열로 표시합니다. 시안의 정보 버튼·기간 선택·상태 탭은 원본 기능이 아니므로 추가하지 않습니다.

테마 시안 · 구현 계획

실제 구현 확인

운동 종류별 횟수와 비율, 주간 범례의 이름과 횟수는 구분점으로 나눕니다. 조각을 길게 누르면 실제 선택값이 남고 선택 해제로 전체 합계를 다시 볼 수 있습니다. 최대 여덟 운동을 차트에 표시하며 전체 목록과 합계를 유지합니다. 리비전별 실제 전후 비교
