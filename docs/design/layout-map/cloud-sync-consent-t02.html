구현 계약

  • 정보 순서: iCloud 히어로 → 비공개 저장 → 기기 간 동기화 → 로컬 사용 → 두 결정. 제목과 설명은 의미를 나누고 기존 기능 범위를 넘는 보장을 추가하지 않는다.
  • iPhone 402pt와 Duo 접힘 466pt: 한 열. iPad와 Duo 펼침: 시트 중앙의 본문 최대 폭을 제한한다. 최대 접근성 글씨에서는 본문이 스크롤되고 두 버튼은 안전 영역에 남는다. 정보 카드의 아이콘과 설명은 세로로 배치해 본문 폭을 확보하며, 장식 배지는64pt까지만 커진다. 텍스트는 시스템 글씨 크기를 유지한다.
  • 배경과 강조색은 기존 앱 테마, 글자와 카드 대비는 디자인 시스템을 따른다. 이 화면의 배치만 바꾸며 테마 방향 시안은 변경하지 않는다.
  • 첫 버튼은 현재 `CloudSyncPreferenceStore.setEnabled(true)`, 두 번째는 `false`를 호출한다. 두 경우 모두 기존 표시 완료와 시트 닫기를 유지하며, 결정 전 제스처 닫기는 허용하지 않는다.

변경 전 실제 T02 캡처: regular, iPad, Duo 접힘·펼침의 `actual/*/images/T02.png`. 새 구현 후 동일 화면 ID를 새 캡처와 출처로 갱신해야 한다.
