# iOS 모달 내비게이션

## 운동 상세

운동 목록에서 기록을 선택하면 좁은 화면에 운동 상세 시트가 열린다. W27과 W28은 제목 왼쪽에 닫기 버튼을 놓는다. 이름 편집을 제공하는 W28은 제목 오른쪽에 편집을 둔다. 시트 위쪽부터 운동 요약까지 상세용 원화가 이어진다. W28 아래의 아틀라스와 지표는 기존 순서를 따른다. 완료 행을 닫기 버튼과 별도로 만들지 않는다. 넓은 화면의 운동 상세 패널은 목록 및 상세를 한 화면에 보이고 하단 완료로 닫는다. W33의 편집 시트는 취소와 저장을 제공한다.

## 일반 모달

- 운동 분석 W32는 제목 줄에 닫기를 둔다. 운동 분석을 닫으면 진행 중인 운동으로 돌아간다.
- 공용 시트 배경을 사용하는 화면은 현재 테마의 정지 원화를 상단에 그리고, 제목 아래에는 끊기지 않는 세로 음영을 사용한다. 검색·목록·편집 양식은 기존 스크롤과 바의 시스템 재질을 사용한다.
- 아틀라스 장소 편집, 확대 지도, 공유 UI, 추천 장비, 신체 비교 그룹·자료 출처는 같은 공용 배경을 사용한다. 공유 미리보기의 바탕과 이미지 처리 및 위치 비공개 선택은 공유 화면이 관리한다.
- 앱의 시스템 공유기와 권한 요청, 자세 카메라, 본문에 자체 제목을 가진 작은 팝오버에는 기존 내비게이션을 사용한다. 동일 View를 공유하는 여러 진입로는 같은 시트로 기록한다.
