# iOS 모달 내비게이션

## 운동 상세

운동 목록에서 기록을 선택하면 좁은 화면에 운동 상세 시트가 열린다. W27과 W28은 제목 왼쪽에 닫기 버튼을 놓는다. W27의 제목은 운동 요약에 표시된 운동명을 사용하고 W26 운동 이력에도 같은 제목이 이어진다. 이름 편집을 제공하는 W28은 제목 오른쪽에 편집을 둔다. 시트 위쪽부터 운동 요약까지 상세용 원화가 이어진다. W28 아래의 아틀라스와 지표는 기존 순서를 따른다. 완료 행을 닫기 버튼과 별도로 만들지 않는다. Duo 외부 화면은 시스템이 제공하는 오른쪽 세로 도구 막대에 닫기와 편집을 배치한다. 넓은 화면의 운동 상세 패널은 목록 및 상세를 한 화면에 보이고 하단 완료로 닫는다. W33의 편집 시트는 취소와 저장을 제공한다.

## 일반 모달

- 운동 분석 W32는 제목 줄에 닫기를 둔다. 운동 분석을 닫으면 진행 중인 운동으로 돌아간다. 추천 장비 A20은 접근성 글자 크기에서 내비게이션 제목을 한 줄로 배치하고 본문의 여러 줄 제목을 유지한다.
- 공용 시트 배경을 사용하는 화면은 현재 테마의 정지 원화를 상단에 그리고, 제목 아래에는 끊기지 않는 세로 음영을 사용한다. 검색·목록·편집 양식은 기존 스크롤과 바의 시스템 재질을 사용한다.
- 아틀라스 장소 편집, 확대 지도, 공유 UI, 추천 장비, 신체 비교 그룹·자료 출처는 같은 공용 배경을 사용한다. 공유 미리보기의 바탕과 이미지 처리 및 위치 비공개 선택은 공유 화면이 관리한다.
- 앱의 시스템 공유기와 권한 요청, 자세 카메라, 본문에 자체 제목을 가진 작은 팝오버에는 기존 내비게이션을 사용한다. 동일 View를 공유하는 여러 진입로는 같은 시트로 기록한다.

## 조사 범위

| 영역 | 확인한 내비게이션 소유자 |
|---|---|
| Today | 고정 지표 편집, 아침 브리핑, 템플릿 저장 |
| Activity·운동 | 운동 선택과 시작, 직접·연결·템플릿 운동, 저장·정렬, 운동 상세·이력·이름 편집·분석, 장비와 안내, 근육 지도와 부위, 개인 기록과 공유 |
| Wellness | 지표 비교와 비교 그룹·출처, 체성분과 부상 기록 편집, 수면·심박 정보, 자세 조회·촬영 |
| Life | 기본 습관 추가, 습관 추가·편집과 이력, 주간 보고서 |

앱의 시트·전체 화면 모달·팝오버·상세 패널 진입점을 소스에서 확인했다. 한 화면에 진입점이 여러 개 있는 경우에도 모달의 자체 내비게이션과 배경은 그 화면에서 한 번 관리한다. 실제로 연 경로와 화면 크기별 캡처 범위는 [새 PNG 목록](../phone-design-map/actual/modal-navigation-2026-11-29/index.html)에 기록한다.
