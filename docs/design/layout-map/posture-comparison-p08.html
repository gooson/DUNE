동작·데이터 계약

PostureHistoryView의 두 record ID 선택과 날짜 정렬을 그대로 사용한다. 새 점수·변화량·개선 판정을 계산하거나 보정하지 않는다. 사진은 각 record의 원본 imageData, jointPositions, metrics와 captureType을 유지하고 탭 확대를 보존한다. 한쪽 사진이 없는 경우 기존 자리 표시를 유지한다. Metric Changes의 원래 이름·단위·전후 값·점수 차·색·아이콘을 유지한다.

기기·큰 글씨·검증

iPhone에서는 연속된 사진 pane/지표 pane, iPad와 Duo에서는 AdaptivePaneView의 기존 분할·접힘 규칙을 따른다. 각 pane의 기존 accessibility ID를 보존하고, 점수 히어로의 새 ID를 추가한다. MAX에서는 점수·화살표를 세로로 배치하며 각 pane을 따로 스크롤한다. 실제 iPhone·iPad·Duo 접힘/펼침의 PNG/AX와 사진 확대·두 pane 도달 검증 전에는 적용 완료로 표시하지 않는다.
