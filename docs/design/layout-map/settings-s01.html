S01 설정 배치 계약

현재 구현 기준은 승인된 설정 허브 배치 시안과 2026-11-21 네이티브 실제 화면·검증 범위다. 시안은 브라우저에서 만든 배치 제안이고, 실제 화면은 별도 캡처로 확인한다.

현재 네이티브 배치

설정 홈은 검색, 현재 테마 원화 카드, 앱 아이콘, 운동 설정·알림과 브리핑·데이터와 개인정보·앱 정보 순으로 읽는다. 시뮬레이터에서는 Mock Data 진입점이 뒤에 추가된다. 각 범주를 열면 해당 상세 설정으로 이동하며 홈의 다른 메뉴 위치는 유지된다.

테마 카드는 사용 중인 원화 한 장과 이름·변경 동작을 표시한다. 갤러리는 번들의 정지 원화 9장을 기본 3열로 배열하고, 좁은 폭이나 큰 글씨에서는 열 수를 줄인다. 각 원화는 선택 전 미리보기를 열며, 미리보기의 밝기 전환은 예시 화면에만 적용된다. 저장된 테마는 적용 버튼을 누를 때만 바뀐다.

좁은 화면은 홈과 상세를 한 번에 하나씩 보여주고, 넓은 화면은 홈 목록과 선택한 상세를 나란히 둔다. 검색 결과와 상세는 같은 목적지로 연결한다. 배치 근거와 화면별 경로는 설정 허브 설명을 따른다.

데이터 및 개인정보 · 암호화 백업 파일

백업 파일 화면에서 저장 범위와 파일 저장·복원 선택을 표시한다. 저장 시 복구 키는 사용자가 요청한 때만 보이고, 따로 보관했음을 확인한다. 전체 기록은 이 기기의 DUNE Exports 폴더 또는 사용자가 선택한 이동식 드라이브에만 저장한다. 테마·앱 아이콘·체중 표시 단위만 담은 설정 파일은 파일 선택기에서 iCloud Drive 등으로 내보낸다. 복원은 사용자가 선택한 파일과 직접 입력한 키를 사용한다. 파일 저장 또는 복원이 성공할 때 각각 완료를 표시한다.

이전 S01 기록 · 42행 Form

2026-11-07 구현은 Native Form 안에 운동 기본값 → Live Activity → 운동별 설정 → 알림·브리핑 → 테마 → 데이터·개인정보 → 정보 순서로 10개 섹션, 일반 기기 기준 42개 행을 놓았다. 시뮬레이터에는 테스트 데이터 4개 행을 더했다. 이 순서와 당시 실제 PNG·AX는 변경 전 비교 자료이며 현재 허브의 화면 캡처가 아니다.

기존 정적 시안도 실제 앱 화면이 아니다. 이전 PNG나 시안을 새 갤러리·검색·상세 화면의 검증 증거로 재사용하지 않는다.
