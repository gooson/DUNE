S01 배치 계약

정적 시안은 실제 앱 캡처가 아닙니다.

읽기와 조작 순서

Native Form → 운동 기본값 → Live Activity → 운동별 설정 → 알림·브리핑 → 테마 → 데이터·개인정보 → 정보. 안전 영역을 중복 가산하지 않고 DS 간격과 system-primary 섹션 제목을 사용한다. 기존 모든 컨트롤·값·아이콘·동작은 유지한다.

상태·보존·검증

로딩·검색 결과 없음·저장된 값·기본값·선택·확인·복귀는 원래 코드의 상태를 유지한다. 새 수치나 사용자 데이터는 시안에서 가져오지 않는다. iPhone·iPad의 일반/MAX와 긴 이름의 실제 PNG/AX를 확인한다. 사용 가능한 전용 Duo가 없어 접힘·펼침은 실제 재개 조건이 확인될 때까지 미갱신으로 기록한다. 시안과 이전 PNG는 새 증거가 아니다.
