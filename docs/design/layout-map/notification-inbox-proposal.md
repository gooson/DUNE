# Today 알림함과 새로운 소식 배치

[Today 상단 종을 눌러 보는 상세 시안](../theme-map/themes/dune-final-four-tab.html) · [4탭 레이아웃 맵](index.html) · [현재 실제 화면](../phone-design-map/actual/index.html)

구현 전 기준에는 Today 상단의 **알림 종·새로운 소식 반짝임·설정 톱니**가 각각 있었고, 앱 시작 시 새 소식 시트가 자동으로 뜰 수 있었다. 현재 코드는 Today의 종·설정만 남기고, 설정의 새로운 소식 행과 종을 `NotificationHubView`로 연결한다. 새 소식은 알림함의 News 필터와 수동 출시 상세에서 읽는다. 아래 표는 구현 계약을 기록한 시안 기준이며, 새 실제 캡처나 런타임 검증 완료를 뜻하지 않는다.

## 화면 순서와 목적지

| 위치 | 목표 배치 | 행동 |
|---|---|---|
| Today 상단 | 제목 오른쪽에 알림 종과 설정 톱니를 44pt 터치 영역으로 둔다. 별도 새 소식 아이콘은 없앤다. | 종은 알림함, 톱니는 기존 설정으로 이동한다. |
| 종 배지 | 읽지 않은 건강 알림과 아직 보지 않은 최신 앱 업데이트를 합산한다. | 같은 업데이트를 여러 건으로 세지 않는다. 0건이면 배지를 숨긴다. |
| 알림함 상단 | 뒤로 가기·제목·설정 진입, 읽지 않은 건수, ‘모두 읽음’을 둔다. | 모두 읽음은 건강 알림과 새 소식의 읽음 상태를 함께 갱신한다. |
| 알림함 필터 | 전체·건강 알림·새로운 소식 | 필터를 바꿔도 읽음 상태와 항목 순서는 유지한다. |
| 새로운 소식 | 최신 업데이트 카드에 제목·짧은 설명·열기 목적지를 둔다. | 현재 `WhatsNewView`의 실제 출시 목록과 상세 항목을 연다. 지난 업데이트도 그 상세에서 찾는다. |
| 건강 알림 | 기존 기록 알림을 최신순으로 둔다. | 수면·운동 등 현재 `NotificationHubView`의 목적지와 읽음·삭제 기능을 보존한다. 전체 삭제는 보조 메뉴와 확인을 거친다. |

## 상태와 반응형 배치

- 알림 내용과 출시 버전은 실제 저장된 항목에서 읽는다. 시안의 건강 알림·업데이트 문구는 예시다. 새 출시 목록이 없으면 새로운 소식 섹션을 비워 두고 임의 업데이트를 만들지 않는다.
- 건강 알림이 없어도 출시 소식이 있으면 알림함은 비어 있지 않다. 둘 다 없으면 ‘새 소식이 없습니다’를 표시하고 ‘모두 읽음’을 비활성화한다. 알림 권한을 허용하지 않아도 앱 업데이트 내용은 알림함에서 읽을 수 있어야 한다.
- 알림함 진입은 Today 탭 안의 화면 이동으로 다루며 탭 바는 유지한다. iPhone·Duo 접힘에서는 한 열, Duo 펼침 가로·iPad에서는 읽기 폭을 제한한다. Duo 펼침은 우측 탭 레일을 유지한다.
- 큰 글씨에서는 상단 건수와 행동을 세로로 쌓고 제목·본문을 자르지 않는다. 배지의 의미는 숫자와 접근성 레이블로도 제공한다.

## 구현 계약과 남은 검증

- 기존 `WhatsNewManager` 출시 목록과 `WhatsNewStore`의 본 이력을 재사용해 최신 버전당 새 소식 항목을 하나 만든다. 새 소식 상세를 열거나 ‘모두 읽음’을 누르면 이력과 종 배지를 함께 갱신한다. 건강 알림의 저장소와 목적지는 그대로 둔다.
- Today의 반짝임 버튼을 제거하고 설정 정보 행을 알림함의 News 필터로 연결했다. 자동 `WhatsNewView` 시트는 일반 시작 흐름에서 표시하지 않으며, 현재 출시 항목을 눌러 수동 상세를 연다.
- 알림함에서 여는 출시 상세는 기존 `WhatsNewView`의 실제 버전·기능 내용을 사용한다. 시안의 예시 문장을 앱 릴리스 문구로 채택하지 않는다.

종 배지 합산, 필터, 모두 읽음, 전체 삭제 뒤 Health 빈 상태는 코드와 테스트에 반영했다. 실제 iPhone·iPad·Duo의 화면 배치와 접근성은 새 캡처 및 런타임 결과로 판정한다. 이 문서의 HTML 링크는 계속 제안 시안이다.

시안의 출시 상세 예시는 `DUNE/Data/Resources/whats-new/catalog.json`과 `0.8.0.json`의 최신 저장 항목을 한국어로 줄여 배치했다. 실제 표시 버전과 언어별 문구는 앱의 출시 카탈로그·번역 문자열에서 결정한다.
