# C14 · Watch 러닝 거리 우선 화면

이 문서는 구현 기준 시안이다. 수치 예시는 실제 운동 기록이나 시뮬레이터 캡처가 아니다. 색상은 현재 Watch 디자인 토큰을 따르며 테마 표현은 변경하지 않는다.

| 대상 | 정보 순서 | 행동 경로 |
|---|---|---|
| 40mm Watch 러닝 진행 중 | `Distance` 레이블 → 두 자리 소수의 누적 km를 가장 크게 표시 → `Elapsed`와 `Average Pace` → `Heart Rate` | 거리 화면이 기본이다. 오른쪽으로 한 번 스와이프하면 운동 제어, 왼쪽으로 한 번 스와이프하면 기존 시간 우선 화면이다. 그다음 심박 존·상세·음악 페이지가 이어진다. |
| 러닝 일시 정지 | 같은 거리·시간·평균 페이스·심박 순서를 유지하고 상단에 `Paused` 표시 | 거리 화면과 멈춘 활성 시간을 유지한다. 늦게 도착한 HealthKit 거리 보정은 반영하며 평균 페이스도 활성 시간과 보정된 총 거리로 계산한다. |
| 다른 유산소 운동 | 기존 시간 우선 화면이 기본이다. | 기존 제어 → 시간 → 심박 존 → 상세 → 음악 순서를 유지한다. |

거리 0일 때는 `0.00 km`, 평균 페이스는 `--:-- /km`로 나타낸다. 심박 수신 전에는 `-- bpm`으로 표시한다. 값은 지역 숫자 형식을 적용하고, 40mm에서 먼저 확인한 뒤 넓은 Watch 크기에 자연스럽게 확장한다. 큰 글씨나 긴 번역에서는 세로 스크롤을 허용하며 각 수치의 이름을 항상 보이게 한다. 기본 40mm 화면에서는 조밀한 세로 간격과 짧은 평균 페이스 레이블로 심박 줄까지 보이게 한다. 큰 km 숫자의 크기는 유지하며 접근성은 전체 평균 페이스 명칭을 읽는다. 거리·경과 시간·평균 페이스·심박에는 독립적인 접근성 식별자를 둔다.

실제 화면 확인 대상: C14 러닝 진행과 C15 러닝 일시 정지, 40mm Watch. [Watch 실제 화면 디자인맵](../phone-design-map/actual/watch/index.html)의 새 캡처와 상태를 확인하기 전까지 이 문서를 캡처 증거로 취급하지 않는다.

## C16 · 음성 안내 제어

러닝 제어 화면은 일시 정지/재개 → 종료 → 음성 안내 토글 순서다. 음성 안내는 기본 활성이고 설정을 다음 실행에도 유지한다. 작은 화면에서 주요 버튼과 토글의 터치 영역을 확보하고 큰 글씨에서는 스크롤을 허용한다. 시작·일시 정지·재개·매 1km와 전경에서 조작한 종료에 짧게 안내하며, 평균 페이스를 구간 페이스로 부르지 않는다. 음악은 안내하는 동안만 낮춘다. 백그라운드 자동 종료는 활성 운동 오디오 런타임이 끝나므로 종료 발화를 생략한다.

## C17 · 러닝 음성 안내 설정

러닝 제어 화면에서 기존 음성 안내 토글 아래 `Feedback Settings` 버튼을 누르면 설정 시트가 열린다. 일시 정지/재개와 종료 버튼은 첫 화면에 남는다. 시트는 별도 내비게이션 스택 없이 시스템 제목과 확인 도구 막대의 완료 버튼을 사용하고, 설정 목록을 세로 스크롤한다. 별도 고정 제목 행으로 작은 화면의 목록 공간을 차지하지 않는다.

| 순서 | 설정 | 기본값·범위 |
|---|---|---|
| 1 | Voice Feedback | 켜짐. 제어 화면 토글과 같은 저장 값을 즉시 반영한다. |
| 2 | Feedback Distance | 1 km 기본. 500 m, 1 km, 2 km 중 선택한다. |
| 3 | Feedback Volume | 100% 기본. 0–100% 슬라이더와 현재 퍼센트를 함께 보여준다. |
| 4 | Target Pace Alerts | 꺼짐 기본. 켜면 목표 페이스와 허용 범위를 아래에서 조정한다. |

## C18 · 목표 페이스 세부 설정

목표 페이스 알림을 켜면 같은 시트의 아래쪽에 `Target Pace` 스테퍼와 `Pace Tolerance` 선택기를 표시한다. 목표는 2:00–20:00 /km를 5초 단위로 조정하고 기본값은 6:00 /km다. 허용 범위는 10·15·30·60초 중 선택하며 기본값은 15초다. 좁은 40mm 화면과 큰 글씨에서는 한 화면에 모든 행을 압축하지 않고 스크롤한다. 값 변경은 즉시 저장되어 다음 안내에 적용되며, 시트를 닫으면 제어 화면으로 돌아온다.

실제 화면 확인 대상: C17 기본 설정과 C18 목표 페이스 알림 활성 상태의 40mm Watch. 이 문서는 배치 계약이며 실제 캡처가 아니다. 완료 증거는 [Watch 실제 화면 디자인맵](../phone-design-map/actual/watch/index.html)에 새 캡처와 상태를 연결한 뒤 확인한다.
