# Today 전체 상태·배치 계약

[방향 시안](../theme-map/themes/dune-today-restart.html) · [재설계 근거](today-restart-proposal.md). 실제 앱 캡처나 네이티브 검증 결과가 아닌, 현재 코드의 표시 조건을 확인해 만든 디자인 계약이다. 테마는 기존 **DUNE / Desert Warm**을 공통으로 유지한다. Compact·Metrics·Editorial은 배치 대안이며 새 테마가 아니다.

| 활동 지표·운동 기록 | 고정되지 않은 걸음/운동, 조회된 운동 | 지표는 작은 카드. 기존 종목별 집계는 종목명·마지막 날짜·거리/시간을 가진 행. 최근 2종목을 우선하고 나머지는 모두 펼침으로 보존. 개별 세션 기록으로 오인하지 않도록 종목별 운동 제목을 표시. 운동명을 자르지 않음 |
| 신체 지표 | 고정되지 않은 체중/BMI/수면 | 3일 전 체중 73.9kg와 9일 전 BMI 25.2처럼 오래된 표본의 날짜를 명시. 차트가 없다고 빈 그래프 높이를 예약하지 않음 |
| 건강 Q&A | 진입은 항상, 지원 여부로 설명 변경 | 지원 기기는 수면·회복·운동 질문 진입. 미지원은 Apple Intelligence 지원 조건을 안내하고 기존 지표 상세 접근을 유지 |
| 탭 바·마지막 행 | native 탭 바 | 실제 구현은 safe area 내 마지막 행까지 스크롤 가능해야 함. HTML 시안은 전체 내용을 확인하기 위해 하단 자연 흐름으로 배치하며 native overlay의 실행 증거가 아님 |

## 전역 데이터 상태

| 상태 | 표시 | 금지·예외 |
|---|---|---|
| 첫 조회·런치 대기 | 짧은 skeleton과 로딩 설명 | 이전 데이터가 있는데 전체 skeleton으로 교체하지 않음 |
| 새로고침 | 기존 값 유지 + 작은 갱신 안내 | 값·섹션을 비웠다가 다시 채우는 점프 금지 |
| 기록 전혀 없음 | 한 번의 안내와 Activity 진입 | 가짜 0점·0시간·빈 카드 묶음 금지 |
| 건강 접근 필요 | 설정 진입과 이유 | HealthKit은 값이 없다는 사실만으로 사용자의 거부를 확정하지 않음. 실제 접근 실패 상태를 사용 |
| 일부 항목 없음 | 해당 지표/계산만 제외, 나머지 유지 | HRV 누락을 전체 데이터 실패로 취급하지 않음 |
| 전체 조회 오류 | 전체 오류와 재시도 | 기록 없음과 다른 문구·행동 |
| 일부 소스 오류 | 유효하거나 캐시된 값 + N/6 소스 실패 안내 | 캐시를 최신 측정으로 표시하지 않음 |
| 기준선 형성 중 | 모은 날짜와 준비 상태 | 0점을 실제 컨디션으로 표시하지 않음. 필요한 일수는 실제 `BaselineStatus` 사용 |
| 읽기 전용·클라우드 대기 | iPhone 동기화 대기 + 다시 확인 | 이 기기에서 HealthKit 측정을 요구하지 않음 |
| 단일 기록 | 값과 날짜; 히어로에는 추세 부족 안내 | 빈 점선/그래프를 위한 24–126pt 공간 금지. 작은 지표 카드는 날짜가 최신 기록의 문맥을 제공하므로 반복 안내를 추가하지 않음 |
| 오래된 기록 | 개별 날짜 + 최근 컨디션이라는 문맥 | 어제·9일 전 값을 오늘 값으로 표기하지 않음. 오래된 운동도 마지막 기록에서 확인 가능 |
| 일부 날짜 누락 | 실제 표본만, 공백 구간 의미 유지 | 빈 날짜를 0으로 채우거나 연결된 관측처럼 생성하지 않음 |
| 유효한 0 | 0점/0걸음/0부채 등 관측값 의미 유지 | `0 == missing`으로 일괄 처리하지 않음 |

## 크기·접근성·문자열

- 폭: 320, 402, 첨부 Pro Max 기준 440, Duo 접힘 466, Duo 펼침 951, iPad 1032pt에서 **브라우저 배치**를 확인한다. 시뮬레이터의 실제 기기나 자세를 실행했다는 의미가 아니다.
- 글씨: 100/160/200%를 비교한다. 원문을 줄이거나 `minimumScaleFactor`로 숨기는 대신 행/열 전환. 네이티브 Dynamic Type의 모든 크기는 구현 이후 별도 확인한다.
- 기본 본문 정보는 14pt 수준, 값은 28pt, 보조 날짜·축은 11–12pt로 구별한다. 링·그래프·패딩·코너는 글씨 비율에 맞춰 함께 커지지 않는다. 이 수치는 이번 제안이며 HIG 의무값을 뜻하지 않는다.
- 작은 폭·큰 글씨: 지표 한 열, 스트레스 상세는 다음 줄, 운동 값은 이름 아래로. 버튼의 제목과 숫자는 자연 줄바꿈. 긴 한국어/영어/일본어를 모두 확인한다.
- 큰 폭: 본문에서 의미 있는 2열 구성, Compact 지표는 최대 2열. 왼쪽 내용만 길어졌다고 오른쪽 카드 전체 높이를 강제로 늘리지 않는다. 큰 글씨에서는 열 수를 줄인다.
- 대비 높이기: 테마를 바꾸지 않고 보조 텍스트·경계 대비를 강화한다. 의미를 색으로만 전달하지 않는다.
- Reduce Motion: OS 설정에서 광택 전환을 정지한다. 차트 값·점수·진행률은 장식 애니메이션으로 지속 변화하지 않는다.
- VoiceOver/키보드: 점수+의미+기간, 지표 값+단위+날짜를 읽는 순서. 닫기·고정 체크박스·펼침은 별도 이름과 실제 상태를 제공한다. 브라우저 구조 점검과 실제 VoiceOver 검증은 구분한다.

## 시안 안에서 확인할 동작

컨디션/스트레스/수면 상세, 스트레스 근거 펼침, 고정 편집과 원래 그룹 복귀, 인사이트/루틴 닫기, 이전 운동 펼침, 알림 모두 읽음, 브리핑/날씨, 템플릿 입력, 체중 입력 검증, 모든 데이터 진입을 로컬로 확인한다. 시안의 입력은 앱·HealthKit·SwiftData에 저장하지 않는다. 브라우저 목적지는 구성과 진입 확인용이며 해당 상세 화면 전체 개편이나 서버 연동 구현 완료를 뜻하지 않는다.

## 추가 화면에서 확인한 여백 원인

- `CumulativeStressCard.swift`: scaled 82pt 게이지+scaled 6pt 획, 24pt 내부 패딩, 각 20pt 간격, 별도 분석 행과 상세 행이 누적된다.
- `VitalCard.swift`: 유효 그래프가 없어도 24/28pt 점선 높이를 예약한다. 단일 운동·체중·BMI 카드에 반복되면 실제 정보보다 공간이 커진다.
- `DashboardView.swift`: 홀수 개 grid의 마지막 위치에 `Color.clear`가 들어간다. 카드가 하나인 그룹은 빈 반쪽이 생길 수 있다.
- `RecoverySleepCard.swift`: 그래프 높이가 기본 112pt에서 글씨와 함께 커진다. 설명과 부채 행까지 누적되어 기본/접근성 밀도 차이가 커진다.
- 날짜가 어제·3일 전·9일 전·22일 전으로 다른 표본을 같은 큰 카드처럼 다루면 현재 상태와 과거 운동 기록의 구별이 약해진다.

## 완료 수준

초기 단계는 전체 Today의 디자인 시안과 상태 계약이었다. 이후 Compact를 선택해 SwiftUI를 구현했다. 브라우저 검사 결과는 `today-restart-qa.json`에 보존하며 네이티브 결과로 취급하지 않는다. 실제 캡처와 검사 범위는 [네이티브 갤러리](../full-redesign-map/review/today-compact-2026-10-26/index.html)와 [실행 기록](../../reviews/2026-10-26-today-compact.md)에 별도로 기록한다.

## Compact 선택과 링 수정 (2026-10-26)

### 로컬 시간 인사·인사이트 기준 (2026-10-31)

- T03·T09의 아침 인사와 브리핑 자동 표시는 기기 로컬 시간 06:00–09:59에만 허용한다. 00:00에 날짜가 바뀌었다고 자동 표시하지 않으며, 야간 접속이 그날 아침의 표시 기회를 소비하지 않는다.
- T09를 다른 시간에 수동으로 열면 인사 대신 기능명 `Morning Briefing`을 제목으로 쓴다. 날짜 비교도 실행 시점의 로컬 시간대를 따른다.
- T04 `Today's Insight`는 현재 로컬 시간이 22:00–05:59이면 점수가 높아도 휴식 안내를 쓴다. 점수의 측정 시간을 현재 시각으로 사용하지 않는다.
- T03 하단 인사이트도 22:00–05:59에는 운동 시작·주간 목표 달성 압박·낮의 야외 운동 권유 대신 회복 안내를 사용한다. 회복/수면 경고와 폭염·한파 정보는 보존하고, 밤에 숨겨지는 브리프의 핵심 인사이트도 하단에서 확인할 수 있게 한다.
- AI 코칭은 생성 시점 로컬 시간·시간대를 전달하고 인사말을 추가하지 않는다. 야간에는 운동 시작을 권하지 않는다.
- 영향 기기는 iPhone·iPad·Duo 접힘/펼침이며 Watch는 소비자가 아니다. 배치·테마 토큰은 그대로다. 실제 캡처는 새 실행 결과만 등록한다.

사용자는 Today에 Compact를 선택했다. Metrics·Editorial은 비교 자료이며 세 안의 하단 구성은 공통이다. Activity·Wellness·Life는 아직 개편하지 않았다. [구현 계획](../../plans/2026-10-26-today-compact-layout-and-ring.md)에 순서와 검증 기준을 확정했다.

시안 링은 외경104pt·획7pt·내부지름90pt로 고정하고 점수를 정중앙에 둔다. CONDITION은 같은 카드 상단에 유지한다. 86pt 축소를 제거하며 큰 글씨는 외부 점수로 전환한다. 0점에서는 진행 호를 숨긴다. 아이콘–숫자4–6pt, 링–설명12pt, 카드 패딩14–16pt를 기준으로 여백을 불필요하게 늘리지 않는다. 이 기준은 SwiftUI에도 반영했다. 아래 네이티브 검증 범위와 실제 캡처를 구분해 확인한다.

## 네이티브 적용 범위

### 2026-10-26 실제 화면 피드백 보완

- T03 컨디션 근거는 HRV/RHR 두 칸의 가용 폭을 채우고 라벨과 수치를 같은 기준선에 둔다. 작은 배지 배경으로 칸 안에 떠 보이게 하지 않는다. xxLarge 이상에서는 한 열이다.
- 어제·인사이트·루틴은 Today 지원 카드의 표면, 모서리, 내부 여백을 공유한다. 인사이트·루틴 닫기는 44×44pt 전체를 터치 영역으로 사용한다.
- 브리핑 보기·수면 상세·스트레스 상세는 카드 제목 옆의 짧은 진입부다. 큰 글씨에서는 제목 아래로 옮기며 별도의 빈 하단 행동 행을 만들지 않는다.
- 스트레스의 추세와 실제 기여 요인 설명은 기본 표시한다. 분석 근거를 보기 위해 빈 행동 행을 먼저 누르지 않는다.
- Today 지표 카드는 루트 NavigationStack으로 상세를 push하고 뒤로가기로 돌아온다. 기기 폭에 따라 sheet로 바뀌는 metric inspector를 사용하지 않는다. 상세에서 백그라운드 복귀·뒤로가기·재진입을 확인한다.
- 재조회 오류는 기록 없음으로 취급하지 않는다. 당일 마지막 정상 값과 측정일을 유지하고 기존 오류 안내로 갱신 실패를 알린다. 정상 빈 응답·날짜 변경과 구분한다.
- 적용 중인 변경의 실제 캡처·테스트 결과는 [보완 실행 기록](../../reviews/2026-10-26-today-repair.md)에서 추적한다. 이전 Compact 캡처는 이번 수정의 증거가 아니다.

- Today 전용 링은 외경104pt·획7pt, 카드 패딩14–16pt, 아이콘과 값4–6pt, 링과 설명12pt다. 접근성 글씨에서는 장식 링 없이 외부 점수를 읽고, CONDITION 제목과 상세 안내를 세로로 나눠 단어 중간 줄바꿈을 피한다. 다른 세 탭의 공통 링은 변경하지 않았다.
- 그래프의 플롯만 고정 높이이며 날짜·단위·범례는 자연 높이로 줄바꿈한다. Today 지표는 최대 두 열, 글씨가 xxLarge 이상이면 한 열, 홀수 마지막 카드는 전체 폭이다. 2026-10-28 후속 수정은 같은 행의 셀에 가장 큰 자연 높이를 제안해 카드 표면·내부 면까지 일치시킨다. 카드 전체 높이를 상수로 고정하지 않는다. 기존에 조회한 HRV/RHR·수면 기록에서 유효한 최근 관측만 작은 추세로 표시하고, 체중처럼 현재 요약에 이력이 없는 지표에는 가상 추세를 추가하지 않는다. 운동 종목 행의 조밀한 표시와 목적지는 유지한다.
- 지표에는 상대 측정 시점을 표시하고 접근성 이름에는 실제 날짜·시간을 포함한다. 동기화 시각과 측정 시각을 바꾸어 쓰지 않는다.
- 운영 기본 고정 항목은 HRV·RHR·수면 세 개지만 UI 테스트 시드는 HRV·RHR 두 개를 명시한다. 홀수 배치는 편집 화면에서 수면을 추가해 검증한다. 편집 행은 전체 폭·최소44pt 터치 영역과 실제 선택 상태를 제공한다.
- 실제 캡처는 측정 데이터가 있는 기본 글씨 T03, 고정 편집 T18을 대상으로 한다. 빈 기록·초기 로딩·모든 VoiceOver 조합을 새로 캡처했다고 주장하지 않는다. Duo 내부 가로는 orientation readback이 세로를 유지해 미검증이며 내부 세로 캡처와 구분한다.
