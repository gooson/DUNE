# 4탭 히어로 제목 표기

사용자 요청으로 각 탭 첫 히어로 카드의 상단 제목을 영어 대문자로 통일한다. Activity 최종 시안의 `READINESS`를 표현 기준으로 삼는다. 이번 문서는 디자인 개편의 공통 계약이며 앱 적용 완료 기록이 아니다.

| 탭 | 히어로 제목 | 설명하는 내용 |
|---|---|---|
| Today | CONDITION | 현재 컨디션 |
| Activity | READINESS | 운동 준비도 |
| Wellness | WELLNESS | 웰니스 상태 |
| Life | HABITS | 오늘 습관 진행 상황 |

- 제목은 카드 상단 왼쪽, 링 바깥에 놓는다. 작은 세미볼드와 약간 넓은 자간을 사용하고, 글씨 크기·상단 여백·정렬·색 역할을 네 탭에서 공유한다. DUNE에서는 현재 READINESS의 골드 톤을 따른다. 다른 테마에서는 같은 역할의 테마 색을 사용한다.
- 영어 대문자는 이 네 히어로의 분류 제목에 적용한다. 점수 해석, 상태, 근거, 날짜와 본문은 기존 사용자 언어로 유지한다. Life 완료 수/대상 수도 유지하며 점수로 바꾸지 않는다.
- 상세 목적지가 있는 제목은 바로 옆 4px chevron과 최소44pt 높이 헤더 터치를 사용한다. 목적지가 없는 제목에 화살표나 새 동작을 만들지 않는다. 실제 상세 화면의 제목은 사용자 언어를 따른다.
- 같은 분류 제목을 링 안에 중복 표시하지 않는다. 준비도 없음·기준선 형성·기록 없음 상태에서도 상단 제목은 유지하고 본문에서 상태를 설명한다.
- 접근성 이름은 의미를 사용자 언어로 전달한다. 큰 글씨에서도 제목을 숨기거나 작은 크기로 고정하지 않으며 날짜/상태와 겹치면 줄을 나눈다. 제목의 대문자 스타일이 링 크기나 점수 계산을 바꾸지 않는다.

현재 Today와 Activity 시안은 CONDITION/READINESS를 카드 상단에 사용한다. Wellness는 기존 링 캡션 WELLNESS를 상단으로 옮기고, Life는 오늘 진행 상황의 분류 제목 HABITS를 상단에 추가하는 후속 적용 대상이다. [4탭 배치 맵](index.html)에 목표 제목을 표시하고 [Activity 최종안](activity-final-proposal.md)에 공통 기준을 연결했다. 기존 실제 캡처와 이전 테마 방향 시안은 당시 상태의 증거로 보존한다.
