# WLA01 · Live Activity 크기·상태 시안

[인터랙티브 시안](../theme-map/themes/dune-live-activity-size-state.html) · [편집 원본](../theme-map/themes/assets/live-activity-size-state-fragment.html) · [현재 구현 계약](watch-workout-live-activity.md)

사용자가 첨부한 음악 동시 표시 상태를 출발점으로 만든 **브라우저 제안**이다. 사진만으로 minimal과 제한 폭 compact 중 어느 프레젠테이션인지 확정하지 않는다. 두 경로를 모두 제시한다. SwiftUI·ActivityKit 코드는 변경하지 않았으며 이 문서의 제안이 현재 구현 계약을 대체하지 않는다. 시안의 수치·카메라·음악 UI는 설명용이고 실제 앱·시스템 캡처가 아니다.

## 종목별 표시 취향 · 후속 반영

### 골드 임팩트 · 비주얼 강조안

후속 요청으로 **골드 임팩트**를 첫 번째 비교안에 추가했다. 기존 ‘내 선택’과 ‘심박 우선’은 보존한다. 유산소 km/웨이트 현재 세트 kg/시간/심박 선호와 데이터 유무는 세 방향에서 공유한다.

- **Expanded**: 시스템 검정 배경을 유지하고, 큰 금빛 수치·선택 지표 이름·입체 운동 심벌·구분된 보조 지표를 배치한다. 심벌은 금속 질감의 발자국/덤벨 그림이며 목표 달성 배지나 진행률이 아니다.
- **잠금 화면**: 브론즈와 밝은 골드의 빛, 두 겹의 모래 능선, 큰 값과 입체 심벌로 DUNE 표현을 강조한다. 밝음/어두움 색을 구분한다.
- **Small**: 큰 수치와 금빛 표면은 유지하고 입체 심벌은 생략해 공간을 확보한다. 긴 시간과 큰 글씨에서는 expanded/잠금 화면도 심벌을 빼고 수치를 우선한다.
- **Compact/minimal/28pt**: 시스템 검은 표면과 기존 영역 크기는 유지한다. 수치·기호의 금빛과 기호 굵기만 강화하며 장식으로 정보 영역을 넓히지 않는다.
- **상태**: 일시 정지는 멈춘 상태를 명시하고 심벌의 채도를 낮춘다. 연결 대기는 입체 심벌과 오래된 지표를 숨긴다. 종료는 제거한다. 가짜 경로·가짜 심박 파형·목표 없는 진행 링·반복 반짝임은 추가하지 않는다.

이 표현은 정적인 방향 시안이다. 실제 ActivityKit 지원 효과, Always-On 대비, 시스템 접근성, GPU/렌더링 비용은 후속 네이티브 검증 대상이다. 새 비주얼안의 한정된 브라우저 검사·이미지는 `live-activity-gold-qa.json` 및 `live-activity-gold-*.png`를 따르며 기존 종목별 취향 전체 검증 상태와 구분한다.

비주얼안의 한정 검사(최대 45초)는 Chrome 시작이 10초 안에 완료되지 않아 0건으로 중단했다. 새 PNG는 없으며 실행·시각 검증 통과를 주장하지 않는다. JavaScript 구문, 테마 맵 생성·동기화, diff 공백 검사는 통과했다. 환경 정상화 증거 없이 브라우저를 반복 실행하지 않는다.

사용자 요청에 따라 **핵심 지표를 하나로 고정하지 않고 종목별로 선택**하는 제안으로 갱신했다. 첫 시안의 ‘시간 우선 권장’은 고정 기본값 결정으로 사용하지 않는다. 현재 첫 화면은 거리 선택 예시이며 실제 앱 기본값이 아니다.

| 운동 | 먼저 볼 정보 | 시안 예시 |
|---|---|---|
| 거리를 제공하는 유산소 | 시간 / 거리 / 심박 | 누적 `4.20 km`, 28pt에서는 `4.2`와 `km`를 두 줄로 표시 |
| 웨이트 | 시간 / 현재 세트 중량 / 심박 | `60 kg`, 소수 `12.5 kg`도 유지. 제한 폭·minimal은 값과 `kg` 두 줄 |

‘내 선택’ 비교안에서 운동 종류와 먼저 볼 정보를 전환한다. 유산소·웨이트의 선호는 각각 기억하며 전환해도 다른 종목의 선택을 덮어쓰지 않는다. 대화에서는 widget state로 선택을 복원하고 보존 HTML에서는 검토 중 선택만 유지한다. 실제 앱 설정 저장소나 ActivityKit 갱신을 구현했다는 뜻은 아니다. 기존 심박 비교안도 유지한다.

- 거리는 **누적 거리**, 중량은 **현재 세트에 명시적으로 입력한 중량**이다. 누적 볼륨·최고 중량·다음 세트 예상 중량과 구분한다. 시안은 벤치 프레스 3세트와 60/12.5kg fixture다.
- 덤벨 한 손/양손 합계, 머신 스택, 체중/보조 중량의 해석은 실제 입력 모델에 맞춰야 한다. 입력 의미 확인 없이 환산하지 않는다. 거리 없는 유산소에는 거리 선택을 제공하지 않는 것이 후속 계약이다.
- 선택한 값이 미수신/미입력일 때만 시간으로 전환한다. 수신한 `0.00 km`, 명시적으로 입력한 `0 kg`는 0을 표시하며 미수신·맨몸으로 바꾸지 않는다.
- 일반 compact는 값과 단위, minimal/28pt는 값 위·단위 아래로 표시한다. 거리의 제한 폭은 소수 한 자리로 반올림하되 원래 값은 펼침과 접근성 이름에 남긴다. 중량 소수는 임의로 버리지 않는다.
- 일시 정지의 compact에는 고정 거리/중량을 남길 수 있으며 minimal은 정지 기호가 우선한다. 연결 대기는 모든 오래된 지표를 숨기고, 종료는 기존처럼 제거한다.
- 현재 Watch snapshot에는 현재 세트 중량 전달이 없다. 거리/중량 선호 저장·단위 설정 연동·현재 세트 식별과 실시간 중량 전달은 **후속 네이티브 구현 과제**다. 데이터가 없는 상태에서 마지막 기록의 중량을 현재 세트 값으로 쓰지 않는다.

## 초기 비교 기준

아래 시간/심박 표는 선택 가능한 각 모드의 크기 기준이다. 최신 첫 비교안은 위 ‘내 선택’으로 바꿨으며 시간 고정안이 아니다.

- **시간 선택**: 일반 compact의 운동 기호·정확한 시간, 일반 minimal의 시간, 제한 폭의 짧은 경과 분·시간을 연결한다. 운동 종료 시각이나 목표를 모르는 상황에서 임의 진행 링은 사용하지 않는다.
- **심박 우선(비교안)**: 일반 compact는 심장 기호·심박수, minimal은 심장 기호와 수치, 펼침·잠금 화면은 심박을 주 정보로 두고 시간을 보조한다. 심박 미수신이면 시간으로 전환한다. 실시간 강도 관찰을 우선하는 별도 선택이며 기본안으로 확정하지 않았다.

두 방향에서 크기 6개를 함께 보고 진행·일시 정지·연결 대기·종료를 전환한다. 45초·23분 14초·1시간 20분 45초·12시간 2분, 심박 미수신, 밝음/어두움, 긴 근력 운동명, 본문 글씨 확대를 비교한다. 브라우저에서는 확정된 fixture를 표시하며 임의로 계속 증가시키지 않는다.

## 크기 계약

| 표면 | 시간 우선 | 심박 우선 | 크기 해석 |
|---|---|---|---|
| 일반 compact | 운동/정지 기호 + `23:14` | 심장 기호 + `142` | 기기별 leading/trailing 제안 영역. 카메라 폭과 바깥 캡슐은 모식도다. |
| 제한 폭 compact | leading 운동 기호 + trailing `23′` | leading 심장 기호 + trailing `142` | 각 내용 영역을 **28×28pt 원** 안에 맞춘다. 숫자만 있는 trailing도 leading과 한 의미로 읽는다. |
| 일반 minimal | `23:14`; 한 시간 이상 `1h20` | 심장 기호 + `142` | HIG에 제시된 **폭 36.67–45pt, 높이 36.67pt** 범위 중 시안은 45pt 폭을 사용한다. 36.67pt 최소 폭은 네이티브 검증 필요다. |
| 제한 폭 minimal | `23′`, `45″`, `1h` | 작은 심장 기호와 `142` | **28×28pt**. 단위는 내림한 경과량이다. 정확한 시간은 펼침에서 확인한다. |
| expanded | 운동명·DUNE·상태 → 시간 → 지표 | 운동명·DUNE·상태 → 심박 → 시간·지표 | 검은 시스템 표면. 시안은 최대 340 CSS px 내에서 재배치하며 실제 기기 외경 치수로 주장하지 않는다. |
| 잠금 화면 / small | 기존 따뜻한 표면·시간 위계 | 심박 강조·시간 보조 | small은 family 배치 연구다. Watch·CarPlay 호스트 프레임 재현이나 인증이 아니다. |

시안은 일반 compact, 제한 compact, minimal, expanded, 잠금 화면, small의 6개 패널이다. minimal 안에서는 일반/제한 폭을 나란히 비교한다. 1 CSS px를 배치 연구의 1pt로 사용하며 모니터 배율·브라우저 축척을 실제 기기 크기로 보장하지 않는다. narrow 브라우저에서는 패널을 세로로 쌓으며 Island 콘텐츠를 무조건 축소하지 않는다.

## 상태 계약

| 상태 | compact | minimal | 펼침·잠금 화면·small |
|---|---|---|---|
| 진행 | 선택한 우선 정보 | 선택한 우선 정보 | 유효 수치만 표시 |
| 일시 정지 | 정지 기호 + 고정 시간 | 정지 기호 우선 | 일시 정지 상태와 고정 누적 시간. 마지막 지표는 진행 중 수신값으로 오해하지 않게 네이티브 접근성 검토 필요 |
| 연결 대기 | 연결 끊김 기호 + trailing 생략 | 연결 끊김 기호 | 운동명·DUNE·Watch 연결 대기. 오래된 시간·심박·칼로리·거리는 숨김 |
| 종료 | DUNE 액티비티 제거 | 제거 | 제거. 연결 대기나 완료 카드로 계속 남기지 않음 |

심박 미수신은 0으로 치환하지 않는다. 진행 중 심박 우선안은 시간으로 전환한다. `23′`는 23분, `45″`는 45초 경과이며 목표 잔여 시간이 아니다. 제한 폭에서 100분 이상은 누적 정수 시간(`1h`, `12h`)으로 내림 표시한다. 일반 minimal의 `1h20`은 1시간 20분이다. 접근성 이름에는 축약 전 경과 시간을 제공한다. 초 단위 타이머와 분·시간 축약의 시스템 자동 갱신 API는 네이티브 적용 단계에서 별도 검증한다.

단순한 한 번 탭은 관련 앱 진입, 길게 누름은 expanded라는 기존 동작을 유지하는 제안이다. 시안의 상태 선택기는 검토 도구이며 앱 컨트롤이나 Live Activity 내 운동 제어 기능이 아니다. 실제 구현에 없는 재개·종료 버튼은 추가하지 않는다.

## 최신 공식 근거

확인일 2026-10-30. 발행·개정일과 구분한다.

- [Live Activities HIG](https://developer.apple.com/design/human-interface-guidelines/live-activities): **2026-10-13 개정**. 제한 폭의 28pt 원 기준, 일반 minimal 치수, 핵심 동적 정보, 카메라 주변 배치와 검은 시스템 표면.
- [Displaying live data with Live Activities](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities): 동시 활동 표시 방식은 기기별로 다르며 compact·제한 compact·minimal 모두 가능하다. 제한 폭에서 leading만 남기고 trailing을 비우는 fallback도 허용한다. 현재 코드의 시간 숨김을 API 오류로 판정하지 않는다.
- [isDynamicIslandLimitedInWidth](https://developer.apple.com/documentation/swiftui/environmentvalues/isdynamicislandlimitedinwidth): iOS 27+에서 제한 폭 compact/minimal에 대응하며 가로 방향·Duo 등을 포함한다.
- [WWDC26 · Live Activities essentials](https://developer.apple.com/videos/play/wwdc2026/223/): 위치별 핵심 정보 선택, 제한 폭 대체 뷰, small family 적응.

## 검증과 남은 범위

브라우저 검증 결과와 렌더링 PNG는 `../theme-map/themes/assets/live-activity-size-state-qa.json`, `live-activity-size-state-*.png`에 보존한다. PNG는 이 제안의 브라우저 렌더링이다. 테마 맵 동기화는 `python3 docs/design/theme-map/build-theme-map.py --check`로 확인한다.

### 종목별 취향 후속 검증
