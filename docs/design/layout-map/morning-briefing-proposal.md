# T09 · 아침 브리핑 배치 계약

2026-10-31 승인된 T09 시안의 네이티브 구현 기준이다. 이 문서는 제안과 구현 배치를 설명하며 실제 앱 캡처가 아니다.

## 순서와 동작

1. 일출 히어로: 기기 로컬 06:00–09:59에는 기존 `Good Morning`, 수동으로 연 그 외 시간에는 `Morning Briefing` 제목을 사용한다. `Done` 완료 동작을 유지한다. 태양·빛·구름·모래 능선은 장식이며 건강 상태를 암시하지 않는다.
2. 회복 요약: `heart.text.clipboard`, 실제 컨디션·수면 요약 및 원본 템플릿 문장.
3. 오늘의 가이드: `figure.run.circle`, 원본 권장 문장.
4. 주간 맥락: `chart.bar.fill`, 원본 주간 운동 문장.
5. 날씨: 원래 제목과 메시지가 모두 있을 때만 `cloud.sun.fill` 카드 표시. 없는 경우 빈 카드나 날씨 수치를 만들지 않는다.

초기 보존 시안의 각 카드는 고유한 정적 그림(회복의 심장·맥, 가이드의 움직임 궤적, 주간의 추상 능선, 날씨의 구름)을 갖는다. 주간 그림에는 수치형 막대를 사용하지 않으며 날씨 장식은 실제 하늘 상태를 주장하지 않는다. 원래 `chart.bar.fill`과 `cloud.sun.fill` 아이콘은 유지한다. 원본 데이터 생성·추천·표시 조건·오늘 한 번 표시·닫기 생명주기는 유지한다.

## 2026-11-03 · 정보 강조안 선택

사용자가 두 시안 중 **1번 정보 강조**를 선택했다. 일출 헤더는 기본 글씨에서126pt, 큰 글씨에서는 자연 확장을 허용한다. 카드의 큰 장식 배너를 제거하고 원래 SF Symbol을 작은 분류 아이콘으로 유지한다. 제목은 title3.bold, 본문은 body와 primary 전경색, 3pt 줄 간격을 사용한다. 회복은 실제 수면 시간과 어제 대비 HRV를 label/value로 분리하고 같은 문장을 본문으로 반복하지 않는다. 추가 RHR 변화가 있으면 본문으로 유지하며 두 지표가 모두 없으면 기존 점수 안내를 표시한다. nil은0으로 만들지 않는다. 주간은 실제 운동 일수/목표와 평균 컨디션을 크게 표시하고 남은 목표 일수 또는 완료 상태를 별도로 표시한다. 진행 막대는 실제 목표가 있을 때만 표시한다. 가이드와 조건부 날씨는 원래 템플릿을 유지한다.

기본 글씨에서는 지표를 나란히, 접근성 글씨에서는 label/value를 한 열로 배치해 읽기 폭을 확보한다. 시안의 예시값은 앱에 하드코딩하지 않는다. 새 네이티브 캡처로 확인하기 전에는 기존 PNG를 이번 구현 증거로 사용하지 않는다.

## 폭·접근성·검증

좁은 iPhone과 Duo 접힘에서 한 열로 스크롤한다. iPad와 Duo 펼침에서는 읽기 폭을 제한하고 카드 순서를 유지한다. 접근성 글씨에서는 두 지표를 세로로 배치하고 제목·값·본문을 자연 확장한다. 분류 아이콘은 VoiceOver에서 제외하고 인사말과 카드 제목은 접근성 제목으로 탐색한다. 각 지표의 레이블과 값을 하나의 요소로 읽는다. 밝음·어두움은 현재 테마 토큰을 사용한다. Reduce Motion은 즉시 표시하고 일반 환경의 기존 stagger는 화면 활성 중에만 진행한다.

실제 화면 맵 T09의 기존 iPhone·iPad·Duo 이미지는 이전 구현의 캡처이며 새 구현 증거로 사용하지 않는다. 대상 기기에서 새 PNG와 출처를 수집할 때만 갱신한다.
