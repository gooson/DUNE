‹지난 기록Save
원본 아이콘
지난 기록선택한 습관의 원본 아이콘 + 현재 선택 날짜
원본 정보 순서Habit → Record Date → Total for the day → 기록 영향 / 다음 예정일 → validation error. 대상 없음은 원래 ContentUnavailableView.
동작 계약Cancel은 닫기, Save는 기존 onSave. 날짜 범위, 값 0의 제거 의미, count/duration 상한, 반복 예정일 미리보기 유지.
접근성 크기제목·값은 자연 줄바꿈. 아이콘 배지는 최소 크기만 지정하고 콘텐츠 높이는 제한하지 않음. 기존 Form/List/ScrollView로 아래 내용을 탐색.

기존 문자·아이콘·입력·알림·일정·저장 경로를 유지한 채 위계와 가독성을 강화한다. 기기별 실제 검토 후 실제 화면 맵을 별도로 갱신한다.
