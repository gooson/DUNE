H07 · 자세 기록 열기 / P06 · 자세 기록 상세

Wellness 최근 기록과 자세 이력은 같은 PostureDetailView를 엽니다. DUNE 정적 시안은 실제 건강 기록이나 앱 캡처가 아닙니다.

읽기 순서

  1. 원래 저장된 자세 점수와 부분 평가 표시
  2. Assessment Details: 기록에 있는 지표 이름·값·단위·상태·신뢰도
  3. Front / Side 사진 또는 작은 자리표시자
  4. 교정 운동과 조건부 좌우 비교
  5. 기록 메모와 삭제
측정값기록의 front/side metric 배열만 사용합니다. 기존 SF Symbol과 상태색으로 실제 항목을 시각화하되, 밝은 화면의 아이콘과 상태 글자만 기존 상태색을 검정과 섞어 더 진하게 표시하며 어두운 화면과 배경색은 유지합니다. 실제 대비는 새 네이티브 캡처에서 확인합니다. 새 점수·각도·의학적 기준을 만들지 않습니다. 항목이 없으면 Assessment Details 제목과 기존 현지화 문구 Unable to measure를 표시하고 값을 채워 넣지 않습니다.
사진과 관절실제 저장된 사진이 있으면 전체 비율·탭 확대·기존 관절 오버레이를 유지합니다. 사진이 없으면 Front/Side 구분과 작은 자리표시자를 유지합니다. 테스트용 시스템 기호 이미지는 실제 촬영 사진이 아닙니다.
행동원래 PDF 생성과 공유, 좌우 비교, 교정 운동, 메모, 삭제 확인, 뒤로 가기를 유지합니다. 3D 근육 메뉴는 추가하지 않습니다.
검증H07 직접 경로와 P06 이력 경로를 각각 일반 iPhone·iPad·Duo 접힘/펼침의 실제 PNG/AX로 확인합니다. Duo MAX에서는 기존 접힘 점수 검사 중 각 자세의 Assessment Details로 이동해 상단과 아래 타일을 캡처합니다. 이 문서는 구현 전 배치 계약이며 네이티브 통과 증거가 아닙니다.
