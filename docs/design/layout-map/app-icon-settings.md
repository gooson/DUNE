# 앱 아이콘 선택과 테마별 시작 화면

사용자가 승인한 형태82(인터리브)·71(오션글라스)·87(네거티브 플로)를 설정에서 선택한다. 기본은82/P04다. 형태 선택은 테마와 독립적으로 저장하며, 다른 테마에서는 형태를 유지하고 팔레트만 자동으로 바꾼다.

S08 진입은 설정 → 외관 → 앱 아이콘이다. 세 선택 항목은72pt 미리보기·이름·선택 표시를 세로로 배치하고 Dynamic Type에 맞춰 높이가 늘어난다. 아래에는220pt 시작 화면 미리보기와 현재 테마·팔레트를 표시한다. 가로3열의 작은 레이블은 사용하지 않는다.

| 테마 | 팔레트 |
|---|---|
| DUNE / desertWarm | P04 코럴 × 샌드 |
| OCEAN | P02 민트 × 페리윙클 |
| FOREST | P03 세이지 × 크림 |
| SAKURA | P07 로즈 × 플럼 |
| ARCTIC | P05 아이스 × 데님 |
| SOLAR | P11 울트라마린 × 코럴 |
| CONTOUR | P06 모스 × 제이드 |
| WATER LILIES | P13 바이올렛 × 민트 |

UIKit 아이콘 요청은 직렬화하고 진행 중에는 마지막 형태·테마 조합을 유지한다. 포그라운드 진입 때 현재 설정과 다시 맞추며 실패하면 재시도 동작을 제공한다. 기본 AppIcon은82/P04이고 대체 아이콘23개·미리보기24개·투명 시작 로고24개를 번들에 포함한다. 홈 화면 원본은 불투명 사각형이며 시스템이 마스크를 적용한다. 시작 화면은 별도 투명 전경을 사용해 로고 주위에 사각 바탕이 보이지 않게 한다.

앱의 SwiftUI 스플래시는 저장한 형태와 테마를 따른다. 앱 프로세스 실행 전 iOS 정적 시작 화면은 앱 환경설정을 읽을 수 없어82/P04를 사용한다. 두 경로 모두 기존 로고에서 변경했다.

영향 화면은 T01 시작, S01 설정의 외관 항목, 신규 S08 아이콘 선택이다. 관련 단위 검사는 승인 형태·기본값·저장·번들 자산 매핑을 확인한다. iPhone·iPad UI 검사는 선택·재실행·테마 전환·세 스플래시를 확인한다. 최신 main 통합 후 캡처와 통합 전 기록을 [실제 화면 갤러리](../phone-design-map/actual/app-icon-2026-11-16/index.html)에서 구분한다.

Duo 접힘·펼침의 T01·S01·S08, 실물 기기 홈 화면과 시스템 아이콘 표현별 검증은 11월 16일 작업 범위에 포함하지 않았다. 11월 19일부터 Watch 배포 아이콘도 iOS 기본 82/P04 원본을 사용하며 watchOS가 원형 마스크를 적용한다. iOS 설정의 형태·테마 선택은 iOS 아이콘에 적용된다.
