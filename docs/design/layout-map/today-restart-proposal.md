# Today 재설계 방향 시안

T03의 배치를 처음부터 재검토하는 제안이다. [세 방향 시안](../theme-map/themes/dune-today-restart.html)은 예시 데이터로 만든 브라우저 프로토타입이며, 현재 앱 구현·실제 캡처·최종 승인안이 아니다. 기존 DUNE(Desert Warm) 테마의 색·모래 능선·밝음/어두움 표현은 유지한다. 세 시안은 테마가 아닌 배치 대안이다. 기존 4탭 배치 계약을 대체하는 시점은 방향 승인 후 정한다. 다른 탭의 개편은 이번 범위 밖이다. Today 안의 전체 섹션과 상태는 [전체 상태·배치 계약](today-case-matrix.md)에 확장했다.

## 기존 구현에서 확인한 문제

- `DashboardView.swift`: 시스템 큰 제목 뒤에 상단 패딩, 카드 간 20/24pt 간격이 더해진다. 첨부 화면의 제목 영역은 높지만 실제 기기의 글씨 설정과 상단 스크롤 위치는 확인하지 않았으므로 단일 원인으로 확정하지 않는다.
- `DesertHorizonConditionHeroView.swift`: 124pt 링, 설명, 구분선, 추세, 근거, 독립 44pt 상세 행을 18pt 간격·21pt 패딩으로 쌓는다. 상세 진입이 카드 전체 링크와 시각적으로 중복된다.
- 같은 파일에서 기본 글씨는 링 옆 설명, 접근성 글씨는 링 위·설명 아래로 전환한다. 고정 장식과 커지는 글씨의 높이 변화가 함께 나타난다.
- `RecoverySleepCard.swift`: 24pt 내부 패딩·20pt 섹션 간격·수면 시간·날짜·부채·그래프·근거·상세 행이 누적된다. 수면 그래프 높이는 `@ScaledMetric`으로 글씨에 비례해 커진다.
- 이전 읽기 위계 V2는 수치·상태·근거를 구별했지만, 이 방식의 세로 길이와 큰 글씨 전환을 다시 설계할 필요가 있다. 과거 [해결 기록](../../solutions/general/2026-10-25-today-reading-hierarchy.md)을 참고한다.

## 방향

사용자가 2026-10-26 기본 테마 유지를 명시했다. 초기 탐색에서 사용한 올리브·청록 팔레트는 폐기하고, 보존된 `dune-final-four-tab.html`의 DUNE 밝음/어두움 배경·표면·능선 수식·링 색을 공통 기준으로 재사용했다. 앱 테마 기본값과 테마 선택은 변경하지 않는다.

| 시안 | 배치 | 표현 |
|---|---|---|
| Compact | 작은 컨디션 링과 요약 → 낮은 추세 → 근거 2개 → 수면 → 스트레스 → 활동 | 기존 브라운 표면·금빛 링·모래 능선, 다층 그라데이션과 얕은 그림자 |
| Metrics | 큰 점수와 가로 게이지 → 동일한 Today 전체 흐름 | 기존 브라운·골드 계기판, 작은 추세선, 낮은 카드, 높은 지표 밀도 |
| Editorial | 카드 밖 열린 점수 헤더 → 동일한 Today 전체 흐름 | 같은 DUNE 표면과 배경 위 열린 헤더·얇은 지평선·타이포그래피 대비 |

V1은 기존 흐름을 보존하는 작은 링 구성, V2는 숫자·계기판 구성으로 대비하며 Editorial은 열린 편집형 대안이다. 방향 이름은 순위를 뜻하지 않는다. 추천 시작점은 Compact다.

## 정보와 행동

- 컨디션 점수·상태·요약을 첫 영역에서 함께 읽는다. 상세 전체 내용은 네이티브 컨디션 상세로 연결하는 것이 목표다.
- 회복·수면은 수면 시간과 날짜, 부채를 가깝게 둔다. 세 시안 모두 현재 제공되는 수면 총량·7일 표본의 짧은 막대를 사용한다. 새로운 수면 단계나 구간을 임의 생성하지 않는다.
- 근거는 HRV/RHR 기준선 대비 변화량을 명확한 단위와 함께 표시한다. 스트레스는 최근 기록 기반 추정이라는 한계를 함께 표시한다.
- 활동 목표와 진행률, 브리프, 나머지 지표는 아래 흐름에 둔다. 코칭·날씨·저녁 요약·고정 지표·기존 운동·신체 지표·Q&A도 최하단까지 포함한다. 시간대 조건과 실제 현재 데이터 계약은 전체 상태·배치 계약에서 대조한다.
- 상세 화살표는 시안 안의 실제 구성 화면으로 연결된다. 근거·이전 운동은 펼침, 고정은 체크박스 편집, 인사이트는 닫기로 확인한다. 알림의 읽음과 템플릿·체중 입력은 시안 안의 로컬 동작이다. 실제 앱 데이터·설정은 변경하지 않는다.

## 글자 크기와 밀도 계약

아래 수치는 제안한 디자인 값이며 Apple의 필수 규격을 뜻하지 않는다.

- 본문 좌우 16pt, 카드 내부 14–16pt, 카드 간 10–12pt로 공간을 관리한다.
- 글자 확대가 패딩·모서리·장식·그래프 높이를 함께 확대하지 않는다. 그래프의 단위·기간 레이블은 별도 행에서 줄바꿈한다.
- 기본 링은 104pt. 큰 글씨에서는 링을 제거하고 `컨디션 52점`을 설명 앞에 별도 텍스트로 노출한다. 장식 원을 위아래로 쌓아서 높이를 늘리지 않는다.
- 큰 글씨에서 2열 지표는 1열로, 근거는 세로로 전환한다. 내용 증가만큼 카드 높이가 자연스럽게 늘어난다. 동일 높이 고정·본문 축소·잘라내기를 사용하지 않는다.
- 프로토타입은 100–200% 글자 확대와 320–1032pt 폭을 비교한다. 이것은 네이티브 Dynamic Type의 모든 접근성 단계 검증을 대신하지 않는다.
- 탭 바는 시안의 콘텐츠 뒤에 배치해 내용을 가리지 않는다. 구현에서는 native 탭 바와 safe area를 사용하고 마지막 행이 탭 바에 덮이지 않게 한다.
- 기록 없음에서는 값·추세·진행률과 하위 카드를 숨기고 첫 영역에 기록 안내를 한 번 표시한다. 0점/0시간을 관측값처럼 생성하지 않는다.

## 표현 근거

- [Apple의 디자인 안내](https://www.apple.com/au/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/): 반사·깊이·유리 표현은 컨트롤과 탐색을 돋보이게 한다. 본문 숫자는 안정적인 표면에서 읽는 방향으로 해석했다.
- [Oura의 앱 재설계](https://ouraring.com/blog/sv/new-app-design/): Today에서 지금 가장 중요한 정보에 초점을 맞춘다. 점수·수면·근거가 한눈에 읽히는 위계의 참고이며 외형 복제는 아니다.

## 범위와 검증

영향 대상은 T03 전체 방향 시안이다. iPhone·Duo 접힘/펼침·iPad 폭과 큰 글씨 배치를 브라우저에서 비교한다. Watch 개편은 포함하지 않는다. 앱 소스·번역 카탈로그·빌드는 변경하지 않으므로 실제 화면 디자인맵은 갱신하지 않았다. 현재 시안을 앱 캡처로 등록하지 않는다.

편집 원본은 `theme-map/themes/assets/today-restart-fragment.html`, 대화 미리보기와 같은 내용으로 보존한다. 세 방향의 기본·밝음/어두움·큰 글씨·기록 없음과 [전체 상태](today-case-matrix.md)를 브라우저에서 확인하고 테마 맵 생성기 `--check`로 등록 동기화를 검사한다. 세부 브라우저 검증 결과는 이 문서 끝에 기록한다.

### 브라우저 확인 결과

- [범위와 원시 결과](../theme-map/themes/assets/today-restart-qa.json): 배치 162조합, 상태/시간대 144조합, 점수/목표 경계 4조합을 확인했다. 이 최초 행렬의 넓은 화면·큰 영어 글씨 4건과 영어 문구 누락은 수정 후 해당 범위만 다시 확인했다. 최종 소스 전체에 같은 행렬을 재실행했다고 주장하지 않는다.
- 시간대 144조합의 어제 요약·오늘의 진행·브리프·일간 요약 조건은 현재 코드 계약과 일치했다.
- 키보드로 고정 편집/그룹 복귀·인사이트 닫기·알림 읽음·이전 운동 펼침을 확인했다. 체중의 유효/범위 밖 입력은 로컬 확인 버튼 수정 후 확인했다.
- 중첩 iframe 미리보기의 긴 포인터 시퀀스는 고정 편집 진입에서 두 차례 타임아웃이 발생해 그 경로를 중단했다. 저장용 문서에서 중첩 프레임을 제거한 뒤 스트레스 근거·고정 편집·닫기·알림·이전 운동·체중 입력의 실제 클릭을 확인했다. 캡처도 이 저장용 문서에서 새로 만들었다.
- 보존 이미지는 [Compact](../theme-map/themes/assets/today-restart-compact.png) · [Metrics](../theme-map/themes/assets/today-restart-metrics.png) · [Editorial](../theme-map/themes/assets/today-restart-editorial.png). 세 이미지 모두 **브라우저 시안**이며 앱 캡처가 아니다.
- Metrics·Editorial도 컨디션 추세를 보존한다. 마지막 보완 뒤 추가 헤더의 폭/큰 글씨/언어 6건, 0·52·100점의 그래프 끝점 9건, 단일 기록에서 그래프 숨김 2건을 한정해 확인하고 세 보존 이미지를 새로 만들었다.
- 실제 SwiftUI·Dynamic Type 전체 크기·VoiceOver·탭 바 겹침·회전 검증은 구현 이후 필요하다. 앱 코드와 실제 캡처 맵은 이번 작업에서 변경하지 않았다.

### 나란히 비교

사용자의 2026-10-26 요청에 따라 [세 시안 동시 비교](../theme-map/themes/dune-today-comparison.html)를 추가했다. 개별 [전환형 시안](../theme-map/themes/dune-today-restart.html)도 유지한다. 세 화면에 같은 글씨·시간대·기록 상태를 적용하며 한 페이지에서 함께 스크롤한다. 좁은 창은 비교 영역만 좌우 이동하고 본문 글씨를 강제로 축소하지 않는다. 시안의 앱 내용·기본 DUNE 테마는 변경하지 않았다.

## Compact 선택과 링 수정 (2026-10-26)

사용자는 Today에 Compact를 선택했다. Metrics·Editorial은 비교 자료이며 세 안의 하단 구성은 공통이다. Activity·Wellness·Life는 아직 개편하지 않았다. [구현 계획](../../plans/2026-10-26-today-compact-layout-and-ring.md)에 순서와 검증 기준을 확정했다.

시안 링은 외경104pt·획7pt·내부지름90pt로 고정하고 점수를 정중앙에 둔다. CONDITION은 같은 카드 상단에 유지한다. 86pt 축소를 제거하며 큰 글씨는 외부 점수로 전환한다. 0점에서는 진행 호를 숨긴다. 아이콘–숫자4–6pt, 링–설명12pt, 카드 패딩14–16pt를 기준으로 여백을 불필요하게 늘리지 않는다. 이 수정은 브라우저 시안에 반영했고 SwiftUI 적용은 아직 계획 단계다.
