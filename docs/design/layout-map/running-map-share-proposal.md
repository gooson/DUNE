# 러닝 지도와 공유 카드 다섯 방향

사용자가 선택한 중심은 **경로 기록과 예쁜 공유 카드**다. 땅의 소유·탈취 대신 달린 길과 개인 업적을 남긴다. 아래 다섯 방향은 승인 전 시안이며 앱 화면·실제 건강 데이터·실행 캡처가 아니다.

## 공통 화면 계약

- 진입: Activity의 러닝 기록 → 운동 상세의 경로 영역 → 경로 전체 보기 또는 공유 카드 만들기. 다섯 번째 루트 탭을 추가하지 않는다.
- 상세 상단의 운동명·날짜·거리·시간·페이스와 기존 심박·구간·날씨는 상세 개편 브랜치가 소유한다. 이번 제안은 지도 콘텐츠와 공유 편집 시트에 한정한다.
- 데이터 상태는 실제 실외 경로, 장소 핀이 있는 실내 기록, 거리 기반 가상 여정, 경로 미수신/권한 거부/기록 없음으로 나눈다. 경로가 없는 실외 기록을 실내 기록으로 분류하지 않는다.
- 실내 트랙은 랩/센서 기록이 있으면 제공한다. 시설의 실측 경로 없이 타원형 트랙이나 GPS 방향을 만들어내지 않는다. 러닝머신은 이동 경로선을 만들지 않지만 운동한 헬스장/시설을 장소 지도와 핀으로 표시한다.
- 지도에는 북쪽 기준, 경로 진행 화살표와 S/F 표식을 제공한다. 화살표는 기록 순서에서 구하고 휴대폰 방향 센서를 경로 진행 방향으로 쓰지 않는다. 시작·종료 숨김을 켜면 해당 표식도 제거한다.
- 공유용 숨김은 경로 geometry에서 적용한다. 배경·구간 표식·리플레이·업적 위치·장소명도 같은 공개 범위를 사용한다. 전체 기록 수치와 공개 경로 길이는 다를 수 있다.

## 다섯 구성

| 방향 | 위에서 아래로 읽는 순서 | 지도 표현 | 공유 핵심 | 업적 |
|---|---|---|---|---|
| Atlas / 아틀라스 | 날짜·장소 → 대형 지도 → 거리·시간·페이스 | 아이보리/브라운 도로, 세이지 공원, 골드 경로, 절제된 지명 | 여백이 있는 지도 포스터 | 하단의 선택형 작은 표식 |
| Pace Ribbon / 페이스 리본 | 큰 거리·평균 페이스 → 구간색 지도 → 구간 기록 | 구간별 색과 숫자/범례·방향 화살표 | 운동의 흐름이 읽히는 데이터 포스터 | 검증된 구간·같은 코스 PR |
| Route Signature / 루트 시그니처 | 작은 제목 → 경로 모양 → 큰 거리 → 기록 | 배경 지도를 빼고 실제 경로의 형태를 보존 | 굵은 골드 경로와 큰 숫자, 후속 투명 PNG | 대표 개인 기록 하나 |
| Journey / 저니 | 가상 여정 이름 → 여정 지도 → 누적 진행·이번 운동 | 실제 지리를 배경으로 한 별도의 가상 진행선 | 엽서와 거리 기반 완주 스탬프 | 실내·실외 공통 거리 목표 |
| Passport / 패스포트 | 수집한 업적 → 기록 지도 → 날짜·수치 | 단일 운동 또는 선택 기간 누적 경로 | 장소와 성취를 모은 기록장 | 첫 5K, 누적 거리, 처음 달린 길 |

Journey는 실내 거리의 활용안이고 Atlas/Pace/Signature는 실외 기록·공유의 우선 비교안이다. Passport는 기본 상세의 많은 배지 대신 별도 모음/공유 모드로 둔다. 각 안의 실내 상태에서 관측하지 않은 실제 위치 업적을 발급하지 않는다.

## 반응형과 조작

- iPhone/접힌 Duo: 지도 위아래로 기록과 공유 제어를 배치한다. iPad/펼친 Duo: 같은 정보를 지도+측면 기록으로 재배치한다. 화면 전체를 축소한 폰 프레임을 사용하지 않는다.
- 시안은 320px부터 넓은 폭까지 확인한다. 글씨 확대 시 제목·기록을 줄바꿈하고 3열 수치를 1열로 전환한다. 지도 라벨의 수를 줄이고 경로 geometry의 비율은 유지한다.
- 비교 시안에서 다섯 방향, 운동 상세/공유 카드, 실외/실내/경로 미수신, 밝음/어두움, 글씨 크기, 공유 비율을 확인한다. 공유 카드는 화면에 바로 미리 보이며 사진 보관함이나 앱 데이터를 저장하지 않는다.
- 실제 내보내기 제안: 피드 1080×1350, 스토리 1080×1920, 정사각 1080×1080. 포맷 변경은 재배치하며 경로·로고·출처를 자르지 않는다. 투명 PNG는 Signature 후속 범위다.

## 구현 전 확인

실외 GPS 거리 계산은 있지만 좌표열 보존·HealthKit route 읽기/쓰기·지도 공유는 아직 없다. 경로가 있는 기존 운동부터 보여 주는 것과 앞으로의 운동을 기록하는 것은 각각 데이터 작업이 필요하다. [조사와 범위](../../brainstorms/2026-10-29-running-map-sharing-achievements.md)를 기준으로 선택한 안의 구현 계획을 작성한다.

## 보존본과 검증

[다섯 시안](../theme-map/themes/dune-running-map-sharing.html), 편집 원본 `../theme-map/themes/assets/running-map-sharing-fragment.html`. 지도 배경의 공개 데이터 출처와 설명용 경로의 생성 방법은 같은 assets의 provenance 파일에 기록한다. 앱 UI는 변경하지 않으므로 이번에 실제 화면 디자인맵을 새 캡처로 갱신하지 않는다.

브라우저의 비율 버튼은 출력별 구성과 여백을 탐색한다. 현재 미리보기는 읽기 크기를 유지하기 위해 내용 높이에 맞춰 늘어나며, 고정 픽셀 크기의 PNG 내보내기는 구현 범위에 남아 있다.

2026-10-29 브라우저 검증: 초기185개 배치 상태 중 영향 없는179개 측정은 재사용했다. 320px Passport의 스탬프 최소 너비를 수정한 뒤 해당6상태와 큰 글씨1상태를 확인했다. 최종 오류·잘림은 없었고 실제 캐러셀 전환·기록/화면 선택·공개 경로 geometry 변경·포맷 구성 변경을 확인했다. 최종 소스 hash와 한정 재검증 범위는 `running-map-sharing-qa.json`에 있다. 별도 카드 보기 모달은 제거하여 공유 결과를 편집 화면에 바로 표시한다. 고정 픽셀 PNG와 네이티브 앱은 미검증이다.

## 실내 장소 지도 보완 · 2026-10-29

사용자가 “실내 러닝도 지도로 어딘지 표시할 수 있지 않나”라고 지적했다. 실내에 이동 경로가 없다는 것과 장소를 표시할 수 없다는 것은 다르다. 모든 안의 실내 상태에 운동 장소 지도와 핀을 추가했다. 실내에서도 실제 장소를 보여주며 가상 여정과 구분한다.

- 위치 접근이 가능하면 운동 시작/종료 시점의 단발 위치를 장소 후보로 사용하고 사용자가 확인/보정한다. GPS가 약하거나 권한을 주지 않아도 직접 장소를 선택할 수 있다.
- ‘현재 위치’·‘기기에서 받은 추정 위치’·‘직접 선택한 장소’를 구분한다. 시설 중심점을 선택했다고 실내의 정확한 위치나 실제 방문이 센서로 검증된 것으로 표현하지 않는다.
- 상세에는 장소 지도/이름/원천을 표시한다. 공유에는 별도 ‘운동 장소 공유’를 두며 끄면 핀뿐 아니라 지도 배경과 장소명도 제외한다. 개인 기록의 장소는 보존한다.
- Journey의 실내 공유는 가상 진행 지도와 별도로 작은 실제 운동 장소 지도를 둔다. 가상 완주가 실제 방문 업적이 되지 않는다.
- 예시 두 장소는 OSM의 성동구민종합체육센터와 서울숲복합문화센터 건물 중심점이다. 실제 사용자 위치·운동 기록을 읽지 않았으며 시설에서 러닝머신을 제공한다는 안내나 추천이 아니다. 출처는 `running-map-venues.json`이다.
- 후속 검증은 `running-map-indoor-qa.json`을 따른다. 앞의185/7개 검사는 이 보완 전 버전에 대한 기록이며 최종 실내 장소 UI의 근거로 승격하지 않는다.

실내 장소 보완의 검증: 영향 있는45개 브라우저 배치를 확인했고 장소 선택·미지정·공유 제외를 검사했다. 미지정 문구 보완 후에는3개 상태를 한정 확인했다. 이는 브라우저 시안 검증이며 실제 기기 위치 정확도·권한·저장 동작의 검증이 아니다.

## 모든 실내 유산소로 범위 확대 · 2026-10-29

사용자가 러닝만이 아니라 **모든 실내 유산소**를 대상으로 정정했다. 장소 지도·핀·장소 선택/보정·공유 공개 범위는 종목과 기록 단위에 독립적인 공통 기능이다. 실내 자전거·일립티컬·계단 오르기·스텝퍼·로잉·줄넘기·인터벌/혼합 유산소·실내 걷기와 수영장 운동 등에 같은 장소 기능을 제공한다. 새 종목이나 사용자 정의 종목도 장소 모델을 재사용하며 특정 종목 allowlist로 차단하지 않는다.

| 기록 단위 | 예시 | 표시 기준 |
|---|---|---|
| km | 러닝·걷기·실내 자전거 | 실제 거리, 시간. 러닝/걷기의 페이스와 자전거의 속도를 구분 |
| m | 로잉·실내 수영 | 실제 거리, 시간. 로잉 /500m·수영 /100m 페이스가 있으면 표시 |
| floors | 계단 오르기·스텝퍼 | 층수·시간·기록한 레벨. km로 바꾸지 않음 |
| count | 줄넘기 | 횟수·시간. km나 러닝 페이스를 만들지 않음 |
| timeOnly | 일립티컬·시간 기반 유산소·기타 | 시간과 실제 레벨/심박/열량. 거리가 없으면 거리 목표에 합산하지 않음 |

현재 `CardioSecondaryUnit.swift`의 km/meters/floors/count/timeOnly와 `WorkoutActivityType.swift`의 종목 모델을 기준으로 구분했다. 일립티컬이 일부 분류에서 distance-based라고 되어 있어도 실제 선택한 운동의 기록 단위와 수신 필드를 우선한다. 스트로크·회전수·랩 등의 추가 지표는 실제로 받은 경우에만 제공한다.

장소 부착은 실외 선택 가능 여부나 거리 필드 유무에 종속시키지 않는다. 실내 전용 머신의 시작 화면·운동 중·완료·기록 상세·공유에서 공통 장소를 이어가며, 수동/가져온 기록도 장소가 없으면 선택할 수 있게 설계한다. 직접 선택한 시설을 센서가 검증한 방문으로 취급하지 않는다. 상세 개편 브랜치에는 W23/W24/W25/W28의 **모든 실내 유산소 공통 장소 영역**으로 전달할 계약이며 이번 작업은 시안/문서만 수정했다.

다섯 시안에 운동 종목 선택을 추가했고, 러닝 외에는 종목별 단위를 사용하는 공통 실내 유산소 카드를 표시한다. 거리 없는 운동의 Journey는 **운동 시간 목표**로 구성하며 가상의 km를 생성하지 않는다. Passport도 러닝 첫5K 대신 운동 시간·운동 횟수 예시로 바뀐다. 모든 수치는 설명용이며 실제 기록을 읽거나 저장하지 않는다.

## 현재 통합 방향 · 2026-10-29

사용자가 아틀라스 기본 + 공유 스타일 선택 + 저니/패스포트 통합을 요청했다. 후속 방향과 화면 계약은 [유산소 아틀라스 통합안](cardio-atlas-integrated-proposal.md)을 따른다. 이 문서는 앞선 다섯 방향 탐색과 범위 보완의 이력으로 보존한다.
