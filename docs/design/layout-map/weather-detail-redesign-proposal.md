# T08 날씨 상세 개편 배치 계약

검토한 브라우저 시안은 `../theme-map/themes/assets/condition-detail-redesign/`의 T08 원본 JSON·밝음/어두움 PNG다. 예시 서울/19°C와 보조 수치는 실제 날씨나 네이티브 캡처가 아니다.

1. 현재 날씨: 큰 실제 기온·원래 상태 SF Symbol·상태 이름·수신한 위치·3°C 이상 차이일 때 체감 온도. 낮/밤과 기존 상태 enum의 날씨별 하늘 색·광원·구름·강수·바람·안개를 절제된 움직임의 장면으로 표시한다. 히어로 가시 면적이 절반 미만이거나 비활성·Reduce Motion·정적 UI 검사에서는 장면이 멈춘다. 하늘 색은 기존 디자인 토큰을 사용한다. 기온/장소의 명암을 우선하고 장식은 접근성에서 숨긴다.
2. 기존 순서: 현재 → 최적 야외 시간(있을 때) → 야외 활동 점수 → 대기질(있을 때) → 습도/UV/바람/체감 → 시간별 예보(있을 때) → 7일 예보(있을 때) → 오래된 정보(해당할 때). 생략 조건과 점수 공식은 변경하지 않는다.
3. 최적 시간·활동 점수·대기질·상세 날씨는 색, 여백, 표면으로 구분한다. 상태와 수치를 색만으로 전달하지 않는다. 오염물질 및 시간별 PM₂.₅는 기존 수신 조건을 지킨다.
4. 시간별 예보는 원래 시각·아이콘·기온·강수 확률을 유지하면서 기온 흐름을 읽기 쉽게 한다. 7일 예보의 실제 최저/최고 및 범위 막대를 유지한다.
5. iPhone·Duo 접힘은 한 열, iPad·Duo 펼침에서는 장면을 읽기 좋은 폭으로 제한한다. 큰 글씨는 텍스트를 우선 확장하고 필요한 세로 길이를 확보한다.
6. 실제 앱 검증은 T08만 새로 캡처한다. 기존 PNG는 개편 전 기준이며 새 구현 근거가 아니다.
