원래 계약

프롬프트, wand.and.stars 아이콘, Generate Template 버튼, 지원 기기 안내를 보존한다. 빈 프롬프트와 미지원 기기에서는 버튼이 비활성화된다. 큰 글씨에서 버튼과 안내 문구는 줄바꿈되어 온전히 보여야 한다.

생성 요청의 모델 결과는 별도 기능 검증 범위다. 새 실제 PNG/AX가 나오기 전에는 이 시안을 완료된 캡처로 표시하지 않는다.
