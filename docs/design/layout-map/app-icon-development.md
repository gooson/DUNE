# DUNE 아이콘 발전 과정

[비교 대시보드](../theme-map/themes/dune-icon-development.html) · [테마 맵](../theme-map/index.html)

## 의미와 범위

기존 사구 곡선 = HRV·심박의 파동, 자연스러운 변화와 회복력. 코퍼·앰버의 따뜻함과 유기적인 곡선을 이어간다. 기준은 [기존 브랜드 결정](../../brainstorms/2026-02-25-app-icon-splash-design.md)과 실제 `AppIcon.png`다. 앱 리소스를 교체하는 단계가 아닌 아이콘 방향 탐색이다.

## 홈 화면 목업 계약

- 390×844 CSS px, 4열, 아이콘 60px/68px 두 크기를 비교한다. 이는 이 목업의 설정이며 모든 iPhone의 시스템 치수 규격이라는 뜻이 아니다.
- 선택 시안과 기존 아이콘을 같은 위치·같은 배경·같은 주변 앱으로 비교한다. 선택한 DUNE은 세 번째 줄 첫 번째 위치다.
- 밝은 사구·어두운 사구·단색 배경 전환은 배경만 바꾼다. iOS의 시스템 다크/클리어/틴트 아이콘 효과를 모사하지 않는다.
- PNG는 생성 원본 그대로 표시한다. 앱 모서리는 CSS로 근사하며, 원본 PNG에는 새 마스크를 굽지 않는다.
- 60/40/29px 축소 비교와 큰 원본 보기, PNG 다운로드를 제공한다. 좁은 창에서 폰 자체를 축소하지 않고 폰 영역만 가로로 이동한다.
- `2차 / 1차 / 레퍼런스 / 발전 기록`으로 탐색한다. 후보 표시·시안별 메모·마지막 선택은 브라우저 localStorage에 저장하고 JSON으로 내보낸다. 저장소의 발전 이력과 브라우저 메모는 별도이며 브라우저 메모가 Git 파일을 자동 수정하지 않는다.

3차 추가 후에는 `3차50 / 2차10 / 1차10 / 레퍼런스·Apple / 발전 기록`으로 탐색한다. 3차는 관점A–E별10개 또는 전체50개로 거를 수 있다. 원문 이미지가 제공되지 않은 Dribbble 레퍼런스는 원문 설명 참고로 표시한다.

## 현재 상태와 다음 단계

현재 탐색은 기존20개와 새50개21–70으로 확장했다. 11·15·16은2차 당시 추천 이력이며 현재 사용자 선택·승인을 의미하지 않는다. 3차의 [50개 프롬프트](../theme-map/themes/assets/dune-icon-development/v3/prompts.json)와 [Apple·Dribbble 연구](../theme-map/themes/assets/dune-icon-development/v3/research.md)를 따른다. 실제 앱 아이콘 교체, iPhone/Watch 설치, Icon Composer의 시스템 마스크·다크·클리어·틴트와 플랫폼별 검증은 미수행이다. 앱·실제 화면 디자인맵은 변경하지 않는다.

20개 PNG의 정사각형·불투명·해상도, 자산 링크, Node 스크립트 구문, linkedom에서 20개 선택·후보·시안별 메모·localStorage·원본 비교·배경·크기 전환·레퍼런스·타임라인을 확인했다. 테마맵 `--check`와 `git diff --check`도 통과했다. [QA 기록](../theme-map/themes/assets/dune-icon-development/qa.json)을 보존한다.

2026-11-03 모바일에서 링크를 볼 수 없다는 사용자 요청에 따라 별도 headless Chrome으로 [모바일 대시보드](../theme-map/themes/assets/dune-icon-development/captures/dashboard-mobile.png), [1차10안](../theme-map/themes/assets/dune-icon-development/captures/v1-overview.png), [2차10안](../theme-map/themes/assets/dune-icon-development/captures/v2-overview.png), 원본과11·15·16번의 홈 화면 병렬 목업을 캡처했다. [출처 목록](../theme-map/themes/assets/dune-icon-development/captures/capture-index.json)을 보존한다. 2차 비교판·15번 병렬 홈 화면·모바일 대시보드 PNG를 시각 확인했으며 사용자 브라우저 세션이나 잠금 화면을 조작하지 않았다. 이 이미지는 HTML 목업의 렌더링이며 실제 iPhone 설치·기기 캡처가 아니다.

## 3차50개 생성·검증·캡처

50개 별도 생성 원본의 정사각형·불투명·해상도와 SHA-256 고유성을 확인했다. 기존20개를 포함한70개 데이터에서 새50개를 각각 선택해 홈 화면 이미지의 일치 여부를 확인하고,50개 모두 같은 위치·같은 크기의 홈 화면 PNG로 보존했다. A–E 관점별10개 비교판5장, 홈 화면 비교판5장, 전체50개 비교판과 모바일 대시보드를 생성했다. 원본PNG는 변형하지 않고 HTML에서 배치·크기·마스크를 적용했다.

[3차 캡처와 브라우저 검증 기록](../theme-map/themes/assets/dune-icon-development/v3/captures/capture-index.json)은 전체50개 필터·이전20개·메모와 후보 저장·원본 비교·배경·크기·레퍼런스12개·발전 기록을 확인하며 브라우저 오류0건이다. 새50개 비교판5장을 시각 확인했다. 관련 없는 앱 빌드·시뮬레이터·전체 테스트를 실행하지 않는다.

추천 검토 후보는27·39·46·57·70이다. [선정 이유와 남은 보완](../theme-map/themes/assets/dune-icon-development/v3/curation.json)을 따른다. 디자인 판단이며 사용자 선택이나 Apple 승인이 아니다. 일부 생성 시안은 가는 끝과 가로 비율을 유지하므로 모두 동일하게 완성된 제작 에셋이라고 표시하지 않는다. 후보 선택 후 곡선·간격·색·레이어를 제작용 원본으로 정리한다.

## 컬러랩 · 20조합×9형태

요청: “컬러 조합별 옵션도 바꿔서 볼수 있게 … 다양하게20조합”. 새로운 형태를 생성하지 않고6차9개 PNG의 같은 픽셀 배치를 유지한 채 화면에서 색만 변환한다. 팔레트 데이터는 [palettes.json](../theme-map/themes/assets/dune-icon-development/color-lab/palettes.json), UI 변환은 `color-lab/lab.js`에 둔다. 112개 역사 시안 수는 유지한다.

- 기본 진입은 컬러랩이며 사용자의 기존 선택을 가능한 한 같은6차 형태에 연결한다. 역사 탭은 원래 색으로 표시한다.
- 선택 순서86·87·84·81·82·80·75·74·71의9개 형태. 팔레트20개 실제 아이콘 미리보기, 드롭다운·이전/다음·색 순서 바꾸기 제공.
- 파스텔·자연·쿨톤·웜톤·보색·뉴트럴·밝은 배경·선명한 대비를 포함한다. 팔레트 기본 바탕, 같은 차콜, 같은 아이보리3모드를 비교한다.
- 큰 아이콘·60/40/29px·9형태 목록·홈 화면의 선택 아이콘이 함께 변한다. 출발 PNG와 현재 앱 아이콘은 필터를 적용하지 않는다. 다른 팔레트 비교는 같은 형태에 별도 필터를 적용한다.

- PNG 저장은 선택한 조합의1024×1024 정사각형 아트워크이며 CSS 모서리 마스크를 굽지 않는다. 원본 PNG의 바이트를 포함하는 지연 로딩 script는 `export-sources/`에 두어 file:// 캔버스의 외부 파일 제한을 피한다. 원본 픽셀 바이트는 편집하지 않는다.
