# WLA01 · Watch 운동 Live Activity 레이아웃 맵

이 문서는 Watch에서 시작한 운동을 iPhone 잠금 화면과 Dynamic Island에 표시하는 구현 기준 시안이다. 수치는 예시이며 실제 운동 기록이나 시스템 캡처가 아니다.

| 표면 | 정보 순서 | 좁은 폭 대응 |
|---|---|---|
| 잠금 화면 기본 | 운동명 → 진행 상태·경과 시간 → 심박·활동 칼로리·거리 | 이름 한 줄 말줄임. 유효한 거리만 표시하고, 심박이 없으면 해당 항목을 제외한다. |
| 잠금 화면 small | 운동명 → 경과 시간 → 남는 공간에 수치 | 숫자보다 운동명과 시간이 우선이다. |
| Dynamic Island 펼침 | 운동명·진행 상태 → 경과 시간 → 유효한 수치 | 긴 운동명은 한 줄로 제한한다. |
| Dynamic Island compact/minimal | 운동 아이콘·시간 또는 아이콘 | compact 시간 폭을 제한하고 숫자 글꼴을 축소한다. |

진행 중에는 시스템 타이머가 경과 시간을 갱신한다. 일시 정지와 종료 상태에서는 마지막 누적 시간을 고정한다. 연결 상태가 오래되어 `isStale`이면 운동명과 연결 대기 상태만 남기고 경과 시간과 운동 수치를 숨긴다. 수치가 없다는 이유로 0 심박이나 임의 거리를 표시하지 않는다.

색은 시스템의 Live Activity 배경과 흰색 글자를 기준으로 한다. 심박·칼로리·거리는 단위와 접근성 레이블을 함께 제공한다. 이 표면에는 운동 제어 버튼이 없으며 탭하면 DUNE 앱을 연다. 큰 글씨에서는 운동명·시간이 우선 보이도록 수치 행을 낮은 우선순위로 둔다.

실제 캡처 확인 범위: iPhone 잠금 화면 기본·small의 진행/일시 정지/연결 대기, Dynamic Island 펼침·compact의 진행/일시 정지. 실제 캡처가 확보되기 전에는 이 시안을 완료 화면으로 표시하지 않는다.
