# WLA01 · Watch 운동 Live Activity 레이아웃 맵

이 문서는 Watch에서 시작한 운동을 iPhone 잠금 화면과 Dynamic Island에 표시하는 구현 기준 시안이다. 수치는 예시이며 실제 운동 기록이나 시스템 캡처가 아니다.

| 표면 | 정보 순서 | 좁은 폭 대응 |
|---|---|---|
| 잠금 화면 기본 | 운동 아이콘·운동명·DUNE 워드마크와 상태 → 크게 강조한 경과 시간 → 심박·활동 칼로리·거리 | 시간과 지표를 명확히 분리한다. 긴 이름은 말줄임하고 좁은 폭·큰 글씨에서는 지표 배치를 전환한다. 유효한 거리만 표시하고, 심박이 없으면 해당 항목을 제외한다. |
| 잠금 화면 small | 운동명·DUNE 워드마크와 상태 → 경과 시간 → 간결한 수치 | 작은 표면에 맞는 별도 배치로 운동명과 시간을 우선한다. |
| Dynamic Island 펼침 | 운동 아이콘·운동명·DUNE 워드마크와 진행 상태 → 강조한 경과 시간·유효한 수치 | 잠금 화면의 정보 위계를 시스템 검정 표면에 맞춘다. 긴 운동명은 제한한다. |
| Dynamic Island compact/minimal | 운동 아이콘·시간 또는 아이콘 | compact 시간 폭을 제한하고 숫자 글꼴을 축소한다. |

진행 중에는 시스템 타이머가 경과 시간을 갱신한다. 일시 정지와 종료 상태에서는 마지막 누적 시간을 고정한다. 연결 상태가 오래되어 `isStale`이면 운동명과 연결 대기 상태만 남기고 경과 시간과 운동 수치를 숨긴다. 수치가 없다는 이유로 0 심박이나 임의 거리를 표시하지 않는다.

Watch에서 운동 종료를 누르면 해당 운동의 라이브 액티비티를 즉시 제거한다. 종료된 운동을 `Watch 연결 대기` 카드로 남기지 않는다. 연결 대기는 종료가 확인되지 않은 진행 중 운동의 일시적인 통신 끊김에만 사용한다. 종료 상태의 고정 시간은 시스템 정리가 일어나기 전의 안전한 표시이며 완료 카드를 계속 보존한다는 뜻이 아니다. 새 운동은 이전 종료 신호와 구분하고, 운동 시작 시각이 아직 없는 임시 미러로는 시스템 카드를 만들지 않는다. 실기기 Watch→잠긴 iPhone의 실제 종료·제거 캡처는 미확인이다.

DESERT HORIZON의 잠금 화면·small family는 named WidgetWarmSurface·DesertHorizonInk·WidgetWarmAccent의 밝음·어두움 표면을 사용한다. Dynamic Island의 시스템 검은 표면에는 기존 테마 액센트를 사용한다. 다른 테마는 기존 검정 표면과 흰색 글자를 유지한다. 심박·칼로리·거리는 단위와 접근성 레이블을 함께 제공한다. 이 표면에는 운동 제어 버튼이 없으며 탭하면 DUNE 앱을 연다. 모든 표면에서 이름과 수치는 한 줄로 제한하고 수치는 폭에 맞춰 축소한다. 큰 글씨의 실제 잘림 여부는 시스템 캡처로 별도 검증한다.

실제 캡처 확인 대상: iPhone 잠금 화면 기본·small의 진행/일시 정지/연결 대기, Dynamic Island 펼침·compact의 진행/일시 정지. 실제 확보 범위는 [실제 화면맵](../phone-design-map/actual/live-activity/index.html)에 따르며 이 목록 자체는 캡처 완료를 뜻하지 않는다.

## 2026-10-25 정보 위계 개선

첨부된 체스트 프레스 머신 화면처럼 운동명·시간·지표가 비슷한 크기로 흩어지는 구성을 정리한다. SF 계열의 굵기 차이, rounded 숫자와 고정 자릿수, 충분한 여백으로 경과 시간을 주 정보로 만든다. 심박·칼로리·거리는 의미가 있는 색상 아이콘과 작은 단위를 함께 사용한다. 값이 없는 그래프·진행 링이나 실제로 지원하지 않는 운동 제어 버튼은 추가하지 않는다.

Apple의 [Live Activities HIG](https://developer.apple.com/design/human-interface-guidelines/live-activities)에 따라 짧게 읽히는 정보를 우선하며 시스템 컨테이너의 모서리·표면을 유지한다. 테마 방향의 색·능선·움직임은 변경하지 않고 기존 테마 토큰 안에서 배치와 강조만 바꾼다. 진행·일시 정지·연결 대기와 긴 근력 운동명은 전용 iPhone의 실제 시스템 표면을 다시 캡처한다. iPad·Duo·Watch small·Island의 미확인 범위는 실제 화면맵에서 별도로 표시한다.

### DUNE 식별 보완

운동 정보만으로는 앱을 식별하기 어려워 기존 상태 행을 `DUNE · 운동` 형태로 바꾼다. DUNE는 번역하지 않는 작은 bold 워드마크이며 자간과 기존 테마 액센트로 구별한다. 별도 행·배지·컨테이너를 추가하지 않고 잠금 화면·small·Island 펼침의 공통 헤더에 적용한다. 좁은 폭에서도 DUNE는 유지하고 상태 문구를 줄인다. compact/minimal은 공간 제약 때문에 기존 상태 아이콘을 유지한다. 워드마크 추가 전 캡처 세 장은 현재 구현의 완료 증거가 아니며 새 캡처 현황은 실제 화면맵에 따로 표시한다.


## 2026-10-30 운동별 아이콘 계약

진행 중 아이콘은 Watch가 전송한 canonical `WorkoutActivityType.iconName`을 사용한다. 러닝은 `figure.run`, 걷기는 `figure.walk`, 사이클은 `figure.outdoor.cycle`, 수영은 `figure.pool.swim`, 근력 루틴은 `dumbbell.fill`이다. 운동명·언어·사용자 지정 이름으로 종류를 추측하지 않는다. 잠금 화면 기본/small과 Dynamic Island expanded/compact/minimal이 같은 선택 함수를 사용한다.

일시 정지는 `pause.fill`, 종료는 `checkmark`, 연결 대기는 `wifi.slash`가 운동 기호보다 우선한다. 구버전 Watch의 누락 필드와 빈/과도한 길이의 값은 기존 `figure`로 대체하고 운동 수치는 계속 갱신한다. 첫 미러 snapshot은 HealthKit 세션의 종류를 사용한다. 색·크기·배치·테마 시안은 변경하지 않는다.

WLA01의 이번 변경 캡처는 아직 미갱신이다. 초기 디스크 공간 부족은 해소됐으나 전용 iPhone 실행이 다른 작업의 저장소 시뮬레이터 잠금 때문에 60초 후 실패했다. 기존 PNG를 운동별 아이콘의 새 증거로 사용하지 않는다. iPhone 잠금 화면의 러닝·사이클·근력 및 정지/연결 대기, iPad·Duo 양쪽·Watch small·Dynamic Island 상태는 새 검증 전까지 미확인이다.

## 2026-10-30 골드 임팩트 · 종목별 주 지표

[보존 시안과 계약](live-activity-size-state-proposal.md)을 기준으로 네이티브 구현을 반영했다. iPhone Settings의 Workout Live Activity에서 유산소 시간/거리/심박, 웨이트 시간/현재 세트 중량/심박을 각각 선택한다. 기본값은 시간, 스타일은 Gold Impact이며 Standard도 제공한다. 거리 지원 여부와 현재 입력 중량은 Watch metadata를 사용한다. 0은 보존하고 nil은 시간으로 전환한다. stale에는 수치를 숨기고 종료는 즉시 제거한다. 펼침의 검정 배경과 28pt 제한 폭은 보존하며 잠금 화면의 금빛 표면·능선·장식 운동 심벌을 추가한다. 실제 시스템 캡처는 새 검증 결과 전까지 미갱신이다.

네이티브의 시간은 항상 시스템 `.timer`로 진행한다. 브라우저 초안의 `23′` 같은 정적 분 축약은 자동 갱신 검증이 없어 구현하지 않는다. 28pt/긴 값이 읽히지 않는 경우에는 해당 지표의 기호로 대체하고 접근성 값에 전체 수치를 유지한다. minimal/compact 기호는 일시 정지·연결 대기 상태가 우선하며, 심박 선택 시 심장 기호를 사용한다. Standard 펼침에서도 주 지표가 시간이 아니면 보조 시간을 유지한다.

최종 일반 빌드와 관련 단위51개는 통과했다. [S01 새 실제 설정](../phone-design-map/actual/live-activity/gold-impact-2026-10-30/index.html)은 저장·재실행 검증을 포함한다. WLA01 최종 시스템 UI는 환경 조회 무응답으로 testcase0건이며 현재 캡처로 표시하지 않는다. [검증 기록](../../reviews/2026-10-30-live-activity-gold-preferences.md)을 따른다.
