배치 맵 · DUNE 표현

P01 · 자세 촬영

구현 기준 정적 시안. 수치·웹 기호는 설명용이며 실제 기록·SF Symbol·앱 캡처가 아니다.

정보 순서

camera preview → 작은 준비 가이드·원래 체크리스트 → 촬영 버튼. 실패 시 원래 오류·기호·Try Again을 스크롤 가능한 중앙 강조면에 둔다.

보존 동작

camera session·권한·방향·mirror·front/side·countdown·auto capture·결과 전환·외부 화면 안내·Close 보존.

기기·큰 글씨·상태

일반 iPhone·iPad·Duo 접힘/펼침을 대상으로 한다. 한 열 스크롤, 안전 영역의 원래 toolbar/CTA, MAX에서 수직 확장. camera preview에 큰 장식을 덧씌우지 않는다. 카메라·추론 성공은 시뮬레이터로 입증하지 않는다. 새 native PNG/AX와 Close/선택/결과 행동 검증 전에는 완료로 표시하지 않는다.
