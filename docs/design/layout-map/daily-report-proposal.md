# T10 · 오늘의 건강 리포트 배치 계약

대상은 알림에서 여는 `DailyDigestNotificationView`입니다. [보존 시안](../theme-map/themes/dune-daily-report.html)은 브라우저 그림이며 실제 앱 캡처가 아닙니다. 실제 근거는 [T10 캡처](../phone-design-map/actual/index.html)에서 별도로 갱신합니다.

1. 내비게이션 제목은 **Today’s Report / 오늘의 리포트**. 앱이 제공하는 뒤로 가기를 유지합니다.
2. 상단 불투명 골드 표지는 `doc.text` 원형 장식, 날짜, 제목, 한 줄 설명을 가집니다. 측정값이나 건강 상태를 암시하는 장식 차트는 넣지 않습니다.
3. 컨디션은 실제 점수가 있을 때만 큰 수치와 어제 대비를 보여 줍니다. 고정된 임의 링은 쓰지 않습니다.
4. 활동은 실제 걸음 수와, 운동 요약이 존재하면 원본 요약 문자열을 보여 줍니다. 두 값의 유무는 독립적입니다.
5. 수면은 유한하고 양수인 실제 분만 `hoursMinutesFormatted`로 보여 줍니다. 달 아이콘은 정적 삽화입니다.
6. 하루 돌아보기는 `DailyDigestSummaryText`의 첫 문장 미리보기와 전체 원본 문장을 펼침/접힘으로 제공합니다. 관측된 지표가 하나도 없으면 기존 수집 중 문구를 사용합니다.
7. 인증 실패, 조회 대기, HealthKit 미허용/기록 없음은 원래 분기를 유지합니다. 시안의 상태 탭은 앱에 존재하지 않는 미리보기 조작이므로 구현하지 않습니다.
8. 작은 화면은 단일 열로 스크롤합니다. 넓은 iPad/Duo에서는 중앙 최대 폭을 유지합니다. AX 글씨에서는 운동 레이블(기존 `figure.run` 포함) 위에 원본 운동 문장을 두고, 섹션 제목 옆의 중복 장식 아이콘을 숨겨 전체 제목 폭을 확보합니다. 펼친 원본 요약은 줄임 없이 스크롤해 읽습니다. VoiceOver에 장식을 중복 읽히지 않습니다. 애니메이션은 Reduce Motion을 따릅니다.

시안의 수치는 예시 데이터입니다. 네이티브 화면은 실제 `DailyDigest` 값 외에 측정값을 만들지 않습니다.
