H05 · 신체 기록 입력·수정

Wellness 추가와 신체 기록 이력의 수정에서 공유하는 BodyCompositionFormSheet의 배치 계약입니다. DUNE 표현 시안의 값은 설명용이며 네이티브 캡처가 아닙니다. 수정 흐름도 H05이며 H06 신체 기록 이력의 완료를 뜻하지 않습니다.

네이티브 Form 읽기 순서

  1. 시스템 제목 Add Record 또는 Edit Record
  2. 미래 날짜를 선택할 수 없는 Date & Time
  3. Weight (kg) · scalemass.fill 헤더와 선택 입력
  4. Body Fat (%) · percent 헤더와 선택 입력
  5. Muscle Mass (kg) · figure.strengthtraining.traditional 헤더와 선택 입력
  6. Memo와 입력 중 키보드 Clear Input / Done
  7. 오류가 실제 발생하면 원래 Form 상단 오류
  8. 고정 하단 Cancel / Save

보존 동작과 상태

입력세 수치는 각각 선택 입력이며 기존 kg / % 단위·소수 키보드·검증 범위·메모 길이 제한을 유지합니다. 값이 없을 때 점수나 측정값을 만들어 표시하지 않습니다.
저장세 측정값이 모두 비어 있거나 저장 중이면 Save가 비활성입니다. 유효한 입력 후 기존 저장·닫기·성공 피드백을 유지하고, 편집에서는 채워진 기존 값을 보존합니다. Cancel은 저장하지 않고 닫습니다.
배치시스템 시트의 NavigationStack과 스크롤 가능한 Form, DatePicker, TextField, 고정 하단 버튼을 그대로 사용합니다. 큰 글씨에서는 헤더가 줄바꿈되고 아래 필드와 저장 버튼에 스크롤로 도달해야 합니다. 키보드 툴바는 입력 중에만 나타납니다.
아이콘기존 HealthMetric category의 세 SF Symbol 이름과 테마 색만 헤더에 붙입니다. 실제 심볼 형태는 이 HTML이 재현하지 않습니다. 헤더 텍스트는 원래 로컬라이즈된 이름입니다.
