H08 · 부상 기록 입력·수정

InjuryFormSheet의 네이티브 Form 배치 계약입니다. DUNE 표현 시안은 설명용이며 앱 캡처나 실제 부상 기록이 아닙니다.

읽기와 행동 순서

  1. 시스템 제목 Add Injury / Edit Injury와 상단 Cancel·Save
  2. Body Part · 현재 선택 부위의 원래 아이콘, Location 피커의 Joints / Muscles
  3. 선택 부위가 좌우 구분을 지원할 때만 Side 분할 선택
  4. Severity · bandage.fill 헤더와 Minor / Moderate / Severe 원래 세 선택 행
  5. Duration · calendar 헤더, 미래 날짜를 막는 Start Date
  6. Recovered 토글 후에만 나타나는 End Date
  7. Notes · note.text 헤더와 Memo (optional)
  8. 실제 검증 오류가 있을 때만 Form 상단 오류, 저장 성공 시 기존 피드백

보존 계약

선택과 저장Body Part, Side, Severity, Start Date, Recovered, End Date, Memo의 원래 바인딩·검증·Cancel·Save를 유지합니다. 선택 상태는 색뿐 아니라 기존 체크 표시와 이름으로 알립니다. 임의의 의료 점수나 완료 상태를 만들지 않습니다.
기기와 큰 글씨iPhone·iPad·Duo 접힘·펼침에서 같은 Form 정보를 유지합니다. 큰 글씨에서는 긴 Severity 설명을 줄바꿈하고 Form을 세로로 스크롤해 마지막 메모와 상단 toolbar 행동에 접근합니다. 키보드가 보일 때 가려짐을 실제 기기에서 확인합니다.
아이콘과 색Body Part는 선택 부위의 기존 iconName, Severity 헤더는 bandage.fill, Duration은 calendar, Notes는 note.text를 사용합니다. Severity 세 행의 원래 상태 아이콘과 상태색을 유지하며 밝은 화면 아이콘·체크만 더 진하게 표시합니다. 정확한 대비는 실제 화면에서 검증합니다.
증거 경계이 HTML은 구현 전 배치 기준입니다. 기존 H08 네 장은 화면 정체성 참고이며 현재 소스·UID·자세·AX에 결합된 전후 캡처가 아닙니다. 새 네이티브 결과는 아직 없습니다.
