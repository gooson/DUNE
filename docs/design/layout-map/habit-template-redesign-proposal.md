# L03 습관 템플릿 개편

검토한 [테마 시안](../theme-map/themes/dune-habit-template-redesign.html)을 네이티브에 적용한다.

카테고리 제목 → 템플릿 카드 격자. 카드: 기존 큰 카테고리 심볼과 시간대 레이블 → 전체 제목 → 반복 주기와 수량/분 목표. 각 카드가 하나의 Button이며 prefill→dismiss→onSelect를 유지한다. 새로운 목표·진행률·추천 순위를 만들지 않는다.

사용 가능한 화면 너비700pt 이상에서는4열, 이하는2열이다. 접근성 글씨에서는 각각2열/1열로 줄인다. 제목은 생략하지 않고 세로로 확장하며 아이콘과 일정은 공간이 부족하면 쌓는다. 장식용 심볼/배경은 글씨 가독성을 위해 확대 상한을 두고 카드 밖으로 그리지 않는다.

영향 화면은 일반 iPhone·iPad·Duo 접힘/펼침의 L03이다. 실제 캡처는 별도 출처와 함께 갱신하며 위 시안 이미지를 앱 구현 증거로 대체하지 않는다.
