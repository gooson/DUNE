H04 · 두 지표 기간 비교

Wellness의 지표 비교 버튼에서 여는 큰 시스템 시트의 배치 계약입니다. DUNE 표현 시안은 예시이며 실제 앱 캡처가 아닙니다.

읽기 순서

  1. 차트 아이콘이 있는 ScoreHeroPalette 제목
  2. 공통 기간 선택 D · W · M · 6M · Y
  3. 두 차트에 적용되는 날짜 범위 한 번
  4. 같은 날짜·별도 값 축이라는 안내
  5. 첫째 지표 선택과 차트
  6. 둘째 지표 선택과 차트
  7. 시스템 Done으로 Wellness 복귀

값과 동작

지표서로 다른 HealthMetric ID를 각 네이티브 메뉴 피커에서 선택합니다. 원래 resolvedIconName과 category 색, 원래 값·단위를 유지합니다. HRV와 Weight는 설명용 예시입니다.
두 차트한 period·referenceDate에서 계산한 정확히 같은 X 날짜 도메인을 두 차트에 전달합니다. 각 지표의 Y 축·단위와 기록 로딩은 독립입니다. 동일 날짜가 인과관계를 뜻하지 않습니다.
표현일반 iPad의 넓은 폭에서는 두 열, iPhone·Duo 좁은 폭과 접근성 최대 글씨에서는 세로 두 카드입니다. 시트 전체를 스크롤해 둘째 차트와 Done에 도달합니다. MAX의 긴 피커 이름이 모두 보이는지는 실제 네이티브 화면에서 확인합니다.
상태기존 로딩·오류/다시 시도·기록 없음·제한 이력 안내를 각 지표에서 유지합니다. 수면은 분 단위 막대, 다른 지표는 기존 선/점으로 표시합니다. Wellness 비교 버튼은 서로 다른 이용 가능 지표가 둘 이상일 때만 활성화됩니다.
