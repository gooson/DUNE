# C14·C15 · 러닝 거리 화면 심박 존 시안

[비교 시안 열기](../theme-map/themes/dune-watch-running-zone.html)

사용자가 2026-11-06 **V2 구간 막대 포함**을 승인했다. `CardioDistanceMetricsPage.swift`에 구현하며 검증 결과는 실제 화면맵에 별도 기록한다. 이 HTML의 수치는 설명용이며 실제 앱 캡처가 아니다. 시안의 기존 C14 PNG는 변경 전 상태로만 비교한다.

## 정보 순서

큰 누적 km → 경과 시간·평균 페이스 → 심박과 현재 존. 기존 `Heart Rate`가 40mm에서 두 줄을 쓰는 부분을 심장 기호·수치·단위·존으로 정리한다. 거리·시간 숫자의 크기를 보존한다.

| 방향 | 구성 | 판단 |
|---|---|---|
| V1 · 한 줄 | `♥ 142 bpm` 오른쪽에 `존 2` | 가장 간결하며 높이 증가가 작다. |
| V2 · 구간 막대 | V1 바로 아래에 얇은 구간 막대, 현재 구간만 강조 | 추천. 옆 페이지로 이동하지 않고 현재 구간의 상대 위치를 읽는다. |

40mm의 162×197pt 화면 비율로 먼저 제시한다. 시안에서 지정한 치수는 제안 값이며 Apple 공식 수치 규정으로 주장하지 않는다. 배경은 기존 검정, km는 기존 activity, 존은 기존 HRZone 토큰을 사용한다. 새로운 테마·심박 계산을 도입하지 않는다.

## 상태·데이터 계약

- 현재 존은 기존 `displayedZoneIndex`와 `displayedZoneCount`를 사용한다. HealthKit의 가변 구간 수와 앱의 추정 fallback을 그대로 따른다. 5개로 고정하지 않는다.
- 존 번호를 텍스트로 표시해 색에만 의존하지 않는다. 막대는 달성도·누적 시간이 아니라 현재 구간의 위치다.
- 심박·존 미수신은 각각 `-- bpm`, `존 --`와 비활성 막대다. 심박만 수신된 경우 심박은 유지한다. 임의로 존 1을 선택하지 않는다.
- 일시 정지는 상단에 `일시 정지`를 표시한다. 숫자는 마지막 값이며 수신이 실시간으로 계속된다고 표현하지 않는다.
- 손목 내림·큰 글씨·긴 번역은 구현 후 native 검증한다. 큰 글씨에서는 세로 스크롤을 허용하고 km·시간을 추가로 축소해 공간을 만들지 않는다.
- VoiceOver는 심박수와 현재 존 번호를 읽는다. 기존 독립 심박 존 페이지와 스와이프 순서는 유지한다.

## 승인 후 작업·검증 범위

2026-11-06 구현과 40mm UI 3건이 완료됐다. [C14·C15·C20·C21 새 실제 캡처](../phone-design-map/actual/workout-surfaces-2026-11-06/index.html)에서 진행·정지·미수신·6개 구간의 존 1을 확인한다. 큰 글씨·Always-On은 이번 실행 범위 밖이다.

거리 기본 C14·일시 정지 C15의 하단 심박 영역만 변경한다. 시간 우선 페이지와 전용 존 페이지는 그대로 둔다. 40mm의 진행/정지/심박·존 미수신과 가변 구간 수를 우선 확인하고 C14·C15 새 실제 캡처를 디자인맵에 등록한다. 시안 승인은 이 실제 검증의 완료를 뜻하지 않는다.
