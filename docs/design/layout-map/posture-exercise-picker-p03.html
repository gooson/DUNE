P03 · 운동 선택

구현 기준 정적 시안. 수치·웹 기호는 설명용이며 실제 기록·SF Symbol·앱 캡처가 아니다.

정보 순서

원래 General Posture 선택 행 → Form Check 운동 목록. 기존 아이콘·체크를 유지하고 앞자리 심볼 면·선택 위계를 보강한다. 일반 글씨는 medium에서 시작하고 large로 확장한다. MAX(accessibility5)는 large만 사용해 고정 헤더와 전체 운동 행의 공간을 확보한다.

보존 동작

onSelect(nil)·각 운동·selected checkmark·Close·scroll 보존. MAX는 세로 레이블과 목록 밖 상단 안전 영역의 고정 Close 버튼·Exercise Mode 제목을 사용한다. 이 분기에서는 NavigationStack toolbar를 사용하지 않아 닫기 행동이 중복되지 않는다. 끝 행 전체 도달·선택/복귀·재진입 후 Close를 확인한다.

기기·큰 글씨·상태

일반 iPhone·iPad·Duo 접힘/펼침을 대상으로 한다. 한 열 스크롤과 원래 선택 동작을 유지한다. 일반 글씨의 원래 toolbar와 MAX의 고정 헤더를 구분한다. Duo 접힘 MAX에서 관측된 빈 내비게이션 바의 프레임워크 내부 원인은 미확정이다. 변경 후 해당 기기 재검증 전까지 해결로 표시하지 않는다. 새 native PNG/AX와 Close/선택/결과 행동 검증 전에는 완료로 표시하지 않는다.
