# T03 · Today 하단 읽기 위계 시안

[인터랙티브 시안](../theme-map/themes/dune-today-reading.html) · [기존 4탭 방향](../theme-map/themes/dune-final-four-tab.html)

사용자 제공 Today 사진의 회복·수면, 장기 스트레스, 오늘 요약을 대상으로 한다. **V2를 실제 앱에 적용했다. 검증 범위는 [실제 화면 갤러리](../full-redesign-map/review/today-reading-v2-2026-10-25/index.html)와 [구현 계획](../../plans/2026-10-25-today-reading-v2.md)에서 추적한다.** 실제 화면 디자인맵의 새 캡처로 취급하지 않는다. 사진의 52분은 수면 시간이 아닌 수면 부족으로 구분한다.

## 정보 순서

| 영역 | V1 · 간격 정돈 | V2 · 권장 위계 |
|---|---|---|
| 회복·수면 | 제목 → 수면 부족·상태 → 7일 그래프 | 제목 → 지난 수면 6시간 51분 → 수면 부족 52분 → 7일 그래프 → 수면 상세 |
| 장기 스트레스 | 링 26 → 낮음 → 근거 두 줄 | 작은 링 26 + 낮음·최근 기록 기준 → 근거 펼치기 → 스트레스 상세 |
| 오늘의 요약 | 기존 문단의 줄 간격 확대 | 날짜 → 컨디션 61·어제 대비 -2와 141걸음 → 전체 요약 펼치기 |
| 빠른 기록 | 체중·수면 | 기존 두 행동 유지 |

수면 보라색, 상태 초록색, 행동 앰버와 따뜻한 DUNE 배경을 유지한다. 숫자·제목·보조 설명의 위계를 나누고 V2 카드 내부 여백을 24px, 카드 간격을 20px로 제안한다. 이 값은 웹 시안의 디자인 값이며 Apple 필수 규격이 아니다. 기술 용어인 HRV 변동계수 0.20과 훈련 부하 균형은 근거 펼치기 안에 보존한다. 스트레스의 추세 데이터가 제공되지 않아 새 그래프나 추세 판단을 만들지 않는다.

## 기기·상태·행동

- iPhone 402px를 주 시안으로, 375px·Duo 접힘 466px·iPad 폭을 웹에서 확인한다. 넓은 화면도 같은 읽기 순서를 유지하고 가독 폭을 제한한다.
- 큰 글씨에서 수면 숫자 줄바꿈, 스트레스 링·설명 세로 배치, 요약 지표 한 열 전환을 허용한다. 높이를 고정하거나 텍스트를 생략하지 않는다.
- 밝음·어두움, 큰 글씨, 기록 없음 전환을 제공한다. 기록 없음에서는 예시 값·그래프·건강 판단을 표시하지 않는다.
- 수면 상세·체중 기록·수면 기록은 시안 내 대화상자로 목적지를 설명한다. 실제 앱 목적지에 연결한 것으로 표시하지 않는다.
- 7일 그래프는 날짜 범위를 표시하며 누락은 0시간으로 그리지 않는다. 그래프 값은 사진을 정밀 추출한 실제 데이터가 아닌 배치 확인용 예시다.

- [V2 어두움 미리보기](../theme-map/themes/assets/today-reading-v2-dark.png) · [V2 밝음 미리보기](../theme-map/themes/assets/today-reading-v2-light.png). HTML을 Chromium으로 렌더링한 이미지이며 실제 앱 캡처가 아니다.
- 브라우저 폭 375·402·466·768px에서 기본·큰 글씨의 문서와 카드에 가로 넘침이 없음을 확인했다. 데스크톱에서는 시안 폭 402·466·600px 전환을 확인했다.
- V1/V2, 밝음·어두움, 큰 글씨, 분석 근거 펼치기와 기록 없음 상태를 확인했다. 기록 없음은 세 카드의 수치·그래프를 숨긴다.
- 기록 버튼의 대화상자 열기·닫기와 페이지 JavaScript 오류 없음, 테마 맵 생성·동기화를 확인했다. 기본 어두움 비교 화면과 큰 글씨 밝음 렌더링을 육안 확인했다.

## 실제 구현 계약

카드는 기존 StandardCard와 디자인 토큰을 사용한다. 수면은 실제 값·날짜와 유효한 기록 최대 7개를 표시한다. 없는 날은 0시간 막대로 만들지 않는다. 그래프 눈금 가장자리는 글자 크기에 따라 여백을 늘린다. 스트레스의 기간은 실제 모델의 한계에 맞춰 최근 기록 기준으로 표시한다. 요약은 운동 완료를 새 헤드라인으로 추론하지 않고 날짜를 사용한다. 불충분 분석의 수면 부채 0은 관측 기록의 근거로 취급하지 않는다. 알림 T10에서는 공유 카드가 컨디션·걸음을 담당하고 수면만 별도로 보여 준다.

HTML·미리보기 PNG는 계속 방향 시안이다. SwiftUI 네이티브 화면은 별도 갤러리로 구분하며, 미캡처 기기는 기존 이미지를 갱신 증거로 사용하지 않는다.
