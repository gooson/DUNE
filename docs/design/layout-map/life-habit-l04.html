‹습관 관리
checklist
습관 관리실제 필터의 Active / Archived 건수와 checklist / archivebox SF 아이콘
원본 정보 순서Active / Archived segmented filter → 해당 목록 또는 원래 빈 상태. 각 행은 원본 아이콘, 이름, 총 완료, 최고 연속, 생성 날짜. 보관 행은 History · Restore.
동작 계약필터는 목록만 바꾼다. History는 기존 sheet, Restore는 기존 withAnimation과 sortOrder를 사용.
접근성 크기제목·값은 자연 줄바꿈. 아이콘 배지는 최소 크기만 지정하고 콘텐츠 높이는 제한하지 않음. 기존 Form/List/ScrollView로 아래 내용을 탐색.

기존 문자·아이콘·입력·알림·일정·저장 경로를 유지한 채 위계와 가독성을 강화한다. 기기별 실제 검토 후 실제 화면 맵을 별도로 갱신한다.
