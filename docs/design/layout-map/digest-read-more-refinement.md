# Today 요약 · 본문 더 보기 다듬기

[세 가지 세부안](digest-read-more-refinement.html) · [편집 원본](assets/daily-summary-refined-fragment.html) · [이전 방향 비교](digest-disclosure-proposal.md)

사용자가 이전 시안의 **본문 더 보기**를 선택하고 요약 방향을 더 발전시키도록 요청했다. 기존의 헤더 펼침 추천보다 이 선택을 우선한다. T03 요약 카드의 정보 순서와 밀도에 관한 후속 제안이며 네이티브 앱 캡처나 구현 완료가 아니다.

## 공통 기준

- 제목과 날짜는 같은 행에 두고 별도의 날짜 행을 없앤다. 헤더는 정적이다.
- 펼침은 본문 뒤 `요약 더 보기 ⌄` / `요약 접기 ⌃`로 표시한다. 글자와 화살표는 4pt 간격이며 행 전체가 최소 44pt 터치 영역이다.
- 접힌 상태에서도 지표와 한 문장 해석은 읽을 수 있다. 펼치면 미리보기를 전체 원문으로 바꿔 같은 문장을 두 번 쌓지 않는다.
- 수치에 얇은 구분선과 일관된 기준선을 사용한다. 하위 지표마다 별도의 카드 배경이나 진행률을 추가하지 않는다.
- 기존 DUNE의 밝음/어두움 카드 색을 사용한다. 테마·능선·링·그래프 방향을 새로 정하는 작업은 아니다.

## 세부안

| 안 | 정보 순서 | 판단 |
|---|---|---|
| 핵심 먼저 · 추천 | 제목/날짜 → 컨디션·걸음 2열 → 짧은 해석 → 더 보기 | 수치를 빠르게 읽으면서 요약을 놓치지 않는 기본안 |
| 한 문장 먼저 | 제목/날짜 → 큰 해석 문장·더 보기 → 작은 수치 2열 | 요약의 읽는 맛을 강조하지만 지표 강조는 줄어듦 |
| 지표를 행으로 | 제목/날짜 → 컨디션 행·걸음 행 → 해석·더 보기 | 항목이 명확하고 긴 레이블에 유리하나 두 행의 높이가 필요 |

## 상태·접근성

예시 날짜와 값은 첨부 화면의 **10월 26일, 45, 어제보다 2점, 5,205걸음**을 유지한다. 실제 현재 건강 데이터로 주장하지 않는다. 새 진단·행동 권고·목표 달성률·수면 추정은 만들지 않는다.

큰 글씨에서는 두 열을 한 열로 쌓고 날짜를 다음 행으로 보낸다. 좁은 카드 폭은 320px로 비교할 수 있다. 이 브라우저 글씨 확대는 실제 iOS Dynamic Type 검증을 대체하지 않는다. 숨긴 원문은 접근성 트리에서도 숨기며 button의 `aria-expanded`와 `aria-controls`를 맞춘다. 색에 의존하지 않고 `어제보다 2점`을 함께 표시한다.

실제 구현 시 원문이 없으면 펼침 제어를 숨기고 데이터 없음 안내를 유지한다. 하나의 지표만 있으면 한 열을 사용한다. 차이 0·걸음 0은 결측으로 취급하지 않는다. 짧은 원문이 이미 전부 보이면 불필요한 더 보기 제어를 만들지 않는다.

## 검증 범위

이번 작업은 시안과 레이아웃 맵만 변경한다. 앱·카탈로그·계산·내비게이션·실제 화면 디자인맵은 변경하지 않는다. 브라우저에서 세 안의 펼침/접기와 줄바꿈을 확인하고, 선택 후 네이티브 T03 및 영향을 받는 기기/상태만 구현·검증한다.

브라우저 확인: 세 안의 더 보기/접기와 carousel 전환, 기본 폭 및 320px·1.35배 글씨 조합의 배치를 확인했다. 확대된 추천안에서도 전체 문장과 접기 버튼이 표시되며 중복 미리보기는 숨겨진다. 고유 ID/제어 대상 일치·JS 구문·편집 원본/대화용 원본 일치도 확인했다. 앱 변경이 없어 새 시뮬레이터 빌드나 실제 화면 캡처를 실행하지 않았다.
