## 현재 습관 분류의 문제

| 분류 축 | 현재 소스/관찰 | 문제와 제안 |
|---|---|---|
| 기록 방식 | `HabitType`: check / duration / count | 입력 방법이며 생활 목적이 아님. 표시를 ‘체크 / 시간 / 횟수’로 명확히 하고 각기 다른 조작 제공 |
| 일정 | `HabitFrequency`: daily / weekly / interval | 현재 분리는 옳음. ‘오늘’, ‘이번 주 목표’, ‘다가오는 일정’을 계속 분리하고 중복 배치하지 않음 |
| 시간대 | morning / afternoon / evening / anytime | 오늘 목록의 보조 순서. ‘기한 지난 반복 일정’은 먼저 보여 주되 나머지는 고정 시간대→사용자 순서를 유지 |
| 아이콘 | `HabitIconCategory` 12개 | 건강·수분·영양·수면과 공부·코딩이 같은 깊이에서 길게 나열됨. 기존 값을 보존하고 목적별 보조 묶음을 적용 |
| 템플릿 | `HabitTemplateCategory` 5개 | 목록의 12개와 구조가 달라 신규/기존 탐색의 기준이 다름. 저장 분류와 추천 템플릿 분류를 별개로 설명하고 동일 목적 묶음으로 탐색 |
| 출처 | 수동 / 사용자 운동 연동 / 기본 자동 운동 규칙 | 현재 ‘주간 운동 성취’ 안에 일일 사용자 연동을 합산. 사용자 연동 목표를 먼저, 기본 도전은 펼침. 단일 달성률 합산 제거 |

### 목적별 보조 묶음 · 제안

| 표시 이름 | 기존 raw value | 예시 |
|---|---|---|
| 몸·건강 | health, fitness, nutrition, hydration, sleep | 영양제, 운동, 수분, 식사, 수면 루틴 |
| 집중·성장 | study, coding, creative | 책, 공부, 개발, 창작 |
| 마음·관계 | mindfulness, social | 명상, 호흡, 안부 |
| 생활·관리 | finance, chores | 지출, 정리, 집안 반복 일정 |

이는 **사용자가 지정한 아이콘 분류의 표시 묶음**이다. 이름을 분석해 임의로 재분류하지 않는다. ‘건강’ 아이콘을 고른 집안 습관처럼 의도와 다르면 관리에서 원래 분류를 수정한다. 원래 12개 선택은 폼/관리에서 유지하고 raw value·CloudKit migration을 만들지 않는다. 템플릿의 기존 큰 분류를 그대로 저장값으로 바꾸지 않는다. 필터는 오늘의 목록에만 적용하며 히어로 전체 수치와 주간·자동 기록을 숨기지 않는다. 필터0건에는 ‘전체 보기’를 제공한다.

## 통합 Flow · 정보 순서와 행동

| 순서 | 구획 | 표현과 동작 | 데이터 계약 |
|---|---|---|---|
| 1 | HABITS | 골드104pt 링의 2/5 완료 + 큰 3 남음. 문장·하단 요약·이동 버튼 없음 | 건강 점수 아님. 오늘 대상 수동 습관만. 0개 대상은 —, 0/0이나100% 금지 |
| 2 | 오늘의 실천 | 기한 지난 반복→시간대→언제든. 미완료 먼저, 완료는 펼침 | 오늘/주간/예정을 이중 등록하지 않음. 정렬이 갱신마다 흔들리지 않게 stable ID 사용 |
| 3 | 이번 주 목표 | 큰 2/3일 + 요일 완료 표시, 별도 오늘 0/20분 | 주간 분모는 목표일, 하루 분모는 분/횟수. 동일 날짜 중복 완료는1일 |
| 4 | 다가오는 일정 | 기본 접힘, 날짜/반복 간격, 미룬 항목 표시 | 미래 시작·첫 완료 대기·미룸을 오늘 미완료로 합산하지 않음. 조기 완료는 별도 확인 |
| 5 | 자동 기록 | 내가 연동한 습관 먼저, 기본 운동 도전 3그룹은 펼침 | 현재 사용자 연동은 **exercise 존재 기반 완료**만 지원. 걸음·수분·수면 자동 연동을 새 기능으로 암시하지 않음 |
| 6 | 실천의 리듬 | 최근7일 큰 완료 건수·낮은 막대, 최근28일 히트맵 | 날짜별 수동 완료 건수. 현재 등록/현재 목표 기준인 한계를 표시. 과거 목표 분모를 만들지 않음 |
| 7 | 주간 돌아보기 | 이번 주 오늘까지 기록한 날짜·완료 건수·이어진 습관 | 진행 중 주간을 실패로 평가하지 않음. 순위/개선율 강조는 집계 계약 해결 후. 자동 운동 성취 중복 없음 |
| 8 | 습관 관리 | 전체·순서·알림·보관함, 템플릿 진입 | 추가는 상단 +. 설정과 오늘 실행의 역할 구분. 기존 기능 삭제 없음 |

실천의 리듬은 히어로의7일 추세를 **이동/통합**하는 계획이며 같은 그래프를 두 곳에 중복하지 않는다. 기존90일/주월 차트의 추가 탐색은 상세에 보존하되 정확하지 않은 분모를 더 크게 보이지 않는다. 28일은 루트의 읽기 범위이고 기존90일 이력 데이터 삭제를 뜻하지 않는다.

기본안은 Flow다. Compact는 같은 기능/정보의 작은 숫자·절제된 표면·낮은 차트 비교안이며 현재 앱 재현본이 아니다. 두 방향 모두 새 분류와 기간 계약을 공유한다. 넓은 화면은 히어로·오늘 실행을 전체 폭으로 두고 주간/예정, 자동/리듬을 두 열로 묶는다. DOM/VoiceOver 읽기 순서는 기본 순서를 따른다. 높이를 억지로 맞추지 않는다.

## 조작 보완

- **최소44×44pt:** 횟수 ±, 더보기, 시간 수정, 필터, 헤더, 완료, 추가. 아이콘이 작은 경우에도 비중첩 hit area를 확보한다. 브라우저의 px 검증은 네이티브 pt 합격을 대신하지 않는다.
- **행과 행동 분리:** 체크·반복은 명시적 완료 버튼. 횟수·시간은 각각 독립 조작. 메뉴 열기/필터/상세 진입으로 값이 바뀌지 않는다. whole-row gesture 안의 자식 버튼 중첩을 피한다.
- **시간은 오늘 총합 수정:** 기존10분→25분을25분으로 저장한다. ‘추가’와 ‘총합’을 섞지 않는다. 저장 전 숫자/범위를 검증하고 잘못된 입력에 기존값을 보존한다.0은 의도적 기록 제거로 별도 계약 확인한다.
- **주간 목표:** 완료일2/3과 오늘0/20분을 별도로 표시. 이 시안의 주간 입력은 로컬로 반영되며 오늘 HABITS 대상 수는 바꾸지 않는다.
- **되돌리기와 포커스:** 값 변경 직후 오늘 목록 위에 상태/undo 제공. 완료 항목이 접힘으로 이동하면 오늘 제목에 포커스를 돌린다. 네이티브는 VoiceOver announcement와 적절한 포커스 연결을 검증한다.
- **반복 일정:** 미루면 오늘에서 빠지고 다가오는 일정에 내일로 나타난다. 되돌리면 양쪽이 복원된다. 건너뜀·조기 완료·기준일 선택은 기존 의미를 보존한다.
- **단위:** 물의 ‘잔’을 횟수와 함께 표시. 기본 운동은 **주5회·근력3회**이며 같은 날의 서로 다른 운동도 각각 집계한다. 수동 주간 목표의 ‘일’과 구별한다.

## 데이터 위험 · 구현 전 선행 과제

1. `LifeView.updateValue`(1272행 부근)는 기존 오늘 로그 삭제 후 `createValidatedLog`를 호출한다. 범위 밖 입력이 이전값을 잃을 수 있는 소스 경로다. **검증→준비→변경** 순서와 rollback/단일 저장 계약을 먼저 고친다. 이번 조사는 런타임 데이터 손실을 재현한 테스트가 아니다.
2. `HabitAnalyticsService`는 현재 active snapshot과 현재 goal로 과거 분모를 계산하고, 긴 interval도 매주 최소1회 목표를 부여한다. ‘90일마다’가 매주 미달로 보일 수 있다. 새 시안에서는 이런 달성률/성장률/최하위 순위를 강조하지 않는다.
3. 완료 건수도 현재 goal/보관 범위를 사용하면 과거가 재해석될 수 있다. 단순히 %를 개수로 바꾸는 것으로 완전한 역사 기록이 되지 않는다. 1차에는 `현재 등록 습관 기준`을 명시하고 Hero와 공유할 수 있는 수동·생성일·미래 제외 필터를 사용한다. **과거 불변 기록**이 필요하면 목표/보관 이력이나 completion event snapshot의 별도 데이터 계획이 필요하다.
4. 자동 주간은 월–일, 기존 수동 통계는 `Calendar.current` 주 경계다. 시안의10.26–11.01은 명시적 fixture다. 실제 앱은 기간 helper를 정의하고 기존 데이터 의미/로케일 영향을 검증한 뒤 통합하거나 각 기간을 표시한다.
5. 마지막 확인 시각·확인 중·오류는 현재 progress DTO만으로 충분하지 않다. 시안 상태를 운영 상태로 표현하려면 ViewModel→Presentation metadata 전달이 추가로 필요하다. 기록 없음으로 권한 거부를 추측하지 않는다.

## 상태·기기·접근성

L01: 진행 중, 전체 완료, 전체 없음, 오늘 대상 없음/주간만 있음, 자동만 있음, 첫 기록, 자동 확인 중, 필터0건을 제공한다. auto-only에서는 수동 예시 목록/주간/예정을 렌더링하지 않는다. 전체 없음에서도 자동 도전·추가·관리를 유지한다. 첫 기록에는 막대/히트맵을 만들지 않는다. 확인 중은 숫자를0으로 채우지 않는다.

폭320/402/466/951/1032, 글씨100/125/160/200%, 밝음/어두움을 비교한다. 160%부터 링을 숨기고 외부 수치로 전환, 본문과 버튼은 세로 확장한다. 고정 장식인 링/플롯을 글씨와 함께 확대하지 않는다. 기간·단위·상태는 자연 줄바꿈, 색과 텍스트를 함께 쓴다. 그래프 summary와 날짜별 상세를 제공하고19px 히트맵 셀 자체를 작은 터치 버튼으로 만들지 않는다.

브라우저 시안은 한국어 중심이다. en/ja 전체 카피·Native Dynamic Type·VoiceOver·Watch는 후속 구현 검증이며 현재 통과로 표시하지 않는다. 기존 Watch/Today의 습관 진입과 앱라우트는 구현 시 소비자 확인 대상이다.

## 두 계획의 통합 결정

| 검토 | 결정 |
|---|---|
| Parent: 목적별 그룹과 시각화 강조 / Astra: 일정 의미를 우선 | 일정3분리는 유지, 목적4분류는 보조 필터로만 적용 |

## 문장 축약 · 수치 강조 보완 · 2026-10-28

사용자 피드백은 ‘문장이 장황함·비주얼 약함·아래 이동 버튼 불필요’다. 히어로는 **HABITS / 오늘 / 골드 링 2/5 완료 / 큰 3 남음**만 표시한다. 104px 링 기하는 유지하고 구리–골드–밝은 골드 그라데이션과 약한 광택으로 대비를 높였다. 오른쪽 남은 수는 기본64px로 강조한다. 카드 기본 높이는200px 미만으로 줄이고 바로 아래 실행 목록이 빨리 나타나게 한다.

히어로의 설명2문장,완료/남음/기준 하단 요약,구분선과모든히어로버튼을제거했다. 습관추가는상단+만사용한다. 목록제목옆중복남은수와주간/자동/리듬/보고서의교육·권유문장도축약했다. 날짜·주간일수/분/횟수·원천·현재등록습관기준은남긴다. 목표0개는—와짧은상태이며다른곳으로스크롤하는대체버튼을만들지않는다. 큰글씨에서는링대신2/5완료를짧게보이고남은수를확대한다.

앱소스·actual캡처는그대로이며,테마맵보존본/manifest/README·계획서와브라우저새PNG를같은작업에서갱신한다. 최신검증은[통합계획](../../plans/2026-10-28-life-tab-redesign.md)의보완기록과[QA결과](../theme-map/themes/assets/life-redesign-qa.json)를따른다.

## 오늘의 실천 카드 표현 보완 · 2026-10-28

사용자 요청으로 평평한 목록을 습관별 카드로 바꿨다. 바깥 today 구획은 투명하게 두고,그안의습관만아이보리표면/약한종류별tint/20px모서리를쓴다. 화분은세이지새싹,독서는골드책,물은청록물방울의52px아이콘well로구분한다. 카테고리색은이시안의표현이며native에서는기존DS/AppTheme의대응semantic색/SFSymbol을재사용한다.

오늘제목/지난기록→한묶음의보조필터→짧은시간대라벨→습관카드→완료펼침의순서다. 반복은예정일/간격·경과일배지와완료/내일로,독서는큰30px기록시간과실제진행막대,물은큰잔수·44px±·목표8잔중실제완료한잔만채운물방울8개로표현한다. 숫자/단위와행동을가깝게두고장문설명은추가하지않는다.

물방울은조작이아닌진행표현이며숫자와접근성요약을함께제공한다. 목표초과수치는그대로보이되물방울은목표까지만채운다. 현재시안의물목표8잔은고정fixture이며일반횟수습관을모두물방울로바꾸지않는다. 완료·메뉴·시간수정·±영역은계속분리한다. 지난기록진입과수정/undo/주기동작을유지한다. 큰글씨에서는자연높이와버튼줄바꿈,넓은폭은이름/아이콘왼쪽·진행/행동오른쪽의가로행으로전환한다.


## 히어로 골드 장면·습관 메달 보완 · 2026-10-28

사용자는 숫자만 남긴 히어로가 다른 탭보다 시각적으로 약하다고 지적했다. 골드 능선의 겹선과 옅은 금빛 면,구리/브론즈에서밝은골드로반사되는배경,안쪽디스크를가진링을더했다. 원래104px링·완료/남음수치·HABITS/오늘과짧은높이는유지한다. 장면은장식SVG이며건강그래프/예측으로해석하지않는다. 별도문장이나스크롤버튼은추가하지않는다.

남은숫자아래최대5개의작은습관메달을둔다. 그날의실제습관아이콘순서를사용하고완료한습관만금속골드/작은체크로채운다. 5개보다많으면나머지개수를표시하고총수/완료수의계산은기존수치를유지한다. 메달은새점수/보상/XP나연속일배지가아니며,장식이므로터치버튼으로만들지않는다. 실제기록동작은아래습관카드가소유한다. 기록이없으면가짜완료메달을만들지않는다.

큰글씨에서는메달을생략하고수치/텍스트를우선한다. 반복되는반짝임·회전·점멸애니메이션은쓰지않는다. 밝음은아이보리/샌드위의골드,어두움은브론즈/브라운위의골드를사용한다. native구현시AppTheme/DS색과ReduceMotion을따르고이시안의금속표면을새게임보상처럼연결하지않는다.

기존수치중심히어로는`life-hero-before-ornament-light.png`/`dark.png`로비교보존하고최신hero/전체/큰글씨PNG를갱신한다. 이번변경은시안표현만이며앱/actual화면은변경하지않는다.
