# Today Compact 실제 화면 · 2026-10-26

[실제 캡처 비교](index.html) · [출처·해시](evidence.json) · [세 브라우저 시안](../../../theme-map/themes/dune-today-comparison.html) · [검토·실행 기록](../../../../reviews/2026-10-26-today-compact.md)

기존 DUNE / Desert Warm 테마를 유지하고 Today 전체의 정보 밀도를 조정했다. 이 폴더의 PNG는 테스트 시드가 있는 실제 네이티브 화면이다. 브라우저 시안 이미지를 실제 화면의 증거로 재사용하지 않았다.

| 구성 | 활성 디스플레이 | PNG 크기 | 확인 범위 |
|---|---|---|---|
| iPhone 18 Pro Max | 주 화면 | 1320×2868 | T03 밝음·어두움, T18 편집 |
| iPad Pro 13-inch M5 | 주 화면 | 2064×2752 | T03 밝음·어두움, T18 편집 |
| Duo 외부 | LCD | 1398×2034 | T03 밝음·어두움, T18 편집 |
| Duo 내부 | LCD-1 | 2006×2852 | T03 밝음·어두움, T18 편집, 세로 |

- 기본21개 검사와 기본 글씨 캡처의 네이티브 소스는 `56f62feceb8e9ec5724a44f4e1881ff19ff75fc8`이다. 육안 검토에서 발견한 최대 글씨 제목만 `19cf57c9bcc91141921e43cadd4facff64f46bd2`에서 세로로 보완했다. 해당 selector1/1과 native 빌드·delta 리뷰를 통과했고 영향받은 최대 글씨 PNG 두 장만 새 출처로 갱신했다. 표준 글씨 branch는 그대로다.
- 각 구성의 루트 캡처 테스트와 편집 진입 테스트는 각각1/1 통과했다. T18은 시스템 표시 설정의 캡처이며 모든 테마/글씨 조합을 의미하지 않는다.
- `regular-odd-pins.png`는 행 가운데 탭 → 수면 선택 → 저장 → 세 번째 카드 전체 폭까지 검증한 1/1 통과 원본이다. UI 시드의 기본 고정 항목은 HRV·RHR 두 개로, 운영 fallback 세 개와 다르다.
- Duo는 전용 기기만 사용해 활성 LCD/LCD-1·실제 PNG를 읽었다. 물리 orientation readback은 세로다. 가로 설정 명령은 성공을 반환했으나 readback과 일치하지 않아 **내부 가로 및 수치 힌지 각도는 미검증**이다. 세로 캡처를 가로 검증으로 사용하지 않는다. 외부 화면의 native 탭 레일 등 OS chrome은 원본 그대로 보존했다.
- T03은 측정값이 있는 기본 글씨 상태다. 기존 시작 스켈레톤·빈 기록 상태의 미갱신 안내는 실제 맵에 유지했다. 새로 캡처하지 않은 상태를 완료로 처리하지 않는다.
- 관련 Today 검사·최대 글씨·링 경계·번역 검사는 별도 실행 기록으로 구분한다. 기본 글씨 이미지가 모든 접근성 상태 통과를 뜻하지 않는다.

원본 PNG는 다음 실행에서 Xcode 결과 번들이 정리되기 전에 복사했고 SHA-256을 저장했다. 이미지는 재색칠·합성하지 않았다. 기기별 통합 맵은 T03·T18만 갱신했고 수집 중 함께 들어온 T09 등 무관한 화면은 원래 이미지와 출처로 복원했다.

최종 실행은 관련21개 고유 검사 통과 뒤 최대 글씨 보완1개를 추가 확인한22회 성공이다. 같은 검사를 반복한 수와 고유 검사 수를 구분한다.
