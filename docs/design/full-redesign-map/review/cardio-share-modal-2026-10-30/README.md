# 공유 모달 배경·드래그 실제 검증

[새 원본 20장](index.html) · [출처·크기·SHA-256](capture-index.json) · [해결책](../../../../solutions/general/2026-10-30-cardio-share-modal-background-and-drag.md)

CA05–CA07 공유 시트에 불투명 바탕과 상단 바, page sizing·large detent·본문 scroll 우선·닫기 손잡이를 지정했다. 본문은 전체 제안 영역을 채우고 내용이 큰 경우에만 bounce한다. inspector 위의 독립 NavigationStack은 유지한다. Journey/Passport의 표시 설정이나 공유 이미지 출력은 수정하지 않았다.

## 최종 관련 UI

4건 모두 정상 종료·통과했다. 각 사례는 위 방향 드래그 2회와 아래 방향 1회 뒤 카드/컨트롤 노출과 본문 높이를 확인한다. 본문 아래 드래그로 모달이 닫히면 같은 상세가 정상적으로 남는 경우만 허용한다. 손잡이 닫기에서는 공유 화면 자체가 사라지는 것을 확인하고, 재열기 후 완료 버튼으로 닫는다. `surfacePrimary`의 light/dark asset alpha가 1임을 확인했고 새 밝음/어두움 원본에서 시트 내부에 아래 운동 상세가 비치지 않는 것을 직접 검토했다.

모든 운동·좌표는 opt-in 예시 데이터다. 위치 포함은 OFF여서 MapKit snapshot 네트워크에 의존하지 않는다. 전체 UI suite, 실기기의 모든 중간 애니메이션 프레임, 공유 앱 호출·GPS·CloudKit 동기화를 검증한 결과는 아니다. 최대 글씨 원본은 긴 본문의 스크롤 검증이며 기존 카드 출력의 모든 글자 배치를 새로 승인한 결과가 아니다.

## 첫 실행의 실패와 입력 보정

첫 3건은 본문 드래그와 내용 유지 구간을 통과했지만 제목 영역을 끌어 닫는 단계에서 실패했다. 실제 AX에서 완료 버튼 중심은 y=110pt, 별도의 `시트 손잡이`는 y=80pt였다. 접근성으로 확인한 보이는 시스템 손잡이를 직접 드래그하도록 테스트 입력을 보정한 뒤 해당 3건만 한 번 재실행해 3/3 통과했다. 앱 코드를 되돌리거나 닫기 실패 assertion을 제거하지 않았다. 최초 실패 receipt와 최종 receipt를 [evidence](evidence/)에 구분해 보존한다.

## 미갱신 기기

두 Duo 상태의 CA05–CA07도 영향 대상이다. 직전 작업의 전용 Duo는 내부 화면 전환 후 AX unknown·테스트 기동 900초/124가 남아 있고 정상화 근거가 없다. 이번 작업에서는 같은 실패 경로를 재실행하지 않았으며 새 Duo 원본은 미완료다. 기존 PNG를 새 구현의 증거로 사용하지 않는다. 전용 기기의 앱/AX/러너 기동 복구를 확인한 뒤 기본 글씨 dark selector만 재개한다. Watch는 공유 편집기를 사용하지 않는다.

이 갤러리의 초기·드래그 후·다른 스타일·닫힌 상세(W27)·재열기 원본을 구분해 확인한다. 이전 [간격 보완 갤러리](../cardio-share-spacing-2026-10-30/index.html)는 이번 배경/표시 정책을 적용하기 전의 이력이다.
