# H07/P06 실제 화면 검토

소스 `1514deb76c33aee630c7bc44173716190af6aff2`의 저장된 자세 기록 상세 화면을 일반 iPhone, iPad, Duo 접힘·펼침에서 확인했다. 봉인된 네 실행에서 UI 사례 11개가 모두 통과했고, 독립 검토가 실제 PNG/AX 20쌍을 선택했다. H07과 P06의 대표 이미지는 각 기기 일반 사례의 상단 화면이다. Duo 정적 큰 글자 화면은 점수 카드와 하단 다섯 화면을 자세별 보조 증거로 보존한다.

예전 H07/P06 이미지 8개는 화면 정체성 참고다. 촬영 소스·기기 UID·자세·AX가 현재 결과와 일치하는 전후 쌍이라고 주장하지 않는다. 이전 소스 8a의 Duo 통과 결과와 1514 접힘의 준비 단계 실패 및 원인 결합 재시도도 별도 이력으로 남긴다.

원래 3자세 FOLD 검사는 실패와 호스트 중단 상태로 미해결이다. 이번 통과 범위는 Duo 0°/180° 끝자세의 정적 큰 글자 검사를 포함한다. 90° 중간 자세 전환, 피드백 동작, 모든 저장 사진·의료적 해석의 검증을 뜻하지 않는다. 구성요소 진단에서 측정된 신뢰도 대비 17.21:1도 전체 실행 통과의 근거로 사용하지 않는다.

선택한 각 이미지와 접근성 계층 파일은 봉인된 사례별 SDK 첨부물·호스트 캡처, 소스, UID, 자세와 연결된다. 실행별 영수증과 과거 실패 이력, 독립 검토 결과는 이 갤러리의 `evidence.json`에서 확인할 수 있다.
