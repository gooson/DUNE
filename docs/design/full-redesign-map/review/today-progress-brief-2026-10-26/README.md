소스 revision은 빌드 당시 HEAD이고 미커밋 제품·테스트 변경이 포함되어 있으므로 파일별 SHA256을 함께 기록했다. 캡처 파일은 xcresult에서 추출한 원본이다. 과거 PNG를 새 실행 증거로 재사용하지 않았다. 회복·수면 카드는 main과 동일하며 수면 단계 타임라인은 이번 변경에 포함하지 않는다.

전체 회귀, iPad, Duo 접힘·펼침, 다른 테마, 브리핑의 최대 글씨 상태는 이번 Ship에서 미실행이다. 앞선 미완료 광범위 검사에 대한 사용자의 다음 단계 진행 지시를 유지하면서 현재 남은 두 카드의 iPhone 검사만 새로 수행했다. 해당 기기의 T03은 새 캡처 완료로 표시하지 않으며 전용 기기에서 관련 selector를 실행한 뒤 별도 갱신해야 한다. Watch는 이 화면을 공유하지 않는다.
