# 공유 스타일 버튼 간격 · 실제 화면

[새 원본 8장](index.html) · [출처·크기·SHA-256](capture-index.json) · [해결책](../../../../solutions/general/2026-10-30-cardio-share-selector-spacing.md)

CA05–CA07 공유 편집에서 아이콘/이름 2단 pill을 아이콘과 이름이 나란한 작은 시스템 버튼으로 바꿨다. 상단 여백은 8pt, 카드까지는 16pt다. 접근성 글씨는 전체 너비의 3행으로 전환한다. 예시 운동·위치 비공개 상태이며 실제 사용자 기록이 아니다. 기존 PNG나 사용자가 제공한 개인 운동 화면은 저장소에 복사하지 않았다.

## 실행 결과

| 기기·상태 | 결과 | 새 원본 |
|---|---|---:|
| 전용 iPhone · 한국어·다크·기본 글씨 | 스타일 3개가 같은 높이/너비의 한 행, 실제 높이 44–56pt, 카드 간격 20pt 이하, 선택·공유 준비 1/1 통과 | 3 |
| 전용 iPhone · 한국어·다크·최대 접근성 글씨 | 스타일 3행·표시·Signature 선택·공유 준비 1/1 통과 | 2 |
| 전용 iPad · 한국어·다크·기본 글씨 | 작은 스타일 3열·간격·선택·공유 준비 1/1 통과 | 3 |

총 관련 UI 3건이 정상 종료·통과했다. iPhone/iPad 기본 글씨의 새 원본에서 이름·아이콘·버튼·카드 사이 간격을 확인했고, 최대 접근성 글씨에서 선택 버튼 이름이 잘리지 않는 것을 확인했다. 카드 콘텐츠의 기존 최대 글씨 배치 전체를 새로 승인한 결과는 아니다. 공유 카드 이미지의 출력 디자인은 수정하지 않았다.

새 문자열·데이터 로직이 없어 별도 unit suite는 실행하지 않았다. 앱 컴파일·관련 UI·문자열 카탈로그 manual/포맷·diff whitespace 검사를 수행했다. 위치 포함은 OFF로 두어 이 컨트롤 검사가 MapKit 네트워크에 의존하지 않게 했다. 실제 공유 앱 호출·다른 테마·밝음·iPad 최대 글씨는 이번 실행 범위가 아니다.

## 미갱신 기기와 재개 조건

CA05–CA07의 Duo 접힘·펼침도 같은 편집기를 사용하므로 영향 대상이다. 직전 장소 검색 작업에서 등록된 전용 Duo의 내부 화면 전환 후 AX가 unknown을 반환하고 테스트 기동이 900초/124로 종료됐다. 해당 의존성의 정상화 근거가 없어 이번 작업에서 같은 기동 경로를 다시 실행하지 않았다. 두 Duo 상태의 새 공유 캡처는 미완료이며 기존 PNG로 대체하지 않는다. 전용 기기의 앱/AX/러너 기동이 복구된 뒤 위 기본 글씨 selector만 실행해 갱신한다. Watch는 이 편집기를 사용하지 않는다.

실행 receipt와 소스 해시는 [evidence](evidence/)에 보존했다. PR 생성·머지는 수행하지 않았다.

후속 [모달 배경·드래그 보완](../cardio-share-modal-2026-10-30/index.html)에 불투명 바탕·표시 크기·닫기/재열기의 새 원본을 보존했다. 이 간격 갤러리는 해당 보완 전 시점의 원본이며 최신 배경/제스처 검증의 증거로 재사용하지 않는다.
