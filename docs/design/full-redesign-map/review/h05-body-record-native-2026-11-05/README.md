# H05 실제 신체 기록 화면 검토

네 기기·자세의 새 Add Record 이미지와 접힘 MAX Edit는 독립 검토한 실제 PNG/AX 18쌍에서 가져왔다. 핵심 다섯 사례가 통과했다. 이전 H05 PNG 네 장은 소스·UID·자세·AX가 연결되지 않은 역사적 정체성 참고다.

첫 iPad Add 실패(1회 실행·0회 통과·1회 실패)는 그대로 보존하고 이후 같은 ID의 조건부 재검사는 따로 평가했다. iPad Done은 키보드 닫힘을 입증하지 못했지만 Save와 목록 반영은 성공했다. iPhone과 펼친 Duo에는 Done 뒤 닫힘 증거가 있다. 실제 도구 버전은 Xcode 27.2 (27B52)다.

[evidence.json](evidence.json)에서 실제 사례, 보존본, 기기, 해시와 검증 한계를 확인한다. 문서 형식 보완은 승인된 게시 stage 이후의 문서 변경이며 PNG/AX는 그대로다.
