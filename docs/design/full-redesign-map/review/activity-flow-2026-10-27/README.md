# Activity Flow · 새 실제 화면 · 2026-10-27

[한 화면으로 보기](index.html) · [원본 출처·해시](manifest.json) · [배치 계약](../../../layout-map/activity-final-proposal.md)

이 작업에서 변경한 A01 및 T03/H01/L01을 전용 시뮬레이터에서 새로 촬영했다. 한국어, Desert Warm, 기본·다크·최대 접근성 글씨의 테스트 데이터다. 실제 사용자 건강 기록이 아니다. 시안 PNG는 별도로 보존하며 이 갤러리의 원본 PNG는 수정하지 않았다.

## 현재 앱과 캡처 출처

마지막 앱 표현 변경은 `a0e8cbbc`(개인 기록 값 전체 폭)다. 이후 변경은 UI 검사·수집 코드다. `manifest.json`의 각 이미지에 기기 UDID, 실제 실행 소스 커밋, 테스트/호스트 체크포인트, 시각, 픽셀 크기, 원본 파일명과 SHA256을 기록한다.

T03/H01/L01은 해당 제목 변경 뒤 이 작업에서 찍은 사진이다. 이후 Today 들여쓰기만 바뀌었고 Wellness/Life 제목 소스는 동일하다. 다른 작업의 기존 PNG를 최신 화면으로 재사용하지 않았다.

## 실행과 해석

- 최초 선택 UI43개는38개 통과·5개 실패였다. 이 중 준비도 이력2개는 DisclosureGroup의 상위 AX 식별자가 그래프 식별자를 덮은 문제로 수정했다. 알림함2개와 기존 Today 차트 식별자 검사1개는 이번 변경 밖의 실패로 별도 보존했다. 변경하지 않은 소스·대체 검증 범위를 최종 리뷰에 기록한다.
- 첫 수정 후 실행은 AX 응답 지연으로 중단했다. 사용자에게 재시도 한도와 복구 결과를 알렸고 “안쓰는거 다 정리하고 해”라는 추가 허용 뒤 잔여 소유 실행기·819MiB 캐시·유휴 기기를 정리했다. 전용 iPhone만 켠 추가7개는7개 모두 통과했다. 준비도 실제 저장 추세·기록 부족·원래 상세·네 제목·큰 글씨를 검사했다.
- iPad 최초6개는6개 통과했다. 실제 PNG에서 발견한 개인 기록 수치 잘림을 수정한 뒤 iPad 최종 Flow1개도126.934초에 통과했다.8개 값이 생략 없이 보인다.
- 최종 기본·다크 iPhone 수집 케이스는 각각130.077초·138.862초에 통과했다. 최대 글씨 전체 수집은19개 A01 PNG와 본문 검사를 마친 후 정리 단계에서300초 제한을 넘겼다. 전체 실행은 실패(exit65)이며 이를 통과로 계산하지 않는다. 해당 이미지의 `executionStatus`에도 구분했다.
- 실제 변경 범위인 개인 기록의 최대 글씨를 분리한 검사는74.678초,1개 실행·1개 통과다. 숫자의 전체 프레임이 가용 화면 안에 있고, 새 PNG에서 값과 단위를 확인했다. 선택적 전체 수집은600초 예산을 선언했으나 다시 실행하지 않았다.
- 관련 단위8개/2개 suite와 최종 iOS 빌드는 통과했다. 단위 실행 뒤 바뀐 것은 View·UI 검사·문서이며 보상/심박/구성 모델과 테스트는 동일하다.

전체 UI·모든 테마/언어·실기기 HealthKit 권한/실시간 동기화·Watch/visionOS 런타임을 통과한 것으로 확대하지 않는다. 변경된 Presentation은 iOS 전용이고 Watch는 별도 문자열 카탈로그를 사용한다.

## Duo

전용 `AD51538E-F7C0-40BC-93F1-997750BCDFBE`에서 외부1개(245.985초)·내부1개(238.111초)가 각각 통과했다. 두 케이스는 앱 설치 뒤 패널 전환, 새 AX, Activity 순서·네 제목·링의 실제 AX 크기를 함께 확인한다. 외부는466×678pt/1398×2034px, 내부는951×669pt/2853×2007px다. 기본 글씨·한국어·밝은 DUNE과 해당 실제 viewport만 검증했다.

공식 `device info displays`에서 LCD/LCD-1의 활성 상태를 읽고 양쪽 원본 PNG를 함께 저장했다. 각도 setter는 검토한 공개 소스 `7acb090dd7d28fb0aea8e1907211ceff15aa450e`의 테스트 전용 helper다. 현재 CLI에는 실제 힌지 각도 조회가 없어 `actualAngle=null`, `angleVerified=false`를 보존한다. 물리 각도·회전·입력 유지·다른 글씨/테마를 통과한 것으로 표시하지 않는다.

원래 등록된937C8462 기기는 실제 목록에서 사라져 첫 검사가 시작 전에 멈췄다. 새 소유 기기를 기록하고 진행했다. 부팅 로그의 데이터 이전 실패와 초기 기본 캡처가 비활성 패널을 골랐던 검은 이미지는 성공 근거로 사용하지 않았다. 이후 활성 패널의 앱 화면·fresh AX·두 UI 케이스 정상 종료로 실제 표시를 확인했다. 해당 검은 이미지는 갤러리에서 제외했다.

## 추가 기능 검증

사진 수집과 분리한 최대 글씨 지표 검사는1개 실행·1개 통과(136.958초)다. 보고서 볼륨, 훈련 부하 시간/칼로리, 근력/유산소 비율의 실제 도달성과 양수 크기 프레임을 확인했다. 전체 사진 수집의 시간 초과를 이 결과로 통과 처리하지 않는다.

모든 실행의 원래 범위와 제한은 [최종 리뷰](../../../../reviews/2026-10-27-activity-final-flow.md)에 정리한다. 커밋되는81개 원본의 SHA256은 manifest로 확인한다. 이후 main의 일일 요약 변경은 해당 별도 실제 맵과 통합 리뷰에서 추적한다.
