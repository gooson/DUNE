Today 실제 피드백 수정 · 2026-10-26

모의 건강 데이터를 넣고 새로 실행한 네이티브 앱 캡처입니다. 원본 픽셀·시간·UDID·테스트·해시는 증거 목록, 구현과 실패 이력은 실행 기록에 보존합니다. 이전 시안이나 사용자 실건강 화면을 새 캡처로 재사용하지 않았습니다.

초기 수정의 단위 회귀 52/52 통과. 후속 리뷰에서 데이터 보존 날짜를 추가 수정했으며 리뷰·출시 게이트 상태를 별도로 기록합니다. 관련 UI 9개 고유 selector 중 8개에서 성공 증거가 있으며, X 실제 클릭은 미완료입니다. 최종 T03 기본 배치는 폰·iPad·Duo 외부 LCD에서 각 1/1 통과했습니다. 테스트 실패 중 얻은 화면은 failed-capture-only로 구분합니다.

검증 제한
  • X 실제 클릭은 사용자 요청으로 추가 실행하지 않음. 최종 44×44 프레임과 독립 식별자는 확인함.
  • Duo 펼침: 내부 LCD-1 확인 후 XCTest 히트테스트 실패·검은 PNG로 실제 화면 갱신 미완료.
  • T06 iPad/Duo 및 다른 건강 지표 상세의 새 캡처 없음. 폰 수면 표본에서 공통 push/복귀/뒤로/재진입/전체 데이터 경로 확인.
  • 루틴은 공통 카드 적용 및 컴파일 확인. 운영 루틴 표본 캡처는 없음.

Duo 내부의 검은 PNG는 실제 화면 갤러리에서 제외하고 실패 진단으로만 보존했습니다. 내부 화면의 히트테스트 실패를 통과로 표시하지 않습니다.
