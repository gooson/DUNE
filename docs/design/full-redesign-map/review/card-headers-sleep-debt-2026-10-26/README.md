# 네 탭 헤더·수면 부채 실제 캡처 · 2026-10-26

현재 워크트리 소유 iPhone 18 Pro에서 최종 컴파일 앱을 직접 설치·실행해 촬영한 PNG 5장이다. 밝음·한국어·기본 글씨·Desert Warm만 확인했다. 4탭 비교 보드는 새 PNG를 축소 배치한 비교용이며 개별 PNG가 수정되지 않은 원본이다.

- T03 낮: 컨디션 제목 옆 chevron, HRV·RHR 별도 칸.
- T03 밤: 회복·수면 헤더와 수면 부채 0분 체크 링. 0 초과·10시간 초과 링은 이번 PNG로 검증하지 않았다.
- A01: 준비도·근육 지도 헤더. 아래 모든 상세 카드를 촬영했다는 의미가 아니다.
- H01: 웰니스·수면·예측 헤더. 최초 5초 시작 프레임은 흰 화면이라 diagnostic-H01-startup.png로 분리하고 완료 증거에서 제외했다. 준비된 저장소로 다시 실행한 새 PNG만 갤러리에 사용했다.
- L01: 첫 화면·습관 목록. 수정된 보고서/히트맵 헤더는 이 viewport 밖이므로 이 이미지로 완료를 주장하지 않는다. 이전 헤더 UI 실행의 Life 한 건은 통과했으나 현재 5개 suite 통과로 올려 계산하지 않는다.

최종 자동 UI 실행은 컴파일·링크 후 러너 시작에서 결과가 나오지 않아 900초/124로 종료했다. 직접 설치도 40초 한도에 걸려 기기 소유권을 대조한 뒤 해당 기기만 재부팅했다. 부팅·설치 정상화 후 위 캡처를 얻었으며 자동 테스트는 추가 재실행하지 않았다. 직접 캡처를 테스트 통과로 취급하지 않는다.

기존 actual/regular의 다른 기기·UDID 인덱스는 덮어쓰지 않고 통합 포털에서 이 새 갤러리로 연결한다. iPad·Duo 접힘/펼침의 T03/A01/H01/L01, 어두움·큰 글씨·다른 테마·하단 모든 카드는 미갱신이다. 재개 시 정상화된 전용 기기에서 필요한 selector와 상태만 이어서 확인한다.

기준 커밋과 당시 미커밋 앱/테스트 delta를 source-delta.patch와 JSON 해시로 보존했다. 스트레스 점수 강조 세 방향은 별도 시안이며 실제 앱 점수 표현에는 적용하지 않았다.
