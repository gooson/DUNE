iPad의 T03·A01·H01·L01도 밝음·어두움에서 [실제 캡처](ipad/dark/T03.png)로 확인했다. iPad 8장의 출처는 `capture-index.json`의 `ipad/` 항목이다.

iPhone 8장은 `ThemeMatrixUITests/testDesertWarmMatrix()`와 `testDesertWellnessRingLayout()`가 통과한 결과의 XCTest 스크린샷이다. 각 이미지의 원본 첨부 이름, 결과 번들, 캡처 시각 및 기기 ID는 `capture-index.json`에 기록했다.

이 캡처는 변경 전 일반 iPhone 인덱스와 다른 기기에서 얻었다. iPad, Duo 접힘·펼침 및 다른 테마의 최신 화면 검증은 별도 상태이며 이 16장을 Duo나 다른 테마의 완료 증거로 사용하지 않는다.
