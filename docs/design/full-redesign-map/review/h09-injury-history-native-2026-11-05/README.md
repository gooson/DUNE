# H09 부상 이력 · 실제 화면 검토

현재 소스 `611d70b1`의 네 프로필, 다섯 통과 SDK 사례와 열 PNG/AX 쌍을 선택했습니다. [갤러리](index.html), [캡처 목록](capture-manifest.json), [근거](evidence.json)를 함께 검토합니다. 원래 네 PNG는 다른 fixture·날짜의 화면 정체성 참고이며 같은 조건의 전후가 아닙니다.

Active/Recovered 두 섹션과 부위·측면·심각도·기간·날짜, 기존 통계 버튼의 Light 대비를 검토했습니다. 네이티브 측정 비율은 Duo 접힘 9.50:1, 펼침 9.09:1, iPhone 9.12:1, iPad 9.07:1입니다. H10 상세·H08 입력은 별도 화면입니다. Dark, 90°, Watch, 삭제·회복·통계 행동 실행은 이번 검토 범위가 아닙니다.
