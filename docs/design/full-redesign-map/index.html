  4. GATE 3WATER LILIES 추가

    새 AppTheme 케이스, 색상·모티프, 설정 선택, 저장값 복원, 4탭·상세·시트·Watch/Vision 토큰을 추가한다. 기존 7개 케이스의 저장 호환성을 확인한다.

  6. GATE 5실제 화면 검증
