# Brainstorm: 장기 스트레스 점수와 상태 강조

## Problem Statement

T03의 `35 보통`이 하단 근거 문장과 비슷한 무게로 읽혀 점수와 현재 구간을 빠르게 구분하기 어렵다. 사용자는 강조 또는 도식화 아이디어를 요청했다. 이 문서는 새 아이디어이며 앱 점수 표시 구현을 승인한 것으로 취급하지 않는다.

## Target Users

Today에서 현재 점수와 상태를 빠르게 파악하고 상세 화면에서 근거를 확인하는 사용자.

## Success Criteria

- 첫 시선에 점수·100점 척도·현재 상태가 보인다.
- 하단 근거는 유지하고 점수와 다른 위계로 읽힌다.
- 큰 글씨·좁은 폭·색각 차이에서도 숫자와 텍스트로 구분한다.

## Proposed Approach

1. **구간 막대 — 추천**: 큰 `35 / 100`과 상태 배지, 네 구간 막대 위 현재 위치 표시. 기존 모델 기준인 0–29/30–54/55–74/75–100을 따른다.
2. **작은 링**: 점수를 링 안에, 상태를 옆에 둔다. 전용 공간이 더 필요하며 수면 부채 링과 시각적 표현이 반복된다.
3. **숫자와 상태 강조**: 숫자를 크게 하고 상태 배지와 짧은 세로 강조선을 둔다. 도식의 정보량은 작지만 가장 단순하다.

## Constraints

실제 계산·구간·기여 요소를 변경하지 않는다. 높은 점수를 목표 달성으로 오해하게 하지 않고 회복률이나 임상 진단을 새로 만들지 않는다. 시안은 원본 스크린샷의 값과 근거를 예시로 사용하며 새 실제 캡처가 아니다.

## Edge Cases

0·100, 구간 경계 29/30·54/55·74/75, 큰 글씨, 데이터 불충분, 길이가 다른 상태 이름을 구현 단계에서 확인한다.

## Scope

MVP는 점수/상태 표시 영역과 승인된 공통 상세 헤더의 조합이다. 근거 펼침·새 차트·추가 계산은 범위 밖이다.

## Open Questions

구간 막대·링·숫자 중심 중 최종 방향은 사용자 선택 대기다. 현재 네이티브 앱에서는 헤더 통일만 진행하고 점수 표시는 바꾸지 않았다.
