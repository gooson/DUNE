# 러닝 경로 기록과 지도 공유 및 개인 업적

## Problem Statement

러닝의 거리·시간뿐 아니라 **어디를 어떤 방향으로 달렸는지** 남기고, 보기 좋은 지도 카드로 공유한다. 사용자가 ‘경로 기록·예쁜 공유 카드 중심’을 선택했고 ‘땅따먹기라기보다 업적’으로 정정했다. 타인의 영역을 빼앗거나 휴식하면 업적이 사라지는 게임을 중심에 두지 않는다.

## Target Users

실외 러닝 경로를 돌아보거나 SNS에 남기는 러너, 실내 운동도 누적 성취로 기록하고 싶은 러너. 기존 DUNE의 운동 상세와 건강 데이터 분석을 유지한다.

## Success Criteria

- 다섯 방향이 색상 외에 배치·지도 비중·공유 목적에서 구별된다.
- 실제 GPS 경로, 미수신 경로, 실내 거리, 가상 여정을 혼동하지 않는다.
- 사용자가 운동 상세에서 경로를 확인하고 공유 결과를 예상할 수 있다.
- 출발·도착 숨김이 공유 geometry와 위치 표식에도 반영된다.
- 다른 브랜치의 상세 개편과 합칠 경계가 명확하다. 이번 산출물은 시안과 조사이며 앱 적용 완료가 아니다.

종합 판단: 경로를 보여 주는 것에서 **기억·개인화된 출력·누적 성취**로 넓히는 패턴이 보인다. 이는 사례의 공통점에서 도출한 설계 해석이며 시장 점유율이나 유행 강도의 실측 결과가 아니다. 사용자 선택에는 지도 포스터와 루트 시그니처가 가장 직접적이고, 실내 확장에는 가상 여정이 맞는다.

## Proposed Approach

다섯 시안은 [레이아웃 계약](../design/layout-map/running-map-share-proposal.md)을 따른다. 추천 조합은 **Atlas의 상세 경로 + Signature를 포함한 공유 템플릿 + Passport의 작은 업적**이다. Pace는 분석형 대안, Journey는 실내 특화 확장이다. 아직 한 방향을 승인한 것으로 보지 않는다.

### 방향과 경로 표현

북쪽 고정 지도를 기본으로 하고, 기록 시각 순서에서 진행 화살표를 구한다. 시작/종료가 가까운 루프도 S/F와 첫 진행 구간으로 구별한다. GPS 끊김·일시정지 구간을 가로지르는 직선을 만들지 않는다. 실시간 나침반 방향과 달린 방향은 별개다. 부드럽게 보이게 하려다 코너를 잘라 실제 경로를 바꾸지 않는다.

페이스색은 구간 통계가 있을 때만 제공한다. 정지 시간을 포함한 순간 페이스를 예쁘게 보이려고 임의로 색칠하지 않는다. 같은 경로 비교는 시작점·방향·거리·GPS 품질·실내외를 맞춘 뒤 제공하며 단순 지도 모양 일치로 PR을 만들지 않는다.

### 실내 세 경우

| 실제 기록 | 지도/방향 | 업적과 공유 |
|---|---|---|
| 러닝머신·센서 거리 | 운동한 시설의 장소 지도와 핀. 이동 경로선은 없음 | 첫 5K·누적 50K, 수치형 Signature, 선택형 가상 여정 |
| 실내 트랙·랩 | 장소 지도와 핀을 기본 제공. 확인된 랩/시설 geometry가 있으면 별도 표시 | 랩 기록·거리 업적. 가짜 GPS 위치/방향 없음 |
| 거리 불명/시간만 있음 | 0km로 채우지 않음 | 시간 카드. 거리 기반 가상 진행은 보류 |

가상 여정은 ‘실내 러닝 · 가상 여정’ 레이블을 카드 안에 남긴다. 실제 운동 거리와 누적 가상 진행을 따로 표시하며, 한 운동을 여러번 가져와도 같은 여정에 중복 합산하지 않는다. 가상 방문은 실제 장소 방문 업적에 포함하지 않는다.

### 업적 규칙 초안

| 업적 | 필요한 근거 | 실내 인정 |
|---|---|---|
| 첫 5K / 누적 50·100K | 유효 러닝 거리, 기록 원천과 중복 제거 | 가능. 센서/수동 원천 구분 |
| 나의 코스 기록 | 같은 방향·코스·종목·거리 조건의 검증된 이력 | 실외 코스와 분리 |
| 처음 달린 길 | 실제 GPS + 도로 매칭 + 중복 제거 길이 | 불가 |
| 장소 스탬프 | 실제 경로와 정의된 장소 조건 | 가상 여정에서는 ‘가상 완주’로만 |
| 가상 여정 완주 | 설정한 목표와 적용한 유효 거리 합계 | 가능 |

업적은 삭제/수정/중복 제거 이후 재계산한다. 취소된 업적을 확정 메달로 공유하지 않는다. 시간대·주간 경계·오래된 HealthKit 재수신을 고려한다. 쉬는 날 업적 소멸·강제 연속일·위험 장소 방문 보상은 두지 않는다.

## Constraints와 현재 코드

- `DUNE/Data/Location/LocationTrackingService.swift`: 실외 GPS의 거리/고도와 필터는 있지만 전체 좌표열을 보존하지 않는다.
- `DUNE/Domain/Services/LocationTrackingServiceProtocol.swift`: start/stop과 합계 중심. 경로 DTO·시각·정확도·구간 경계 계약이 필요하다.
- `DUNE/Presentation/Exercise/CardioSession/CardioSessionViewModel.swift`: 실내/실외와 운동 수치가 있지만 결과 DTO에 경로가 없다.
- `DUNE/Data/HealthKit/WorkoutWriteService.swift`: workout 저장은 있으나 route builder/query는 아직 없다. 타 앱의 기존 경로를 읽는 것과 새 경로 저장은 각각 추가 작업이다.
- `DUNE/Presentation/Exercise/HealthKitWorkoutDetailView.swift`: 기존 지표 상세를 보존하고 경로 섹션을 추가할 접점이다.
- `DUNE/Presentation/Exercise/Components/WorkoutShareService.swift`, `WorkoutShareCard.swift`, `ShareImageSheet.swift`: 공유 이미지의 선례를 재사용하되 지도 생성은 별도다.
- Watch 러닝·페이스 피드백이 있다는 사실만으로 Watch GPS 경로 보존이 된다고 가정하지 않는다. [기존 Watch 작업](../solutions/architecture/2026-10-25-watch-running-feedback.md)은 수치/피드백 중심이다.

구현 순서는 route 읽기/보존과 품질·권한·백그라운드/중단 복구를 먼저 확인한 뒤 지도 표시, 정적 공유, 업적, 가상 여정이다. Apple의 [workout route](https://developer.apple.com/documentation/healthkit/creating-a-workout-route)와 [map snapshot](https://developer.apple.com/documentation/mapkit/mkmapsnapshotter)은 구현 시 확인할 공식 API 진입점이다. 이번 조사에서 본문이 JS 전용으로 반환되어 세부 API 사용법을 검증한 것으로 표시하지 않는다.

### 공유 품질

지도 도로/지명은 대비를 낮추고 경로·방향·핵심 수치를 선명하게 둔다. 지도 기준과 경로 원천은 바꾸지 않으며 부드러운 렌더링과 geometry 변조를 구분한다. MapKit snapshot과 별도 경로 렌더링을 후보로 검토한다. 지도 제공자의 표시·사용 조건과 attribution을 내보내기에도 보존한다. 지도 불러오기가 안 되면 경로만 카드 또는 수치 카드를 제공한다.

출발·도착 숨김, 장소명 제외, 전체 경로 제외를 선택할 수 있게 한다. 숨긴 위치를 배경의 중심점·업적 핀·사진 위치정보·공유 메타데이터로 다시 노출하지 않는다. 이 처리가 익명성을 보장한다는 문구는 쓰지 않는다. [Strava 공개 범위 도움말](https://support.strava.com/en-us/articles/15402012-how-do-i-edit-my-map-visibility-on-strava)의 ‘지도 공개 범위와 활동 공개 범위는 다르다’는 구분을 참고한다.

## Scope

### MVP

1. 실제 route가 있는 러닝의 지도 + 방향/구간 경계 + 경로 없음 상태.
2. Atlas·Signature 중심 정적 출력. 피드·스토리·정사각, 수치/날짜/장소 선택, 공유 전 공개 경로 미리보기.
3. 경로 수집/저장/HealthKit 가져오기와 iPhone·Watch 원천 중복 제거.
4. 검증 가능한 첫 거리·누적 거리 업적을 작게 연결.

### Future

Pace 구간·동일 코스 비교, 사진/투명 PNG, 월간 누적 지도·새 길, 가상 여정, 짧은 리플레이. 3D 영상·실시간 위치 공유·외부 서비스 업로드·친구 피드는 우선 범위가 아니다.

## Edge Cases

권한 거부, 아직 경로를 받는 중, 경로 없는 기존 workout, GPS 비약/끊김, 가까운 평행도로, 왕복/루프/반대 방향, 경로 일부만 공개, 모두 숨긴 경로, 지도 오프라인, 삭제·수정된 원천, 중복 Watch/Phone workout, 거리 미수신, 수동 보정, 자정 경계, 큰 글씨/긴 번역을 별도 상태로 다룬다. 시안의 검증은 브라우저 배치와 조작 범위이며 GPS/센서/HealthKit 동작 검증이 아니다.

## 다른 상세 개편과의 경계

「디자인 개편 시안부터 보기」 세션의 da96 worktree를 읽어 공통 DUNE 브라운·골드와 Compact/Focus 방향, 전체 상세·설정 inventory 확장, iPhone·iPad·Duo 대상을 확인했다. 그 브랜치의 제목/통계/기존 차트/탐색은 덮어쓰지 않고 **경로 섹션·전체 지도 목적지·공유 편집**을 추가하는 계약으로 설계한다. 다른 브랜치 변경·병합·세션 메시지 전송은 하지 않았다. 공유 manifest/index는 병합 시 entry 단위로 합친다.

## 실내 장소 표시 보완 · 2026-10-29

실내 러닝도 **운동한 장소를 지도에 표시**한다. 위치를 자동 추정할 수 있으면 후보 시설을 제안하고, 실내 GPS 오차나 권한 거부 때는 사용자가 지도/장소 검색으로 직접 선택한다. 러닝머신에서 실제로 이동한 경로를 만드는 것과 시설 위치 핀을 보여주는 것은 별개의 기능이다. 장소를 정하지 않은 상태에서는 위치를 만들어 채우지 않는다.

저장할 장소 정보는 좌표·표시명·선택 원천·필요시 추정 정확도로 분리한다. 단발 위치 수집과 장시간 경로 추적을 구분하며, HealthKit에서 장소를 받지 못한 기존 기록에는 사용자가 장소를 연결하는 방식을 검토한다. 직접 선택한 장소를 GPS로 검증한 방문 업적으로 취급하지 않는다.

공유는 ‘운동 장소 공유’ 선택을 제공한다. 끄면 지도 배경·핀·시설명 모두 출력하지 않고 개인 기록은 유지한다. 현재 시안에서는 OSM의 두 시설을 설명용 후보로만 사용하며 실제 사용자 위치나 시설 이용을 의미하지 않는다. 실내 카드의 실제 장소 지도와 Journey의 가상 지도는 각각 명시적으로 이름을 붙인다.

## 모든 실내 유산소로 범위 확대 · 2026-10-29

사용자가 러닝만이 아니라 **모든 실내 유산소**를 대상으로 정정했다. 장소 지도·핀·장소 선택/보정·공유 공개 범위는 종목과 기록 단위에 독립적인 공통 기능이다. 실내 자전거·일립티컬·계단 오르기·스텝퍼·로잉·줄넘기·인터벌/혼합 유산소·실내 걷기와 수영장 운동 등에 같은 장소 기능을 제공한다. 새 종목이나 사용자 정의 종목도 장소 모델을 재사용하며 특정 종목 allowlist로 차단하지 않는다.

| 기록 단위 | 예시 | 표시 기준 |
|---|---|---|
| km | 러닝·걷기·실내 자전거 | 실제 거리, 시간. 러닝/걷기의 페이스와 자전거의 속도를 구분 |
| m | 로잉·실내 수영 | 실제 거리, 시간. 로잉 /500m·수영 /100m 페이스가 있으면 표시 |
| floors | 계단 오르기·스텝퍼 | 층수·시간·기록한 레벨. km로 바꾸지 않음 |
| count | 줄넘기 | 횟수·시간. km나 러닝 페이스를 만들지 않음 |
| timeOnly | 일립티컬·시간 기반 유산소·기타 | 시간과 실제 레벨/심박/열량. 거리가 없으면 거리 목표에 합산하지 않음 |

현재 `CardioSecondaryUnit.swift`의 km/meters/floors/count/timeOnly와 `WorkoutActivityType.swift`의 종목 모델을 기준으로 구분했다. 일립티컬이 일부 분류에서 distance-based라고 되어 있어도 실제 선택한 운동의 기록 단위와 수신 필드를 우선한다. 스트로크·회전수·랩 등의 추가 지표는 실제로 받은 경우에만 제공한다.

장소 부착은 실외 선택 가능 여부나 거리 필드 유무에 종속시키지 않는다. 실내 전용 머신의 시작 화면·운동 중·완료·기록 상세·공유에서 공통 장소를 이어가며, 수동/가져온 기록도 장소가 없으면 선택할 수 있게 설계한다. 직접 선택한 시설을 센서가 검증한 방문으로 취급하지 않는다. 상세 개편 브랜치에는 W23/W24/W25/W28의 **모든 실내 유산소 공통 장소 영역**으로 전달할 계약이며 이번 작업은 시안/문서만 수정했다.

다섯 시안에 운동 종목 선택을 추가했고, 러닝 외에는 종목별 단위를 사용하는 공통 실내 유산소 카드를 표시한다. 거리 없는 운동의 Journey는 **운동 시간 목표**로 구성하며 가상의 km를 생성하지 않는다. Passport도 러닝 첫5K 대신 운동 시간·운동 횟수 예시로 바뀐다. 모든 수치는 설명용이며 실제 기록을 읽거나 저장하지 않는다.
