# S01 설정 허브 검증 기록

설정 홈에서 현재 테마와 앱 아이콘, 운동, 알림, 개인정보, 앱 정보에 접근한다. 미리보기를 열면 사용자가 적용할 때까지 현재 설정을 보존한다. 검색은 지원 언어의 표시 이름과 영어 별칭을 사용한다.

## 발견 및 수정

| 발견 | 수정과 확인 |
|---|---|
| 검색에서 테마를 적용하면 검색 결과로 복귀 | 적용 후 갤러리에서 같은 테마에 선택 표시가 남는지 iPhone에서 확인 |
| 좁은 화면에서 연 상세를 넓힌 뒤 왼쪽 메뉴를 선택하면 이전 상세가 남을 수 있음 | 설정 루트가 선택을 소유하고 기존 push를 닫도록 변경. iPad에서 오른쪽 상세 교체와 왼쪽 허브 유지를 확인 |
| 테마 버튼의 접근성 식별자가 별도 Other 요소에 부여됨 | 네이티브 Button에 식별자·선택 상태를 부여. 취소·적용, 검색에서 적용하는 시나리오 통과 |
| 한국어 환경의 아이콘 팔레트 결과를 영어와 비교함 | 지원하는 세 언어의 해당 팔레트 이름을 검증하도록 테스트를 수정. 한국어로 통과 |

Duo에서 시스템 뒤로 버튼이 내비게이션 막대 밖에 배치되는 실제 AX 트리를 확인하고, 테스트의 뒤로 탐색 도우미가 플로팅 버튼도 찾도록 보완했다.

아키텍처, 데이터 정합성, 보안, 성능, 단순성, iOS UX, 앱 품질, PR 관점에서 검토했다. 확정된 미해결 P1·P2는 없다. 에이전트 지침은 이번 변경 범위 밖이다.

## 검사와 실제 화면

| 대상 | 확인한 동작 |
|---|---|
| 검색 단위 검사 6건 | 중복 ID, 취침·테마 목적지, 번역·별칭·띄어쓰기, 시뮬레이터 전용 항목 |
| iPhone 18 Pro | 서로 다른 6개 경로. 미리보기 취소·적용과 앱 아이콘 팔레트, 검색에서 테마 적용, 취침 검색·빈 결과·뒤로, 운동·개인정보, 최대 글자 크기, 한국어 화면 |
| iPad mini | 한국어 화면과 왼쪽 허브를 유지한 상세 전환 |
| iPhone Duo | 외부 화면과 내부 화면에서 한국어 설정 동선. 공식 패널 활성 상태와 앱 캡처 해상도를 기기별 증거에 기록. Xcode 27.2는 수치 각도 조회 명령을 제공하지 않음 |

총 10개의 기기별 UI 시나리오가 통과했다. 실제 지도에는 iPhone 11장, iPad 8장, Duo 접힘·펼침 각 6장을 보존한다. 접힘 상태에서 비활성 패널을 반환한 XCTest 화면 첨부는 제외했다. 활성 LCD에서 직접 수집한 1398×2034 PNG와 펼친 LCD-1의 2853×2007 PNG를 상태별 접근성 트리와 함께 대조했다. iPhone 결과는 처음 실행에서 성공한 세 경로와 수정 후 통과한 세 경로를 합산했다. 마지막 iPhone 팔레트 실행의 XCTest 종료 코드는 0이었다. 같은 시간에 실제 화면 문서를 갱신해 작업 폴더 전체를 검사하는 래퍼가 변경을 표시했다. 실행 전후의 앱 소스와 테스트 변경 범위를 대조하고 XCTest 결과를 재사용했다.
