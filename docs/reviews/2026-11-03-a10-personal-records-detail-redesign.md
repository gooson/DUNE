# A10·T16 개인 기록 최종 검토

최종 앱 검증 소스는 `7ce674d4b3da73a7a24ccda6fbe39429f098d806`다. A10 Activity 진입과 T16 알림 진입은 같은 상세 화면을 사용한다. 이후 실제 비교 자료와 문서를 추가했으며 앱·검사·카탈로그 소스는 바꾸지 않았다. [기존·개편 실제 화면 비교](../design/full-redesign-map/review/a10-personal-records-native-2026-11-03/index.html)에서 기기별 자료와 대응 접근성 기록을 확인할 수 있다.

## 변경과 보존 범위

일·주를 추가한 다섯 기간을 제공하고 선택 기간의 추세와 전체 최고 기록을 구분한다. 원래 아홉 종류의 아이콘·단위·공유 동작, 실제 레벨·포인트·배지·달성 이력을 유지한다. 알림 진입에도 실제 획득 배지 키를 전달한다. 보상 갱신을 독립시키고 기존 pace 조회·취소·캐시와 이력 제한을 보존한다.

접근성 글씨에서는 최고 기록 제목과 NEW·공유 버튼을 두 줄로 나누고 기간 선택은 시스템 메뉴를 사용한다. 배지 폭은 글씨와 함께 확장하며 날짜축 간격도 넓힌다. 선택 기간의 마지막 실제 값·원래 단위·날짜를 읽을 수 있는 요약으로 제공한다. 일반 크기의 헤더·기간·축 배치는 유지한다.

## 실제 검증

- b0의 일반 크기 Activity·알림 진입: iPhone·iPad·Duo 접힘·펼침에서 각각 **2/2**, 합계 **8개 통과**. 다섯 기간·선택 범위·최근 값·보상·이력과 각 경로의 Back을 확인했다.
- 최종 7ce의 Duo 접힘 다크 MAX 원래 검사: **1/1 통과**. 제목·NEW, 공유 버튼의 44pt 영역과 접근 가능성, 다섯 기간과 범위 복귀, 최근 값·레벨·포인트·전체 배지 이름·달성 이력 및 전체 플롯을 확인했다. 실제 공유 시트를 실행한 검사로 확대하지 않는다.
- 최종 MAX의 **15개 PNG·접근성 체크포인트**를 모두 검토했다. 과거 헤더 줄바꿈·배지 가독성·축 겹침 문제는 검토한 최신 캡처에서 해소됐다.
- 관련 VM 검사는 5d46에서 **19/19 통과**했다. 이후 VM·검사 및 관련 기간 계산 소스가 바뀌지 않은 범위로 재사용했다.
- 7ce CI의 Build iOS와 iOS·Watch 단위 테스트는 성공했다. [빌드](https://github.com/gooson/DUNE/actions/runs/41587687735) · [단위 테스트](https://github.com/gooson/DUNE/actions/runs/41587687649)

일반 크기 b0 캡처를 새 7ce 촬영으로 표시하지 않는다. 독립 소스 대조는 내용·배치 범위이며 DEBUG 파동 위상·픽셀이나 새 플롯 접근성 식별자의 동일성을 주장하지 않는다. b0 iPad MAX는 과거 보조 증거로 구분한다. 기존 원본의 개별 촬영 소스·기기·접힘 출처가 없으면 미상으로 기록한다. 원본 PNG와 EXIF 회전 정보는 보존한다.

각 캡처의 실제 비동기·시드 값이 다를 수 있으며 같은 데이터 상태로 설명하지 않는다. 최종 MAX는 기존 어제 러닝 운동을 원래 PR 저장 API로 등록하는 명시적 DEBUG fixture를 사용한다. 일반 실행에는 적용하지 않는다. 각도·활성 디스플레이·원본 PNG·접근성 자료를 연결했고, Duo 부팅의 migration 경고는 후속 검사 통과와 별도로 보존했다. 마이그레이션 수리를 입증했다고 주장하지 않는다. Phone의 당시 registry 원본이 없는 부분은 표준 생성·등록 성공에 대한 작업자 증언으로 구분한다.

## 검토와 자료 반영

실제 다섯 관점 리뷰와 후속 UI·fixture·main 통합 변경을 대조했다. 검토 범위에서 열린 P1·P2는 없다. 실제 VoiceOver 음성이나 정량 명암비, 모든 언어·상태·기기의 MAX를 검증했다고 주장하지 않는다.

실제 맵의 기존 변경 대상은 A10/T16의 기기별 이미지·시작/활동 보드·인덱스와 연결 문서 27개다. 별도 전후 비교 갤러리를 추가했고, A05·T04·T09 및 다른 화면은 보존했다. 원본 출처·해시와 설치 전후 변경 범위를 독립 검토했다. 이전 실패와 성공의 원래 결과·소스·실행 제한은 유지했다.

## 확인 경로

Activity → 개인 기록에서 다섯 기간과 전체 최고 기록을 비교한다. 알림함의 개인 기록 알림에서도 같은 상세로 진입하고 Back으로 알림함에 복귀한다. 큰 글씨에서는 기간 메뉴와 전체 배지 이름, 겹치지 않는 날짜축을 확인한다. 최종 머지 상태는 [PR #904](https://github.com/gooson/DUNE/pull/904)에서 확인한다.
