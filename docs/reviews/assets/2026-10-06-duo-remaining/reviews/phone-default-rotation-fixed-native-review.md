# iPhone 기본 글자 크기 회전 native delta 검토

범위: 통과한 `phone-default-capture-handshake-fixed` 캡처 010–016 및 해당 AX 계층의 kg/reps 값. 파일 이름은 모두 `1206x2622`이지만 실제 픽셀 크기는 010·014–016이 세로 1206×2622, 011–013이 가로 2622×1206이다.

- **회전 전 세로(010):** `KG 62.5`와 `REPS 11`이 같은 화면에 온전히 보인다. 라벨·숫자·증감 버튼의 내부 겹침은 없다.
- **가로(011–013):** 011은 스크롤 전 위치여서 입력부가 고정 하단 버튼 뒤/아래에 있다. 012에서는 `KG 62.5`, 013에서는 `REPS 11`이 각각 스크롤로 온전히 노출된다. 두 값이 **동시에 한 뷰포트에 보이는 증거는 아니다.** 해당 AX 필드 값은 두 캡처 모두 `62.5`/`11`로 유지된다.
- **세로 복귀(014–016):** 두 값이 다시 같은 화면에 온전히 보이고 `62.5`/`11`이 유지된다. 016의 AX 필드 값도 일치한다.

확인한 필드에서는 회전으로 인한 숫자 잘림·소실이 보이지 않는다. 이 결과는 iPhone 기본 글자 크기의 지정된 스크롤 위치에 한정하며 실제 사용자 iPad 동작이나 VoiceOver 발화를 뜻하지 않는다.
