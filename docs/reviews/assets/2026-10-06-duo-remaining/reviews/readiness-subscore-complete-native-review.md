# Readiness SubScore 전체 플롯 native 검토

범위: 통과한 Book/maxAX `book-max-readiness-subscore-complete` 캡처 003–008. 각 차트의 제목·평균은 홀수 번호, 전체 플롯은 짝수 번호에서 확인했다.

- **HRV (003/004):** `Avg 75 ms`, Y축 79/75/71, 첫·끝 날짜 `S 30`/`O 6`이 온전히 보인다. 선과 채움의 양끝이 플롯 안에 있고 축 글자와 겹치지 않는다.
- **Resting Heart Rate (005/006):** `Avg 52 bpm`, Y축 56/52/49, 양끝 날짜가 온전히 보인다. 붉은 선·채움이 플롯과 카드 안에 유지되며 눈금을 가리지 않는다.
- **Sleep Duration (007/008):** 앞선 캡처에서 화면 밖이었던 하단까지 새 증거로 확인했다. `Avg 7.4 hrs`, Y축 8.9/7.5/6.1, 양끝 날짜가 모두 보인다. 보라색 선·채움의 끝과 축 라벨이 겹치거나 잘리지 않는다.

세 플롯의 지정된 Book/maxAX 상태에서 조치할 내부 잘림·겹침은 보이지 않는다. `S 30`·`O 6`은 좁은 월 표기 그대로이며, 다른 글자 크기·방향·VoiceOver는 이 픽셀 검토의 결론에 포함하지 않는다.
