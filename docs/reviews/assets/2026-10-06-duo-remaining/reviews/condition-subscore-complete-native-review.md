# Condition Closed 최대 AX SubScore 전체 플롯 native 검토

범위: 조건 데이터가 채워진 `closed-max-condition-subscore-reveal-fixed` 활성 1398×2034 캡처 003–006. 제목·평균은 003/005, 전체 플롯은 004/006에서 확인했다. 기존 `100` 카드 판정은 반복하지 않았다.

- **HRV:** `Avg 75.8 ms`가 온전히 보인다. Y축 79.6/75.5/71.4와 첫·끝 날짜 `O 1`/`O 7`이 서로 분리되어 읽힌다. 황금색 선과 채움의 양끝은 플롯 안에 있고 축·날짜를 덮지 않는다.
- **Resting Heart Rate:** 제목은 단어 단위 두 줄이고 `Avg 52 bpm`은 온전하다. Y축 56/52/49와 `O 1`/`O 7`이 분리되어 보인다. 붉은 선·채움이 플롯 안에 있으며 라벨과 겹치지 않는다.

지정된 Closed/maxAX 화면에서 두 차트 모두 조치할 픽셀 잘림·겹침이 보이지 않는다. 다른 상태·폴드와 VoiceOver 발화는 이 판정에 포함하지 않는다.
