# A11 운동 일관성 상세 최종 검토

최종 앱 소스는 `fa4ba7383f1e08c70585e84e0bddaa30d6f41bf1`다. 현재·최장 연속 운동일, 현재 월 달력·목표와 전체 이력을 불투명 히어로와 원래 아이콘으로 강조했다. 개별 운동 20분 이상이라는 기준, HealthKit·수동 기록 병합, 계산·취소·로딩·빈 상태·뒤로 가기는 유지한다. 새로운 기간 선택이나 정보 동작은 추가하지 않았다.

접근성 글씨에서는 일곱 열의 날짜를 글자 크기에 맞춰 넓히고 가로 스크롤한다. 글씨를 축소하지 않으며 월간 진행률을 세로로 배치한다. 실제 계층에서 달력·이력 자식 식별자를 확인했고, 지연 생성되는 날짜는 스크롤 후 값과 전체 프레임을 검사한다. 1일 이력은 `1 day`/`1일`/`1日`로 바로잡았다.

[기존·개편 실제 화면 비교](../design/full-redesign-map/review/a11-consistency-native-2026-11-03/index.html)에는 다음 촬영 소스와 한계를 구분했다.

| 프로필 | 실제 결과·소스 | 검토 범위 |
|---|---|---|
| Duo 접힘 일반 | be23 일반 검사 통과, 전체 묶음은 1통과·1실패 | 현재·최장 3일, 달력·3/16·이력·Back. 이후 소스와 비교한 일반 배치 범위로만 재사용하며 단수 문구·픽셀 동일성은 제외한다. 종료 자세는 지연된 작업자 확인으로 구분한다. |
| Duo 접힘 MAX | 3c 원래 검사 1/1·9개 유효 체크포인트 | 양쪽 위치의 한 줄 두 자리 날짜, 값·월간 진행률·이력·Back. 과거 `1 days`가 남은 촬영이며 새 fa4 MAX 촬영으로 표시하지 않는다. |
| Duo 펼침 일반 | fa4 1/1·7개 체크포인트 | 실제 180°/LCD-1 전후 확인, 값·달력·진행률·이력·수정된 `1 day`·Back. |
| iPhone 일반 | fa4 1/1·7개 PNG·AX 쌍 | 실제 값·날짜·달력·이력과 단수 문구, 전체 프레임·Back. |
| iPad 일반 | fa4 1/1·7개 PNG·AX 쌍 | 넓은 화면의 배치·값·날짜·달력·이력과 단수 문구, 전체 프레임·Back. |

검토한 소스와 실행 범위의 미해결 P1·P2·P3는 없다. 일반 4개와 MAX 1개는 서로 다른 리비전의 실제 실행이며 단일 fa4 5/5 묶음으로 주장하지 않는다. MAX 이벤트 006은 앞선 날짜 이미지와 같아 반복 표시를 줄였다. 실제 월간 진행률과 이력은 다음 007 캡처에서 확인한다. AX 기록만으로 VoiceOver 음성·탐색이나 모든 언어·상태·명암비를 검증했다고 주장하지 않는다.

fa4의 [iOS 빌드](https://github.com/gooson/DUNE/actions/runs/41599085729)와 [단위 테스트](https://github.com/gooson/DUNE/actions/runs/41599085708)는 성공했다. 바뀌지 않은 VM·도메인 검사를 로컬에서 반복하지 않았다. 과거 실제 실패와 0건 실행 준비 오류, 보존 후처리 오류는 구분해 유지했다. 초기 migration 경고는 후속 성공으로 수리됐다고 주장하지 않는다.

실제 맵의 변경 대상은 A11 기기별 이미지·활동 보드·인덱스·비교 메타데이터 및 연결 문서 19개다. 별도 전후 갤러리를 추가하고 A05·A10·T04·T09와 다른 행을 보존했다. 이전 네 장은 운동 일관성 화면임을 확인했으며, 촬영 소스·기기·자세가 불명확한 부분과 Duo 펼침의 원래 EXIF 회전 정보를 그대로 구분했다. 검증을 끝낸 전용 Duo·iPhone·iPad는 각 결과 보존과 검토 뒤 삭제했고 현재 소유 기기는 0개다.

확인 경로는 Activity → 운동 일관성이다. 일반 크기의 두 히어로·달력·진행률·이력과 큰 글씨의 달력 가로 스크롤을 확인한다. 머지 결과는 [PR #905](https://github.com/gooson/DUNE/pull/905)에서 확인한다.
