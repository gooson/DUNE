# FOREST · 숲 안개와 소나무

[승인 시안](../design/theme-map/themes/forest-green-direction.html) · [실제 기기별 화면](../design/phone-design-map/actual/forest-canopy-2026-11-18/index.html) · [iPhone 정상 속도 영상](../design/phone-design-map/actual/forest-canopy-2026-11-18/phone/motion/today-light.mp4)

## 리뷰와 수정

| 관점 | 결과 |
|---|---|
| 아키텍처·영향 범위 | 알림과 운동 목록도 탭 배경을 재사용하고 있었다. 두 화면은 기존 숲 실루엣을 명시적으로 선택하도록 수정했다. 설정의 테마 미리보기는 새 원화를 정지 상태로 표시한다. |
| SwiftUI·접근성·단순성 | 좁은 화면에서 주간 그래프의 세 자리 값이 잘릴 위험을 수정했다. 기록을 펼치면 장식을 카드 아래에 두고 그래프에 전체 폭을 준다. 7개 날짜에 접근할 수 있고 마지막 값은 그래프 안에 들어온다. |
| 성능 | 몸통과 능선을 담은 원화를 타임라인 밖에 두고, 투명 솔잎과 두 안개층의 위치·농도만 갱신한다. 동작 줄이기·저전력·비활성 상태에서는 타임라인을 정지한다. |
| 데이터·보안 | 실제 수치와 버튼은 기존 모델·동작을 사용한다. 앱 에셋과 브라우저 시안은 로컬 리소스를 사용한다. 캡처에는 테스트용 기록을 사용했다. |

우선순위 P2 두 건을 수정하고 해당 범위를 다시 검토했다. 에이전트 설정 변경은 없다.

## 검증

- `DUNETests/ForestCanopyMotionTests` 4건 통과. 24초 경계와 앞·뒤 안개 농도, 두 솔잎 그룹의 진폭과 시차, 정지 조건과 앱 에셋을 검사했다.
- iPhone 18 Pro에서 T03·A01·H01·L01의 라이트·다크와 설정 테마 선택을 확인했다. 별도의 XL 검사에서 펼친 그래프의 폭, 7개 값과 마지막 날짜의 접근성을 확인했다. 마지막 값에 허용되는 안쪽 여백을 반영한 후 해당 검사만 재실행했다.
- iPhone 정상 속도 영상은 앞안개가 짙은 시점과 맑아진 시점, 골짜기에 안개가 다시 차는 모습을 담는다. 시작 화면을 잘라낸 영상 길이는 약 22초다. 전체 주기 24초의 반복 경계는 유닛 검사로 확인했다.
- iPad mini(A20 Pro)와 접힌 Duo에서 같은 네 탭의 라이트·다크 검사를 각각 통과했다. Duo는 활성 외부 디스플레이(LCD), 세로 방향과 466×678pt 앱 화면을 확인했다. iPad의 Life 라이트·다크 촬영 사이에 날짜가 바뀌어 습관 완료 수가 달라진다.
- 펼친 Duo에서는 활성 내부 디스플레이(LCD-1)를 사용했다. 8장 모두 캡처 시점의 앱 접근성 트리에서 951×669pt 가로 화면을, PNG에서 2853×2007px를 확인했다.
- 최종 유닛 4건과 UI 6건이 통과했다. 실제 화면 34장과 각각의 접근성 트리, 영상 및 프레임 3장을 갤러리에 연결했다.
