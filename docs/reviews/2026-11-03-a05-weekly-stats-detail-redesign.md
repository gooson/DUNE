# A05 주간 운동 통계 최종 검토

검증한 앱 소스는 `ed21363cf3a790d29e704e5fa4883f9e5e16bd0a`다. 이후 이 문서와 실제 화면 비교 자료를 추가했으며 앱·검사 소스는 바꾸지 않았다. [실제 전후 비교](../design/full-redesign-map/review/a05-weekly-stats-native-2026-11-03/index.html)에서 원본과 개편 화면, 대응하는 접근성 기록을 확인할 수 있다.

## 변경과 보존 범위

현재 다섯 통계와 이전 기간의 실제 값·변화량을 구분하고 원래 아이콘·단위를 보존했다. 세 기간과 세 차트 지표, 날짜 선택·스크롤·새로고침·Back은 유지한다. 큰 글씨에서는 수치와 비교 행을 세로로 배치하고 기간 선택은 시스템 메뉴로 제공한다. 별도 통계 창은 전경 창 제거 후 원래 운동 소유 창으로 복귀한다.

## 실제 검증

- iPad 다크 일반 크기와 원래 최대 글씨 검사: **2/2 통과**, 실패·스킵 0.
- 일반 크기: Activity에서 진입해 실제 다섯 현재 값과 네 이전 값을 확인하고 캡처했다.
- 최대 글씨: 세 기간 선택, 실제 비교 범위 변경·복귀, 큰 메뉴의 전체 표시, 차트 볼륨 선택과 기존 10초 닫기·운동 화면 복귀 조건을 확인했다. 복귀 후 세트 조작의 표시·활성 상태를 확인했으며 세트 완료를 실제 탭한 검사로 확대하지 않는다.
- 관련 VM 검사: c707에서 **9/9 통과**. 이후 VM·검사 파일의 변경이 없는 것을 대조해 해당 범위로 재사용했다.
- ed213 CI의 Build iOS와 iOS·Watch 단위 테스트는 성공했다. [빌드](https://github.com/gooson/DUNE/actions/runs/41582484329) · [단위 테스트](https://github.com/gooson/DUNE/actions/runs/41582484342)

Phone·Duo 접힘·펼침의 일반 크기 이미지는 실제 d79 촬영 원본이며 ed213의 새 캡처로 표시하지 않는다. 변경되지 않은 화면 내용·배치의 소스 대조로 범위를 한정하고 DEBUG 정적 파동의 위상·픽셀 일치는 주장하지 않는다. Duo 각도·활성 화면과 PNG·접근성 자료의 대응을 보존했다. 과거 원본 맵의 개별 소스·기기·접힘 출처가 없는 경우는 미상으로 기록한다. 측정하지 않은 명암비나 실제 VoiceOver 음성 실행을 통과했다고 주장하지 않는다.

## 검토와 해결

기존 다섯 관점 리뷰와 이후 코드 변경분을 대조했다. 독립 네이티브 검토에서 최대 글씨의 작은 기간 선택기 문제를 확인했고 실제 새 캡처로 해결을 확인했다. 열린 P1·P2는 없다. 이전 값 포맷 규칙이 일부 중복된 P3 유지보수 의견 1건은 현재 출력이 일치하는 상태로 허용했다.

실제 맵의 기존 변경 대상은 A05의 기기별 이미지·활동 보드·인덱스와 연결 문서 19개다. 별도 갤러리를 추가하고, 다른 화면의 행·이미지·브리핑 및 컨디션의 T04·T09 변경은 보존했다. 독립 스테이지 검토와 설치 후 원본 해시·비대상 비교를 수행했다. 기존 실패 및 원래 시간 제한은 유지했다.

## 후속 확인

앱의 Activity → 이번 주 통계를 열어 현재 값과 이전 기간을 비교한다. 글씨를 크게 설정하면 기간 메뉴에서 이번 주·지난 주·이번 달을 선택할 수 있다. 운동 진행 중 통계를 열었다 닫으면 원래 운동 화면으로 돌아온다. 최종 머지 상태는 [PR #892](https://github.com/gooson/DUNE/pull/892)에서 확인한다.
