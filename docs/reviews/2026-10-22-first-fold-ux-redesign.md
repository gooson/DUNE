# 첫 화면 UX 개편 리뷰 및 해결 기록

2026-10-22 · `codex/design-revamp-ux` · 비교 기준 `main...HEAD`

## 검토 범위

Today T03, Activity A01, Wellness H01의 첫 화면과 관련 UI 테스트, 4탭 디자인 맵, iPhone·iPad·Duo 실제 화면 캡처를 검토했다. 보안, 성능, 구조, 데이터 무결성, 단순성 5개 리뷰 관점을 실행했다. `.claude/`와 에이전트 설정 변경이 없어 Agent-Native 관점은 적용되지 않는다. SwiftUI, Apple UX, 앱 품질, UI 테스트 관점도 별도로 실행했다. 새 대량 데이터 처리 구현이 없어 `perf-optimizer`는 적용되지 않는다.

## 발견 사항과 처리

| 우선순위 | 발견 | 처리 |
|---|---|---|
| P2 | Activity 로딩 중 새 운동 제안 영역이 전체 운동 기록의 최근·인기 ID를 계산함 | `suggestedWorkoutSection(useHistory: false)`로 로딩 분기의 기록 조회를 건너뛰고 운동 검색 진입을 유지함. 성능 재리뷰에서 해결 확인. |
| P2 | Today 링 점수와 7일 차트의 당일 값이 서로 다를 수 있음 | `weeklyTrendScores`가 현재 점수를 당일 값으로 사용하도록 수정하고 UI 테스트로 현재값을 확인함. |
| P2 | 준비도가 없는 로딩 상태에서도 준비도 상세 진입을 제공함 | 준비도 링크를 값이 생길 때까지 비활성화하고 운동 시작 경로는 유지함. |
| P2 | iPad Wellness 큰 글씨에서 수면 요약의 가로 배치가 좁아짐 | 접근성 크기에서는 수직 배치하고, iPad 기본·Accessibility XXXL 화면을 실제 캡처해 잘림이 없음을 확인함. |
| P2 | 수면 날짜·기간과 Today 대체 추세의 데이터 정확성을 직접 확인하는 UI 테스트가 부족함 | 실제 시뮬레이터 seed 경로에 0분 수면 fixture를 추가하고 정확한 값·날짜·차트 접근성 값을 테스트함. |
| P3 | Wellness 카드의 수면 설명 영역을 탭하면 웰니스 점수 상세가 열리지만 하단에는 수면 상세라고 표시됨 | 기존 카드의 터치 동작이다. 첫 화면 개편 범위에서 카드 전체 경로를 바꾸면 점수 상세 진입이 사라지므로 후속 UX 판단 항목으로 보존함. |

수정 후 `main...HEAD`를 다시 수집해 같은 5개 관점으로 재리뷰했다. **열린 P1=0, P2=0, P3=1(위 UX 판단 항목)**이다. 재리뷰에서 추가 발견은 없었다. 로딩 이외의 기존 Activity 운동 기록 전체 조회는 이번 변경 전부터 있던 성능 검토 대상이다.

## 검증

- iOS 빌드: 수정 후 `scripts/build-ios.sh` 성공.
- iPhone 영향 테스트: Activity·Today·Wellness 14/14 통과.
- iPad 수면 요약 기본·Accessibility XXXL: 1/1 통과. 두 상태의 실제 스크린샷을 확인했고 텍스트 잘림은 없었다.
- 원래 범위의 iPhone UI 게이트: 35/35 통과. 이후 리뷰 해결 코드가 반영된 범위의 최종 UI 게이트를 출하 전에 다시 실행한다.
- 현지화: 새 표현의 영어 원문 및 한국어·일본어 번역, 동적 기간과 수면 시간의 현지화 사용을 직접 확인했다.

실제 첫 화면 캡처와 출처는 [화면 갤러리](../design/full-redesign-map/review/first-fold-ux-2026-10-22/index.html)에 있다. Duo 펼친 상태의 어두운 화면은 시뮬레이터 호스트 정체로 촬영하지 못했으며 완료된 상태로 계산하지 않는다.
