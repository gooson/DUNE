# 전체 건강 지표 이력 검토

## 범위와 판정

현재 HEAD `757cd9c0`의 16개 지표에 대해 조회, 목록 페이지, 차트 과거 탐색, UI 비용 및 공유 캐시를 정적 검토했다. 전체 이력 통일 기준으로 **NEEDS WORK**: P1 1건, P2 4건. 앱 코드는 변경하지 않았다. 과거 세션의 체중 테스트 통과는 다른 지표 전체의 검증을 의미하지 않는다. 이번 검토에서 새 빌드·실기기 테스트는 수행하지 않았다.

HealthKit 기록 읽기·표시 범위를 검토한 것으로, Apple 건강의 전체 데이터를 CloudKit에 복제하는 변경을 의미하지 않는다. 최근 상태·점수 계산의 제한된 관찰 기간은 유지할 수 있다.

## 지표별 현황

| 지표 | 전체 데이터 목록 | 상세 차트 |
|---|---|---|
| 체중 | 전체 조회 후 200개씩 표시 | 전체 이력, 표시 구간 필터링 |
| 체지방·제지방량 | 페이지 중복 발생; 별도 체성분 화면은 전체 조회 | 기간 버퍼로 제한 |
| 심박수·SpO₂·호흡수·VO₂Max·심박 회복·손목 온도 | 페이지 중복 발생 | 기간 버퍼로 제한 |
| HRV·안정시 심박·수면·걸음·운동·BMI·호흡장애 | 빈 구간에서 탐색 종료 | 기간 버퍼로 제한 |

## 발견사항

### [P1] 8개 지표의 과거 페이지 중복 및 종료 불가

위치: `DUNE/Presentation/Shared/Detail/AllDataViewModel.swift:246`

심박수·체지방·제지방량·SpO₂·호흡수·VO₂Max·심박 회복·손목 온도는 페이지 종료 경계를 적용하지 않고 현재까지 누적 조회한다. 최근 기록 하나만 있어도 다음 페이지마다 반복 추가되고 hasMoreData가 유지된다.

수정 방향: 고정 기준일과 겹치지 않는 [start, end) 구간 조회를 사용한다.

### [P2] 빈 30일 구간에서 이전 이력 탐색 중단

위치: `DUNE/Presentation/Shared/Detail/AllDataViewModel.swift:103`

체중 외 경로는 빈 페이지를 전체 이력의 끝으로 간주해 공백 이전의 기록을 표시하지 못한다.

수정 방향: 최초 기록 또는 실제 샘플 커서를 종료 기준으로 사용하고 빈 중간 구간을 건너뛴다.

### [P2] 체중 외 차트에 전체 이력 탐색 미적용

위치: `DUNE/Presentation/Shared/Detail/MetricDetailViewModel.swift:238`

체중만 최초 기록까지 스크롤 도메인을 확장한다. 다른 지표는 기간 버퍼에 제한되고 스크롤 시 추가 조회도 없다.

수정 방향: 전체 탐색 도메인과 제한된 조회·렌더링 구간을 분리한 공통 이력 처리를 도입한다.

### [P2] 과거 페이지마다 최근 데이터까지 반복 조회

위치: `DUNE/Presentation/Shared/Detail/AllDataViewModel.swift:155`

HRV와 운동은 과거 페이지마다 현재까지 누적 조회한 뒤 필터링한다. 오래된 이력을 탐색할수록 중복 조회·변환 비용이 증가한다.

수정 방향: HRV 날짜 구간 API와 기존 운동 start/end API로 해당 페이지 구간만 조회한다.

### [P2] 캐시 무효화 전 조회가 새 캐시를 덮어쓸 수 있음

위치: `DUNE/Data/Services/SharedHealthDataServiceImpl.swift:64`

invalidateCache는 실행 중 태스크 참조만 지운다. 이후 새 조회가 시작되어도 이전 태스크 완료가 캐시를 저장하고 새 태스크 참조를 지울 수 있다. 공유 스냅샷 사용 화면에 영향을 준다.

수정 방향: 세대 번호와 요청 ID로 완료 시점의 캐시 저장 및 태스크 해제를 검증한다.

## 전체 적용 시 성능 조건

현재 체중 방식의 전체 원본 조회를 고밀도 지표에 그대로 복사하면 안 된다. 체중 외 차트는 전체 배열의 마크를 만들며, DotLine/Bar/RangeBar 등의 축은 stride 기반이다. 전체 기간으로 도메인만 확장하면 이전 Charts 지연을 재발시킬 위험이 있다. 이 항목은 아직 발생을 재현한 신규 결함이 아니라 구현 시 반드시 지켜야 할 조건이다.

체중도 스크롤할 때 전체 배열 filter와 Y축 map/min/max를 반복한다. 공통화할 때 정렬된 날짜의 이진 탐색 슬라이스와 조회 완료 시 계산한 축 범위를 사용한다. 심박·HRV는 기간별 통계, 걸음·운동은 합계, 수면은 중복 처리된 일별 수면량 등 지표별 의미를 유지한다.

## Implementation Steps

1. 중복 페이지와 빈 구간 종료를 고정 날짜 경계·최초 기록 또는 커서 기반으로 수정한다.
2. HRV·운동의 누적 재조회를 구간 조회로 바꾸고 공유 캐시에 세대 검증을 추가한다.
3. 전체 지표 차트에 최초 기록 기반 도메인과 주변 구간 비동기 조회를 적용한다. 이미 표시된 구간은 다음 조회 중 유지한다.
4. 모든 차트에 제한된 표시 데이터·축 눈금과 재사용 가능한 집계 캐시를 적용한다. 메인 액터의 반복 전체 순회를 제거한다.
5. 16개 지표별로 중복 없는 페이지, 빈 달/빈 연도 통과, 최초 기록 도달, 기록 없음, 취소·빠른 기간 전환을 검증한다.
6. 캐시 무효화 중 이전/새 요청의 완료 순서를 뒤집는 테스트와 고밀도 장기 이력에서 스크롤·탭 반응 UI 테스트를 추가한다.

## 검토 관점

독립 검토로 목록의 데이터 무결성/성능과 차트의 구조/성능을 교차 확인했다. 통합 검토에서 공유 캐시 경합을 확인했다. 이번 범위에서는 별도 보안·현지화 결함을 확정하지 않았으며, 앱 전체 보안이나 실기기 HealthKit 저장소의 완전성을 보증하는 검토는 아니다.
