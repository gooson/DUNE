# 건강 지표 상세: 실제 단위와 가시 이력을 보존하는 비교

## Problem

16개 지표의 값과 원래 심벌을 강조하면서 기간 선택·이동·전체 데이터·수면 분석을 보존해야 했다. 반복된 날짜와 별도 통계는 차트와의 관계가 불명확했다. 수영 거리 1,314m를 운동 시간으로 표시하는 기존 입력 경로와, 거리 차트 하이라이트가 기본 분 단위를 사용하는 문제도 있었다. 기간 조회의 이전 응답이 새 요청의 통계를 덮어서는 안 된다.

신체 비교는 나이와 성별을 추정하거나 체중만으로 건강을 판정하지 않아야 한다. 공개 조사 자료의 평균과 백분위, 한국 기준과 미국 표본을 구분해야 했다.

## Solution

| 영역 | 구현과 보존 계약 |
|---|---|
| 수량 히어로 | 기존 resolved SF Symbol·실제 측정값·단위·측정 시점을 유지하고 사구 배경과 큰 숫자를 사용한다. duration·거리·백분율·부호 있는 온도·선호 질량 단위를 구분한다. |
| 이력 | 기간 조작·날짜·차트·가시 구간 통계를 한 카드에 모은다. 수락한 조회의 generation·coverage와 통계를 함께 게시하고 오래된 성공·실패는 새 상태를 덮지 않는다. |
| 통계 | 관측된 가시 구간을 기준으로 계산한다. 일·주·월·6개월·년의 기존 집계 주기를 설명하고 누락값을 가짜 0으로 만들지 않는다. |
| 운동 단위 | 실제 운동 종류와 거리 단위를 보존한다. 수영 1,314m의 차트 하이라이트는 해석한 차트 단위에 맞춰 1.3km로 표시하며 운동 시간과 혼합하지 않는다. |
| 신체 비교 | 사용자가 명시적으로 선택한 20세 이상 연령대·조사 성별만 사용한다. 미국 NHANES 2021–2023 체중·BMI 평균 28개 셀을 원문 표와 대조했다. 미지원 체지방·제지방량에는 평균을 생성하지 않는다. |
| 접근성 | 기존 기간·전체 데이터 경로와 수면 분석 네 그룹을 보존한다. 큰 글씨의 주간 차트 날짜는 달력 기준 두 눈금으로 간소화하되 전체 날짜와 모든 데이터는 유지한다. |

신체 참고 자료는 [CDC/NCHS 원문](https://stacks.cdc.gov/view/cdc/174595)의 Table 3 체중, Table 10 BMI이다. 미국 성인 조사 평균이며 한국인 기준·개인 목표·진단 범위가 아니다. 비교 기준을 선택하지 않으면 수치를 추정하지 않고, 취소와 적용을 구분한다. 출처 이동은 사용자의 명시적 조작으로만 제공한다.

Duo의 첫 검사는 본문 전에 실패했다. 독립 상세 화면으로 실행했는데 공통 setup이 탭·사이드바를 요구한 것이 원인이었다. `waitForInitialScreenReady()`를 추출해 기본 동작은 보존하고 T06만 선택한 category의 정확한 화면 ID를 기다리게 했다. 엄격한 audit, orientation, 원래 값·단위·기간 검사는 유지했다. 원래 실패와 재시도 1회를 같은 검사 ID에 보존했다.

## 검증 범위

- 과거 iPad 원본 한 검사는 17개 지표를 순회했다. 수영 원본은 별도 한 검사로 기존 잘못된 분 표시를 기록했다. 개편 iPad 한 검사는 18개 식별을 순회했으며, 이를 18개 테스트 통과로 표현하지 않는다.
- 거리 하이라이트 실행은 3개 중 2개 통과·비교 기준 1개 실패였다. 통과한 수영·러닝 결과와 실패한 bundle을 함께 보존하고, 비교 기준은 초기화 조건을 수정한 별도 1개 통과 결과를 연결한다.
- `c0b51078`의 iPhone 5개 검사에서 HRV 식별·5개 기간·이전/다음 이동·어두움·체중 최대 글씨를 통과했다. 실제 최대 글씨에서 전체 기간·비교 버튼이 노출되고 주간 날짜 두 개가 겹치지 않았다.
- `c0b51078`의 Duo 접힘과 펼침에서 HRV 핵심 검사가 각각 1개 통과했다. 자세 0°/180°·활성 LCD와 실행별 strict PNG/AX 2쌍을 확인했다. 다른 지표·기간 조작·어두움·최대 글씨 전체 통과로 확대하지 않는다.
- 현재 앱 소스 `a6f52495`의 CI 빌드와 Watch 213개 검사·29개 suite는 통과했다. iOS CI의 T06 관련 7개 suite는 모두 통과했으나, 전체 2,733개 검사·302개 suite 실행은 AI 모델 safety asset 누락에 따른 라이브 AI 평가 2개·9개 issue로 실패했다. 전체 실패를 보존하며 T06 결과만 구분한다. 이전 통과한 T05 CI에서도 이 두 라이브 AI 검사는 비활성으로 건너뛰었으므로 AI 생성 회귀 통과로 재사용하지 않는다.
- [18개 지표 실제 iPad 비교](../../design/full-redesign-map/review/t06-metric-matrix-native-2026-11-02/index.html)는 과거 10월 31일 실행과 소스·해시를 보존한다. 상단에는 네 기기 HRV 개편 캡처를 추가했다. 이 중 iPad는 과거 10월 31일이고 Phone·Duo는 11월 2일이다. 왼쪽 공통 원본은 실제 기존 iPad HRV이며 Phone·Duo와의 기기·viewport 차이를 명시했다. 같은 기기의 새 원본 캡처로 표시하지 않는다. HRV 옆에 수면 이미지를 재사용하지 않는다. 없는 원본 수영 하단 캡처는 없는 것으로 표시한다.

기존 공통 날짜 눈금 glyph 문제는 TODO 158에 별도 미해결로 유지한다. 이번 문서는 모든 기기·언어·상태의 전체 완료 선언이 아니다.

## Prevention

- category와 실제 운동 종류·해석한 단위를 함께 추적한다. 숫자와 기본 단위만 조합하지 않는다.
- 차트와 통계를 동일한 수락된 조회 snapshot으로 게시한다.
- 참고 수치마다 조사 모집단·연령 구간·단위·평균 여부·공식 표를 기록한다.
- native 비교 이미지는 화면 ID·값·단위·기기·소스·실행 결과와 연결한다. 일부 통과와 실패 bundle을 동시에 보존한다.
- 독립 UI fixture는 정확한 독립 화면을 검증한다. 탭이 없는 것을 통과시키기 위해 공통 준비 검사를 제거하지 않는다.

## Lessons Learned

시각적 강조는 원래 데이터 계약을 명확히 드러낼 때 유용하다. 같은 컴포넌트라도 단위와 실제 조회 범위가 달라질 수 있으므로 값·조작·출처를 함께 검토하고, 검증 결과는 실제 실행한 범위로 제한한다.
