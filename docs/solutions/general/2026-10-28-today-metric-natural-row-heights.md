# 조건부 본문을 가진 지표 카드의 행 높이

## Problem

Today의 비교값과 작은 그래프가 있는 수면 카드는 높지만, 이 필드가 없는 체중 카드는 짧았다. `HStack(alignment: .top)`은 위쪽만 정렬하므로 카드 아래 경계가 달랐다.

## Solution

`TodayMetricRow`가 동일한 열 폭으로 각 셀의 자연 높이를 먼저 측정하고 가장 큰 높이를 모든 셀에 제안한다. 지표 카드 내부는 제안 높이를 받아 표면까지 채운다. 높이를 상수로 고정하거나 값 없는 그래프를 만들지 않는다. 큰 글씨는 기존처럼 한 열, 홀수 마지막 카드는 전체 폭으로 유지한다. 운동 종목 행은 기존 조밀한 구조·폰트·상세 목적지를 보존한다.

Wellness와 같은 범주색·옅은 내부 면·큰 값·측정일을 적용했다. 이미 조회한 HRV/RHR·수면 관측만 작은 추세로 전달하고 체중 이력은 새로 만들어내지 않는다. 새 단위2건과 관련 UI·Astra 결과는 [실제 화면과 검증 범위](../../design/full-redesign-map/review/today-wellness-metrics-2026-10-28/index.html)에 보존한다.

## Prevention

같은 행에서 비교 있음/없음, 실제 추세 있음/없음, 긴 수면 값과 짧은 체중 값을 함께 확인한다. 배경 바깥에만 frame을 늘리면 실제 카드 표면이 짧게 남을 수 있으므로 내부 면까지 실제 PNG와 frame을 대조한다. 글씨 확대와 홀수 전체 폭을 별도로 확인한다.

표준 단위 실행기에서 범위를 선택할 수 없고 무관한 장기 실행이 생기면 새 테스트의 실제 실행을 확인한다. 이번에는 임시 계획의0개 실행을 검증으로 인정하지 않고 실제 식별자를 열거한 뒤 기존 빌드의2개 메서드를 실행했다. 전체 실행의 실패/시간 초과·0건·선택 실행의 통과를 합치지 않는다. 향후 표준 단위 실행기에 selector 지원을 추가하는 작업은 별도 범위이며 이번 실행 중 runner를 수정하지 않았다.

## Lessons Learned

같은 높이는 같은 고정 높이값보다 같은 행에서 자연 높이를 공유하는 문제다. 그래프와 비교값의 유무는 데이터 의미를 유지하고, 정렬은 배치 계층에서 해결한다.
