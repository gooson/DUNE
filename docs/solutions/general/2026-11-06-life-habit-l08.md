# 주간 습관 리포트의 완료율과 이전 주 비교를 연결하기

## Problem

기존 주간 완료율·완료/목표 수·이전 주 비교·습관 순위와 push 내비게이션을 유지하면서 핵심 수치의 위계를 분명히 해야 했다. 최대 글씨에서는 현재 값과 이전 값, 추세 아이콘, 두 순위 목록이 각각 읽히는지 확인해야 하므로 제목이나 카드의 존재만으로 가독성을 판단할 수 없었다.

## Solution

`DUNE/Presentation/Life/WeeklyHabitReportView.swift`: report의 현재/이전 주 비율·분자/분모·best/worst 목록·trend 기호와 색을 그대로 사용한다. HeroCard의 실제 현재 값, StandardCard의 비교, MAX에서도 보이는 원래 Best/Needs Improvement 아이콘을 배치했다.

기존 조회·정렬·날짜 범위·합계·비율·저장·내비게이션을 바꾸거나 합성 표시 값을 production에 추가하지 않았다. 관련 기존 UI selector와 두 combined MAX selector를 공유하며, combined MAX 메서드는 두 App 소유 화면이 모두 게시된 PR부터 포함한다. 첫 화면 PR에 아직 존재하지 않는 다음 화면의 AX ID를 요구하는 새 nightly 검사를 넣지 않는다.

## Prevention

비교를 검사할 때 상단 값은 실제 보이는 시점에 읽어 저장한다. 스크롤 뒤 오프스크린 텍스트의 materialization에 의존하지 않는다. 원래 뒤로가기는 실제 report scroll의 사라짐까지 확인한다.

## Lessons Learned

앱 상태를 새로 계산하지 않고 기존 값·원래 SF Symbol을 더 잘 읽히도록 배치한다. SDK 성공, 실제 PNG/AX의 시각 검토, 실제 디자인맵 갱신, PR 머지는 서로 다른 게이트다. 실패한 준비·SDK aggregate와 이후 개별 성공을 구별한다.
