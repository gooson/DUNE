# Solution: 활성·보관 습관의 실제 개수와 동작을 같은 화면에서 드러내기

## Problem

### Symptoms

습관 관리 화면은 활성/보관 필터, 기록 개수와 연속 기록, History·Restore를 제공했다. 필터 전환 뒤 현재 몇 개의 습관을 보는지 화면 상단에서 즉시 읽기 어렵고, 보관 행의 동작은 큰 글씨와 짧은 Duo 화면에서 실제 접근성을 별도로 확인해야 했다. 기존 쿼리나 복원 동작의 데이터 오류는 소스 리뷰에서 확인되지 않았다.

### Root Cause

기존 행 정보는 있었지만 필터와 실제 표시 개수를 결합한 상단 표현이 없었다. 보관 행의 동작 대상에는 명시적인 최소 프레임이 없었다. UI 검사의 첫 제안은 Restore를 전역 스크롤로 찾을 수 있어 관리 화면의 실제 가시성을 보장하지 못했다.

## Solution

### Changes Made

| File | Change | Reason |
| --- | --- | --- |
| `HabitManagementView.swift` | 기존 `displayedHabits.count`와 `filter.displayName`을 HeroCard의 텍스트 리프에 표시했다. | 활성/보관 필터에서 현재 쿼리 결과를 그대로 보여 준다. |
| `HabitManagementView.swift` | 기존 행의 아이콘·이름·횟수·연속 기록·생성일을 `StandardCard` 안에 배치하고 큰 글씨에서 세로 레이아웃을 사용한다. History/Restore에 최소 44pt 프레임을 더했다. | 정보 위계와 터치 대상을 명확히 한다. |
| `LifeRegressionTests.swift`, `DuoRemainingRouteTests.swift` | 관리 화면의 활성/보관 개수와 History·Restore·Back을 검증한다. 접힌 Duo MAX Restore는 식별된 관리 ScrollView 안에서만 완전히 보이도록 드러낸다. | 다른 화면의 동일 이름이나 전역 스크롤에 기대지 않는다. |

### Key Code

```swift
Text(displayedHabits.count, format: .number)
    .accessibilityIdentifier("habit-management-hero-count")
Text(filter.displayName)
    .accessibilityIdentifier("habit-management-hero-filter")

app.revealFullyVisible(restoreID, in: managementScroll, maxMoves: 10)
```

기존 활성/보관 `@Query`, `logSignature`, 로그 해석과 streak 계산, `restoreHabit(_:)`, History 시트·내비게이션은 유지했다. 행의 원래 SF 아이콘과 의미도 유지했다. 화면 카드에 부모 AX ID를 붙여 자식 이름/버튼을 숨기지 않았다.

## Prevention

필터별 수치는 별도의 캐시나 임의 카운터가 아니라 실제 표시 컬렉션에서 읽는다. 복원 테스트는 대상 ScrollView에 범위를 묶고 버튼 전체 프레임과 화면 이탈·Life 복귀를 확인한다. `@Query` 변경 뒤에는 새 화면 상태가 나타날 때까지 기다리되, 두 번째 탭이나 느슨한 조회로 단일 탭 실패를 감추지 않는다.

## Lessons Learned

자료 표현과 동작 검증은 같은 화면 소유권을 사용해야 한다. 쿼리 결과에서 읽은 헤더와 해당 관리 ScrollView에 묶인 Restore 검사가 서로 일치한다.

## Native review limits

접힌 Duo 최대 글씨에서 기존 표준 segmented control과 공유 Back의 AX 프레임은 각각 약 175×32pt, 38×38pt였다. 새 History/Restore는 실제 접근·단일 탭이 확인됐고 Restore는 161×59.3pt였다. 기존 공유 컨트롤 전체의 44pt 터치 영역까지 증명했다고 주장하지 않으며, 이는 P3 보완 항목으로 분리한다.

## Validation status

L04의 5개 메서드·프로필 조합을 선택 SDK 결과와 독립 PNG/AX 리뷰로 확인했다. 이 배치의 총 23개 조합과 기존 실패·원인별 재시도는 [L04 실제 화면·원본 출처](../../design/full-redesign-map/review/l04-habit-management-2026-11-06/index.html)에 구분했다. 해당 네 기본 프로필의 actual-map 행을 갱신했다. 전체 회귀·Dark·실기기·VoiceOver·최종 PR HEAD 실행·CI·머지는 주장하지 않는다.
