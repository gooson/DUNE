# 90일 습관 활동의 실제 총합과 요일 값을 강조하기

## Problem

기존 90일 습관 집계와 push 내비게이션을 유지하면서 기간·주요 통계·격자·요일 값의 시각 위계를 분명히 해야 했다. 최대 글씨에서는 세 통계 카드와 긴 레이블, 격자·범례·요일별 수치가 스크롤로 읽히는지 확인해야 하므로 제목의 존재만으로는 가시성을 판단할 수 없었다.

## Solution

`DUNE/Presentation/Life/HabitHeatmapDetailView.swift`: 기존 validData·완료 수·평균·활동일·최장 연속·90일 격자·범례·요일별 값·조건부 차트를 유지한다. HeroCard/StandardCard의 실제 값과 자연 높이를 사용하고 detail-only AX prefix로 Root 격자와 구별한다.

기존 조회·정렬·날짜 범위·합계·비율·저장·내비게이션을 바꾸거나 합성 표시 값을 production에 추가하지 않았다. 관련 기존 UI selector와 두 combined MAX selector를 공유하며, combined MAX 메서드는 두 App 소유 화면이 모두 게시된 PR부터 포함한다. 첫 화면 PR에 아직 존재하지 않는 다음 화면의 AX ID를 요구하는 새 nightly 검사를 넣지 않는다.

## Prevention

공유 Grid/Legend의 기본 nil prefix는 기존 Root AX 표면을 보존한다. 검사는 실제 상세 스크롤의 기간·통계·요일·범례를 드러내며 별도 이미지 검토로 색 격자와 전체 배치를 확인한다.

## Lessons Learned

앱 상태를 새로 계산하지 않고 기존 값·원래 SF Symbol을 더 잘 읽히도록 배치한다. SDK 성공, 실제 PNG/AX의 시각 검토, 실제 디자인맵 갱신, PR 머지는 서로 다른 게이트다. 실패한 준비·SDK aggregate와 이후 개별 성공을 구별한다.
