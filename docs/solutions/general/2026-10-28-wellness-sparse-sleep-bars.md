# 적은 수면 기록에서 막대가 가로로 늘어나는 문제

## Problem

`WellnessSleepSummaryCard`는 실제 표본 수만큼 열을 만들고 각 열의 `Capsule`이 가로 공간을 모두 사용했다. 2~4개 기록에서 막대 폭이 높이보다 커져 알약처럼 보였고, 중간 결측일의 시간 간격도 사라졌다. 기존 Flow의 accepted P3를 사용자 피드백에 따라 수정한다.

## Solution

오늘까지7일의 달력 슬롯을 유지한다. 실제 유효 표본만 해당 날짜에 폭16pt·최대 높이64pt의 둥근 세로 막대로 표시하고 누락일에는 도형을 그리지 않는다. 한 표본도 같은 축을 사용한다. 기록이2개 이상인 경우에만 평균을 표시하며 수면 상세 링크를 유지한다.

큰 글씨에서는 첫날·중간·마지막 날짜만 보여 주고, 차트 전체 높이는 날짜 텍스트의 자연 높이를 포함한다. 각 실제 막대의 접근성 레이블은 날짜와 수면 시간을 유지한다.

## Prevention

UI 전용 fixture로0/1/2/4/7개 기록을 만들며2개·4개에는 중간 결측일을 포함한다. 실제 막대 폭과 날짜별 존재 여부, 비균등한 날짜 간격, 평균 유무, 빈 상태, 다크/최대 글씨를 검사한다. 일별 요약에서 데이터 개수를 가로 폭의 분모로 사용하지 않는다.

## Lessons Learned

기본7개 기록만으로 그래프 품질을 판단하면 적은 표본의 왜곡을 놓친다. 기록 수와 시간축의 슬롯 수를 구분해야 한다. 테마와 점수 계산은 이 변경의 대상이 아니다.

최종 소스 `52988932`의 iPhone2·iPad1개 device-case와 iOS 빌드가 통과했다. 초기0개 빈 상태·독립 상세 진입2개는 변경되지 않은 분기의 결과를 재사용했다. 최초 AX 실패2건과 육안 검사에서 발견해 보완한 최대 글씨 날짜 잘림도 [새 실제 화면10장과 검증 기록](../../design/full-redesign-map/review/wellness-sparse-sleep-2026-10-28/index.html)에 보존했다. Duo 접힘·펼침과 iPad 다크/최대 글씨는 이번 미갱신이며, 이전66장을 이번 수정의 증거로 사용하지 않는다.
