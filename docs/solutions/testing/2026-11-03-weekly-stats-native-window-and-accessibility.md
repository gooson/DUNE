# 주간 운동 통계의 실제 비교값과 창 복귀 검증

## Problem

주간 운동 상세에서 현재 수치·이전 기간 비교·일별 차트의 읽기 순서가 약했다. 큰 글씨에서는 차트 제목과 메뉴를 함께 읽기 어려웠고, 별도 통계 창을 닫은 뒤 원래 운동 창으로 돌아가는 검사가 실패했다. 후속 검사에서는 통계에 진입하기 전 XCTest의 애니메이션 유휴 알림을 기다리다 시간 예산이 소진되는 실패도 별도로 확인됐다.

## Solution

원래 다섯 통계 값과 단위·아이콘을 같은 기간의 히어로에 모으고, 이전 기간 값과 변화량을 실제 계산 결과로 표시한다. 세 기간·세 차트 지표·스크롤·새로고침과 원래 데이터 조회를 보존한다. 접근성 크기의 값은 세로로 배치하고 차트 제목과 지표 메뉴를 분리한다. 기간 선택도 접근성 크기에서만 시스템 메뉴로 제공한다.

별도 통계 창은 정확한 전경 창의 파괴를 먼저 완료하고 원래 운동 소유 창을 활성화한다. 소유 창이 없는 복구 경로는 별도로 제한한다. 테스트는 기존 10초 닫기 조건과 원래 운동 조작 가능성 확인을 보존한다. 실제로 세트 완료를 탭하거나 값을 변경한 것으로 확대해 설명하지 않는다.

DEBUG UI 검사에서 정적 파동 설정은 주 화면뿐 아니라 통계 Scene에도 전달한다. 원래 실패 원인이 모두 파동 때문이었다고 단정하지 않는다. e3d의 원래 최대 글씨 검사는 실제 1/1 통과했고, 기존 실패 기록도 보존했다. ed213의 일반 화면·개선한 최대 글씨 검사는 실제 2/2 통과했다. 세 기간 선택·비교 날짜 변경과 복귀, 차트 볼륨 선택, 기존 닫기 조건을 실제로 확인했다.

## Verification

관련 VM 9개는 c707 소스에서 통과했고 이후 VM·검사 파일의 변경이 없는 것을 대조했다. ed213 iPad의 일반·최대 글씨 두 검사와 실제 PNG·AX를 확인했다. Phone·Duo 접힘·펼침의 일반 크기 d79 캡처는 원래 소스를 명시하고 변경되지 않은 내용·배치 범위로 사용한다. DEBUG 정적 파동의 위상이나 픽셀 동일성은 주장하지 않는다. 디자인맵은 해당 화면만 갱신하며, 머지 상태는 PR에서 별도로 확인한다.

## Prevention

- 현재 값·이전 값·변화율을 같은 기간 기준으로 읽고 테스트한다.
- 여러 Scene의 닫기는 전경 창 제거와 소유 창 복귀를 구분한다.
- 정적 캡처 환경은 각 Scene에 실제 적용됐는지 확인한다.
- 원래 실패 원본·시간 제한·실제 실행 수를 보존하고, 빌드 성공을 UI 통과로 표시하지 않는다.

## Lessons Learned

검사 성공 뒤에도 실제 이미지의 글씨 크기와 메뉴 가독성을 확인해야 한다. 코드·캡처·진입 경로의 검증 범위는 서로 구분하고, 다른 화면의 머지 변경을 보존한 상태에서 해당 화면만 반영한다.
